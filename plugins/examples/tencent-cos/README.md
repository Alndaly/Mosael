# 腾讯云 COS

存储桶名要填**带 APPID 的全名**,如 `examplebucket-1250000000`(控制台存储桶列表里就是这一列)。
访问域名留空按地域拼 `cos.<地域>.myqcloud.com`;用全球加速就填 `cos.accelerate.myqcloud.com`。

## 它解决的那个具体问题

Mosael 是**本地优先**的:素材库里的文件在你自己的盘上,没有公网地址。而有些供应商只收链接 ——
火山方舟 Seedance 的参考视频就是一例。官方文档写得很清楚:

> 请确保 URL 是公网可公开访问的链接

而且它**明确不收 Base64**:参考**图**可以走 data URL,参考**视频**不行。于是一段本地素材
根本没法当参考视频用 —— 装一个对象存储插件,这条路就通了。

`cos_upload` 就是那座桥:把素材传上去,交回一条**限时直链**。签名在查询串里,所以
**桶不必设成公共读** —— 那条地址谁拿到谁能下,但过期就失效。直接粘进生成节点的「参考视频」那一格。
装好并填上桶和密钥之后,生成节点遇到本地素材会**自动**用它传上去。

## 四个工具

| 工具 | 干什么 |
| --- | --- |
| `cos_upload` | 传一份素材上去,交回限时直链 + 公共读地址 |
| `cos_presign` | 给桶里已有的对象签一条限时直链 |
| `cos_fetch` | 把桶里的对象拉回素材库(**交地址,由宿主搬字节** —— 进度、取消、重试都归它) |
| `cos_list` | 列出某个前缀下的对象 |

## 签名

用的是 COS 的**原生签名**(`q-sign-algorithm=sha1`),纯 `hmac` + `hashlib` 手写在 `tools/qsign.py`,
不装官方 SDK —— 插件进程是按 stdio 协议跑的短命脚本,为签四个请求装一整个 SDK 不值得。

它和另外三家(S3 / TOS / OSS)的 SigV4 不是一系,几处和直觉不一样:签的是**未转义的路径**;
头和参数的键要小写、值要转义;中间那串每一段后面都有换行,连最后一段也有。任何一处写错,
服务端回的都只是 403。所以它拿官方 Python SDK(cos-python-sdk-v5)在同样输入下算出的结果
逐字对过 —— 上传、列目录、预签名直链三种,见 `backend/tests/test_cos_signature_matches_the_sdk.py`。

上传、列目录这些主体(`tools/storage.py`)和另外三家是**同一份**,字节相同的拷贝由
`backend/tests/test_storage_plugins_share_one_core.py` 钉住;这个插件只带来自己的签名方言。

## 权限与密钥

在「访问管理 → 用户」里建一个**只对这一个桶有读写权限**的子用户,用它的 SecretId / SecretKey,
别用主账号的密钥。插件读得到的只有你填的这几个环境变量 —— 它没有数据库、没有 API 令牌、
没有媒体目录(那是隔离边界的一部分)。
