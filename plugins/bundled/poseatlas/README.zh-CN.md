# PoseAtlas

把 [RuiC-PoseAtlas](https://hruiccc.github.io/RuiC-PoseAtlas/) 的两本图鉴接进 Mosael 的**参考库**(资产页的「参考库」页签,ADR 0091):

- **姿势图鉴**:去脸的灰色人台线稿,每个姿势五个机位(正面、斜侧、侧面、俯拍、仰拍);
- **服装图鉴**:没有人体的整身穿搭,按春 / 夏 / 秋 / 冬 / 泳装 / 派对等分类,带颜色、材质、单品标签。

在参考库里浏览、搜索(中文、英文、日文名称和编号都认),点「用这一张」把原图取进工作区成为一份素材;
点「存为资产」会同时建一个姿势 / 服装资产,之后生成时 `@` 它 —— 姿势以「姿势参考」发给模型,只约束体态和构图。

## 出处与许可

- 图片与原始名称、分类出自原作者 [ギア (@giaaibusi)](https://x.com/giaaibusi) 的 POSE-DB-01 / COSTUME-DB-01,
  由 RuiC-PoseAtlas 整理、补英文名称;全部是 AI 生成的虚构参考素材。
- 图片的版权归原作者,**仅供参考与创作使用,禁止再分发、转载或转售图片本身**。
- 这个插件**不带任何一张图**:浏览时显示的是原站的缩略图,取用时从原站下载你选中的那一张,只存在你自己的工作区里。
  取进来的素材记着出处(作者、原站、许可说明),不会进 Mosael 的分享包,也不会被同步到 MosaelCloud。
- 插件代码按仓库的许可证发布。

## 成人内容

原站有「性感」「双人」两个系列(后者包含性爱体位)、上半身里的「性感・大胆」「挤胸」两类,以及服装的「内衣」「性感」两类。
连接配置里的 **「包含成人内容」默认关闭**,关着时这些条目根本不出现;打开后它们会标成 NSFW,
按「预览图」设置模糊或隐藏(和模型库同一个设置)。

## 网络与缓存

- 需要能访问 `hruiccc.github.io`(权限 `network:github`)。
- 两份索引(几百 KB 的 JSON)缓存在插件的持久目录里,一天刷新一次;刷新失败时继续用旧的。
