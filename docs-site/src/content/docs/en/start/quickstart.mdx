<Steps>

1. **Sign in / create a local account**

   On first launch Open Studio asks you to sign in or register a local account (data stays on your machine). You can also switch to a team server.

   <img src={loginShot.src} alt="Open Studio sign-in page" />

2. **Configure model providers (for AI features)**

   Open Settings and use the **AI Chat / AI Image / AI Video / AI Audio** sections to "Add provider", pick a vendor and paste its API key.
   See [Configure model providers](/en/guides/providers/).

3. **Create a project, import or generate media**

   Create a project from Home. Drag local videos into the **Media** library, or ask the agent in **AI Studio** to generate assets from a description.

4. **Edit on the timeline**

   On the **Edit** page, drag media onto tracks; polish the cut with transcript-driven deletions, ripple delete, speed ramps, color grading, subtitles and filters, then export in one click.

   <img src={editorShot.src} alt="Open Studio editor: multi-track timeline" />

5. **Publish in one click (optional)**

   On the **Publish** page, pick signed-in social accounts, set title/description/tags, do a dry run first, then publish for real.
   See [Publishing & account matrix](/en/guides/publishing/).

</Steps>

:::tip[Every AI change goes through a confirmation card]
Whether the agent edits your project or a workflow performs an action, anything that mutates state pops a confirmation card first and only lands after you approve.
:::
