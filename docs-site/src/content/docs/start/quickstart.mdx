---
title: 快速上手
description: 从登录到剪出并发布第一条成片的最短路径。
---

import { Steps } from "@astrojs/starlight/components";

<Steps>

1. **登录 / 创建本地账号**

   首次打开 Mibu 会让你登录或注册一个本地账号(数据都在本机)。也可以切到团队服务器。

2. **配置模型服务商(用到 AI 时)**

   进「设置 → AI 供应商 → 添加供应商」,选服务商、贴 API Key。每个字段旁有「获取 API Key」直达控制台。
   详见[配置模型服务商](/guides/providers/)。

3. **新建项目、导入或生成素材**

   首页新建项目。把本地视频拖进「素材」库;或到「AI 工作台」让智能体按描述生成素材。

4. **在时间线上剪辑**

   「剪辑」页把素材拖到轨道上;用逐字稿删句删词、涟漪删除、变速、调色、字幕滤镜把成片打磨好,一键导出。

5. **一键分发(可选)**

   到「发布」页,选好已登录的社媒账号,配标题/简介/标签,先跑一遍确认无误再正式发布。
   详见[发布与账号矩阵](/guides/publishing/)。

</Steps>

:::tip[所有 AI 变更都先出确认卡]
无论是智能体改工程,还是工作流跑动作,涉及改动的操作都会先弹确认卡,由你批准后才落地。
:::
