插件是一组**纯函数工具**,跑在与代码节点同级的本地信任沙箱里,自动暴露给智能体与工作流。

## 安装与启停

- 「插件」页点「扫描」发现本地插件;每个插件可启用 / 停用。
- 插件的 `manifest` 声明它的工具与所需**权限**;权限逐项授权,未授权的工具不可用。

## 工具与调用记录

- **工具**:插件面板列出每个工具,可就地填参数试跑。
- **调用记录**:最近的调用逐条记录(成功 / 失败 + 输入输出),点击展开;支持**逐条删除**或**清空**。

## 在工作流里用

工作流的「插件工具」节点可选一个已启用插件的工具,把上游变量作为入参传进去。
