Open Studio 的 AI 能力(智能体对话、文生图 / 视频、配音、转写等)都需要你自带各服务商的 API Key。密钥只存本机,后端接口只回显掩码提示,不回传明文。

## 按能力分区配置

设置页把 AI 供应商按**能力**分成四个分区,各自独立配置:

| 分区 | 用途 |
| --- | --- |
| **AI 对话** | 智能体与工作流的 LLM 节点 |
| **AI 绘图** | 文生图(图像生成) |
| **AI 视频** | 文生视频 |
| **AI 音频** | TTS 配音 / 播客合成 |

每个分区顶部是**默认模型**:为该能力选定默认供应商与模型;用到时可在对应界面临时覆盖。

![设置 → AI 绘图:默认模型 + 已配置的供应商列表](../../../assets/screens/settings-models.png)

**按能力配置供应商**——设置里 AI 对话 / 绘图 / 视频 / 音频各自独立,「添加供应商」后前端只渲染该供应商声明的字段,密钥本地保存:

![操作演示:AI 对话与 AI 绘图的供应商配置入口](../../../assets/gifs/providers.gif)

## 添加一个供应商

进对应分区点「**添加供应商**」:

1. 选**服务商**(内置阿里云百炼 DashScope、火山方舟 ARK(视频 / Seedream 图像)、Kimi、MiniMax、OpenAI、Google、快手 Kling、OpenAI 兼容端点等,目录随版本扩充)。
2. 填**名称**(便于区分,如「我的 Kimi」)。
3. 贴 **API Key**。字段旁有「**获取 API Key ↗**」直达该服务商的密钥控制台。
4. **Base URL**:留空即用该服务商默认(占位符会显示默认值);OpenAI 兼容端点需自己填。
5. **默认模型**可选,占位符给了示例。

添加后可随时**启用 / 停用**,不必删。同一个 Key 用在不同能力(如火山的视频与图像),也要在各分区**分别建档案**——互不影响,改一处不牵连另一处。

## 成本规则

设置 → **成本规则** 里可给模型配计价(按 token / 按张 / 按秒),首页与任务中心会按规则累计 AI 费用;没配的用量标「未定价」。

## 绑定关系:哪里没配,哪里会提醒

模型和用到它的地方是**绑定**的。没配好时,用到它的地方会给提醒 + 直达配置入口:

- 工作流的 **LLM 节点 / AI 生成节点**:没有可用供应商、或引用的供应商被删,属性面板顶部会出现琥珀 / 红色提示,点「去配置」直达设置。
- **AI 工作台**的生成:没有任何可用生成模型时,列表顶部同样提示。

> 生成模型目录始终有内置项;能不能真跑取决于**对应服务商的密钥是否配好**。
