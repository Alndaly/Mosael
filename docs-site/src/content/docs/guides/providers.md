Mibu 的 AI 能力(智能体对话、文生图 / 视频、大模型重排等)都需要你自带各服务商的 API Key。数据只存本机。

## 添加一个供应商

**设置 → AI 供应商 → 添加供应商**:

1. 选**服务商**(阿里云 DashScope / 火山方舟 ARK / Kimi Moonshot / MiniMax / OpenAI / OpenAI 兼容端点 / Google / 快手 Kling)。
2. 填**名称**(便于区分,如「我的 Kimi」)。
3. 贴 **API Key**。字段右上角有「**获取 API Key ↗**」直达该服务商的密钥控制台。
4. **Base URL**:留空即用该服务商默认(占位符会显示默认值);OpenAI 兼容端点需自己填。
5. **默认模型**可选,占位符给了示例。

添加后可随时**启用 / 停用**,不必删。

## 绑定关系:哪里没配,哪里会提醒

模型和用到它的地方是**绑定**的。没配好时,用到它的地方会给提醒 + 直达配置入口:

- 工作流的 **LLM 节点 / AI 生成节点**:没有可用服务商、或引用的服务商被删,属性面板顶部会出现琥珀 / 红色提示,点「去配置」直达设置。
- **AI 工作台**的生成:没有任何可用生成模型时,列表顶部同样提示。

> 生成模型目录始终有内置项;能不能真跑取决于**对应服务商的密钥是否配好**。
