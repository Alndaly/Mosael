# ADR 0097 · 关键帧的参考图按先后取;Krea2 关键帧成为官方 ComfyUI 范例

- 状态:**已采纳**(2026-11-10)。做漫剧第一集时维护者说「尽量避免使用 gpt-image-2,可以自行创建必要的 ComfyUI 工作流
  作为官方 ComfyUI 工作流模版,可以使用 krea2、moss image 这种较好的模型」「可以自行修改 ComfyUI 工作流节点」。
- 关联:ADR 0096(整片按说话的角色配音、系列设定)、ADR 0094(画幅)、插件 README「官方工作流范例」。

## 背景

「从主题到完整视频」逐镜画首帧时,把白模帧排第一、全部角色三视图和全部场景设定图一股脑挂上,交给一个「能同时带很多张参考图」
的图像模型 —— 实际上只有付费的(gpt-image-2、Seedream)收得下。本机 5090 上能出好图的 Krea2 编辑**只收两张**(先场景、
后人物),qwen 编辑只收一张:挂多了生成漏斗当场拒(`genErr_tooManySources`)。

实测 Krea2 编辑(`Krea2EditModelPatch` + `Krea2EditGroundedEncode`,identity_edit LoRA):

- 整张三视图交进去,同一个人被画两三遍(提示词里说「同一个人,只画一次」更糟);只截正面那一格就只剩一个人;
- 给场景图时它**保留场景图的构图**,要特写、低角度都不换机位 —— 一场 20 镜全是同一个大全景;
- 只给人物(正面)一张、场景和机位写进文字:机位跟得上分镜,人物长相、服装一致,29 秒一张。

## 决定

### 1. 官方 ComfyUI 范例多两张 Krea2 出图工作流(插件 1.25.0)

- `krea2_keyframe_character.json`「Krea2 关键帧 · 人物三视图 + 文字」:三视图缩到 1536×864、截左边正面那一格 → Krea2 编辑
  (单图)。整片画首帧用它。
- `krea2_keyframe_scene_character.json`「Krea2 · 把人物放进场景图」:场景图 + 人物正面 → 双图编辑,构图跟着场景图。
- 都只用 ComfyUI 内置节点和 Krea2 节点包(去掉了整合流里的 rgthree 种子、文字节点),模型写标准文件名。

### 2. 出图节点:输入素材「按先后保留收得下的」

`ai_generate` 多一格 `source_overflow`:缺省 `error`(超了就拒,不说清先后的调用方丢哪张都是替人做主);`keep_first` =
素材是按先后排的,去掉重复、每个角色只留前面收得下的那几张、模型不收的角色丢掉(`generation.operations.keep_sources_that_fit`,
上限读所选模型的描述符)。张数不写死在模板里 —— 换个收两张 / 十六张的模型都对。

### 3. 整片模板 18 版:首帧的参考图按先后排

- 分镜每镜多两格:`location_name`(这一镜的场景在视觉圣经里的 name)、`first_frame_subject`(首帧里最主要的角色的 name,
  没有人物写空)。逐镜按名字到资产库里认(和「找说话的角色」同一个做法)。
- 首帧:主角三视图 → 地点设定图 → 白模 → 其余三视图与设定图;尾帧:主角 → 首帧 → 地点 → 白模 → 其余。两步都 `keep_first`。
  收两张的模型拿到主角和地点(Krea2 单图版只用第一张),收十六张的照旧全拿。
- 首帧提示词的参考图说明改成按先后写,不再假定「第一张是白模」。

## 后果

- 没有人物的镜头(定场),第一张参考图是地点设定图,单图版会截它的左边三分之一当参考 —— 画出来是同一种气质的空镜,
  构图仍由文字定。要更稳可以给这类镜头换「把人物放进场景图」那张或纯文生图的模型。
- 三视图、设定图那两步和首帧共用一个图像模型:选了只收参考图的 Krea2 关键帧时,新角色画三视图那一步要换成文生图模型
  (Krea2 文生图)。模板目前不分开挑,建图后在那两个节点上换。
- 两个人同框时只带主角一个人的长相,另一个人靠文字;Krea2 编辑最多一场景一人物。

## 补充:分镜、白模两次对话的输出上限(同日,模板 19)

漫剧第一集一场 20 镜,分镜那次对话写到 3.7 万字时被 12000 的输出上限截断,交回半截 JSON(`wfErr_llmNotJson`,
「Unterminated string」),整条运行停在分镜。两次对话的 `max_tokens` 都提到 32000;每镜的提示词本来就长,镜数一多
它就是整条模板最长的输出。
