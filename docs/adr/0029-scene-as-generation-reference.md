# ADR 0029:3D 场景当生成的参考 —— 连进来的是场景,跑的时候现渲

## Status

Proposed — 2026-09-28。待维护者拍板文末「待定」几项后改为 Accepted 再动手。

## Context

画板上的 3D 场景格今天有两种身份,互相打架:

1. **格子上画的**:整个场景的全景白模(后端按修订号现渲,`scenes.scene_overview_image`)。
2. **连到下游时给的**:格子上存着的一张 `asset_id` —— 在场景编辑器里点「生成素材」时导出的某个镜头某一刻的画面
   (`SceneStudio.bridge`),画板把它当成一张普通图片喂给下游(`boardAssetSources` 里 `scene → image`)。

后果:

- **看到的和喂进去的不是一张图。** 格子上是全景,下游拿到的是某个机位的一帧,而那一帧是哪个镜头、哪一秒,画板上看不出。
- **会过期。** 场景在编辑器里改了,导出过的那一帧不会跟着变;要再点一次「生成素材」。
- **只有一种用法。** 一张图只能当 `reference_image`。可 3D 场景真正能给的是:构图和机位、首尾帧、一段运镜、谁站在哪
  —— 整片模板已经在后端这样用它了(`scene_render` 渲首尾帧和运镜参考视频),画板上却用不上。

另外,「按文字搭 3D 场景」现在搭出的是**一个布景 + 人物关键帧 + 几台相机**(`single_set_rules`),
场景里有了会动的人物和多个机位,「从哪个镜头、拿什么」就成了必须说清的事。

## Decision(提议)

### 1. 场景格就是一个场景,不是一张图

- 场景格不再存 `asset_id`。一次迁移把现有场景格上的 `asset_id` 摘掉(那几帧素材还在素材库里,
  也还是当初一起放下的图片 / 视频格)。`boardAssetSources` 不再把场景当图片。
- 场景编辑器的「生成素材」改成:放一格场景 + 一格连好线、预设好「3D 参考」的空图片 / 视频格(见 §2),
  不再先导出一帧。

### 2. 图片 / 视频格上的「3D 参考」:连进来一个场景,挑镜头、挑用法

场景格连进图片或视频格时,那一格的面板多一行「3D 参考」,两项:

- **镜头**(场景里的哪台相机;只有一个镜头时自动选中),视频另可选时间段(默认整镜)。
- **用法**,只列当前模型收得下的那几种(描述符说了算,ADR 0013 的正面证据):

| 用法 | 渲什么 | 交给模型的素材角色 | 图片格 | 视频格 |
| --- | --- | --- | --- | --- |
| 构图参考(默认) | 这个镜头第 0 秒的白模画面 | `reference_image` | ✓ | ✓ |
| 首尾帧 | 这个镜头首、尾两帧白模 | `first_frame` / `last_frame` | — | ✓ |
| 运镜参考 | 这个镜头的运镜白模视频 | `reference_video` | — | ✓(模型收才出现) |

- **跑的时候现渲**,用场景当时的修订号:改了场景,下一次生成就用新的,不用再导出。渲染器就是后端的 `scene_render`
  (和格子上的全景、整片模板同一个)。
- 模型不收参考视频时,「运镜参考」不出现;这时照整片模板的做法,把 `describe_camera_move` 算出的那句运镜描述
  (「镜头从 3 米推近到 1 米」)**并进提示词**,至少把运镜说出来。
- 提示词里附一句固定说明:参考图是白模,只取构图、机位、人物站位和光的方向,不取颜色和材质
  (不说的话,图像模型会把灰方块当成真的灰方块画出来)。

### 3. 人物对得上:场景里的人偶可以指向一个人物资产

- 人偶(`figure`)多一个可选的 `entity_id`,在场景编辑器里从资产库挑(按文字搭场景时,文字里写到的、资产库里有的
  人物自动指上)。
- 渲某个镜头当参考时,**这个镜头里看得见的**人偶,它们指向的人物资产的参考图一并作为 `reference_image` 交出去,
  提示词里写明「红色人偶是小美」。构图由 3D 定,长相由资产定 —— 这是 3D 和资产库合起来才有的一件事。
- 看不看得见按渲染时的视锥算,不是整个场景的人全交:镜头里只有一个人,就只交一个人的脸。

### 4. 不做的

- 深度图 / 线稿 / 姿态这类 ControlNet 控制图:要等有模型在描述符里声明收它们(新的素材角色)再加一种用法;
  格子和数据形状不用变。
- 在画板格子里嵌一个能转的 3D 视口:格子只画全景白模;要转、要改去编辑器。

## 分步落地

1. 场景格去掉 `asset_id`(迁移)、`boardAssetSources` 不再把场景当图片、编辑器「生成素材」改成放连好线的空格子。
2. 图片 / 视频格的「3D 参考」一行:镜头、用法,跑的时候现渲;提示词里的白模说明和运镜描述。
3. 人偶指向人物资产;渲参考时按视锥带上看得见的人物参考图。

## 待定

- 「构图参考」要不要**同时**带一张去掉背景色的剪影(人物和主要体块的轮廓),给不太听参考图的模型多一分约束?
- 按文字搭场景时自动把人偶指向资产库里的同名人物 —— 同名不止一个时是挑第一个,还是留空让人自己挑?
- 视频格的「时间段」第一步就做,还是先只做整镜?
