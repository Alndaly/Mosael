# 0113 工作台把「模型资源」和「节点上下文」拆成两个页签

- 状态：已采纳
- 日期：2026-11-27
- 相关：ADR 0038（ComfyUI 工作台）、ADR 0034（模型库）、`frontend/src/features/plugins/workbench/`

## 背景

工作台原来的「模型库」页签同时承担两件事：

- 没有选中节点时，它只显示「在画布上选中一个加载模型的节点」，模型库的搜索、来源、详情和下载都用不了；
- 选中节点后，它又只列出当前 slot 的目录，模型库退化成节点属性面板。

这让「node 是模型库的前置条件」成为隐式契约。插件桥没有选到节点、或用户只是想找/下载一个模型时，右侧整列没有可用入口；下载目标也只能由当前 slot 推断，容易把文件放到错误目录。

## 决定

### 1. 两个页签，各自只有一个职责

`TABS` 为：

```text
模型 | 节点 | 工作流 | 缺失 | 应用 | 运行 | 助手
```

- **「模型」**：全局模型资源。已安装模型按目录浏览，按名字 / 标题 / 触发词搜索；不依赖 `selection.node`。搜索、候选解析、来源筛选和下载交给 `ModelLibraryDialog`，不复制一套候选页面。
- **「节点」**：节点上下文。和 AI Studio 右栏「引擎参数」同一套 InspectorCard / ParameterSection / ParameterField 排成可编辑表单；数字、文本失焦提交，下拉和开关立即经桥写回。模型槽仍用下面的 SlotPicker。插件没认出目录的自定义节点也能直接改参数。

### 2. 依赖方向

```text
ComfyWorkbench
  ├─ ModelsPanel  ── useModelLibrary ── ModelLibraryDialog
  └─ NodePanel    ── workbenchCall + modelSlots
```

`ModelsPanel` 不再接收 `node`；`NodePanel` 不承担全局模型浏览。两者只共享模型数据与底层卡片/缩略图组件，不共享「哪个 tab 应该显示什么」的判断。

`ModelLibraryDialog` 的 `instance` 参数收窄为 `Pick<PluginInstance, "id" | "name">`：工作台只需要连接身份，不需要整个插件实例；这避免了工作台为了打开模型库而伪造实例字段。

### 3. 列内只放工具条,页签只放图标

工作台右栏的空间属于画布，不属于面板自己：

- 「模型」不画页内大标题/说明，和「工作流」一样是**一行工具条**(搜索 + 预览设置 + 下载)；已安装模型搜索和在线平台搜索分开：前者是输入框，后者是明确的「搜索并下载」入口，打开模型库的下载弹窗(HuggingFace / ModelScope / Civitai)；
- 模型卡按 3:4 封面 + 名称/目录/大小排，`w-full` 撑满网格列；封面上的 NSFW / 来源角标和模糊悬停看清沿用模型库，`group/thumb` 让 NSFW 模糊能悬停解锁；
- 外间距只由 `TAB_PANEL` 的 `p-3` 提供，面板根不再叠一层 `p-3`；
- 右栏页签一律只放图标，名字进 `aria-label` / 悬停说明；数字徽标保留，避免为了塞下名字在「选中才显示文字」和「折行」之间摇摆；
- 顶栏动作只放图标、去掉描边；运行是蓝色实心箭头(可运行时)，不另加文字或底板。

### 4. 默认页签与状态

默认进入「节点」，保留原来的使用路径；「模型」是新增的独立入口。没有选中节点时，「模型」照常列出全部已安装模型；选中节点时，「节点」页签显示该节点的槽位。两个页签的通知/数量互不冒充。

## 后果

- 模型库不再被节点选择阻塞；下载入口不再要求先选中一个 slot。
- 节点页签可以继续扩展为检查器（widgets、连接、运行状态），而不用继续往模型库塞节点信息。
- 全局模型页签与模型库页面共享 `ModelLibraryDialog`，避免两套搜索/下载逻辑漂移；如果未来要内嵌成非弹窗布局，应先抽出 `ModelLibraryPanel`，而不是复制候选页面。
- 旧的持久化页签值 `models` 会落到全局模型页签；这是预期的语义变化，不需要迁移。

## 验证

- `ComfyWorkbench.dom.test.tsx`：默认节点页签、模型页签在无选中节点时列出跨目录模型并搜索。
- `ModelsPanelDetail.dom.test.tsx`：节点页签的目录筛选、填值、缺失下载行为保持不变。
