# 0109 插件工具上不上画板由声明说;挂在哪种格子只按声明的素材种类;ComfyUI 工作流要勾「在画板上用」

- 状态：已采纳
- 日期：2026-11-24
- 修订：ADR 0021「修订:画板上只放内容变换」里「插件工具不用声明,按它清单里 `node` 块声明的输出判」那一句
- 相关：ADR 0025（能力住在内容格上）、ADR 0045（表单是工作流的入口）、`boards/transforms.py`

## 背景

维护者：「关于 ComfyUI 工作流变成节点能力这个的判断机制,感觉设计的不太合理」。现状有两处不合理:

1. **全自动上板。** 插件报出的每个工具只要过得了「内容变换」那几条规矩就自动上画板。ComfyUI 每张工作流就是一个工具,
   吃图片的成了每个图片格操作条上的一项(「工作流 · clip_generate_text」),工作流一多操作条就挤,而很多工作流本来
   就不是给画板用的 —— 用不用在画板上,是这张工作流的主人的选择,不是规矩能推出来的。
2. **说不清的三种格子都挂。** 生成器(空格子的填法)挂在哪种格子上看它产出什么;没声明产出哪种素材(`output_media`)
   的按「一份素材」处理,图片、视频、音频三种空格子都挂 —— 空图片格上能选「Manim 自定义动画」,跑出来是一段视频。
   能力那一边同理:收素材的字段没声明 `x-media` 的,三种格子都挂。ComfyUI 插件明明知道读图节点读的是图、
   `SaveImage` 交回的是图,却两样都没写。

## 决定

### 1. 上不上画板由声明说 —— 插件工具和内置节点同一条

插件工具在 `node` 块里写 `"surfaces": ["workflow", "board"]` 才上画板,和内置节点的 `NODE_TYPES[…]["surfaces"]` 同一个键、
同一个意思。没写的只在工作流和智能体里。声明了的照旧要过「内容变换」那几条规矩(`transforms.content_transform_gap`),
过不了的不上(工具在画板上跑时说清楚为什么)。

### 2. 挂在哪种格子只按声明的素材种类

- 生成器(`slot`):挂在它**声明产出**的那几种素材的空格子上(`output_media`)。只说「一份素材」(`asset`)的不上板 ——
  不再按三种媒体格兜底;
- 能力(`ability`):宿主字段收什么就挂什么格子。收素材的字段要声明 `x-media`(内置节点是 `media`);没声明的不当宿主
  (它照样能从上游接,只是这一格不会因为它出现在哪种格子的操作条上)。文字、3D 场景、资产这几种字段本来就说得清。

### 3. ComfyUI:工作流上一个「在画板上用」的标记,插件按它声明

- 存在**工作流文件自己的** `extra.mosael.board`(布尔,缺省没有 = 不上板),和表单、「结果取自」同一处(app_form)——
  跟着文件走,换机器、换连接都还在。存储格式还是第 2 版:这是一个可选的新键,旧插件读到不认识的键不读也不写坏它
  (`apply` 只改它管的那几处)。
- 插件生成工具时,标了「在画板上用」的工作流:有表单的,它的**每张表单**入口声明上板(完整工作流入口不上 —— 和它不进
  智能体工具表同一条,ADR 0045);没有表单的,完整入口上板。
- 插件顺手把说得清的写上:读素材的节点按节点类型写 `x-media`(LoadImage 是图、读视频的是视频、读音频的是音频,
  读蒙版的是图),每个输出节点按它交回什么写 `output_media`(保存 / 预览图片是图……)。
- 工作流库里每张工作流的详情面板上一节「在画板上用」(和「表单」「用到的模型」并列 —— 它说的是整张工作流,不放进表单编辑器:
  没有表单的工作流在那里找不到它)。写回和「一键去掉」同一个做法:先读一遍这张的标记、只改 `board` 这一格、整份走现成的
  `annotate` 写回(表单、结果标记原样);改的是那台服务器上的文件,先确认。API 格式的图放不了标记,读到时说清楚。

### 4. 画布上存着的、此刻不再上板的

按名字存着的设置照存(ADR 0025:能力设置只认名字);跑的时候 `get_producer` 说清楚「这张工作流没开『在画板上用』——
到工作流库里勾上」。不写迁移去替用户勾 —— 勾不勾正是这次交给人的那件事,而且标记在 ComfyUI 那台机器上的文件里,宿主
写不了别人的文件。

## 后果

- 升级后画板上原来自动出现的 ComfyUI 工作流能力和生成器都不在了,要用的去工作流库勾上。会出图的工作流照旧在「生成」的
  模型下拉里(那是生成目录,不是画板工具),最常用的那条路不受影响。
- 随应用发的示例插件(Manim、Remotion 等)要在清单里写 `surfaces` 和 `output_media` 才在画板上出现,版本号随之升。
- 第三方插件作者:清单规范(docs/PLUGIN_MANIFEST.md)写明这两个键。
