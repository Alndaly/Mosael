# ADR 0082 · 项目入口只有一个:剪辑页的两个状态

- 状态：**Accepted** — 2026-10-25
- 相关：ADR 0060（智能体不再带用户跳页）、`contracts/studio-views.json`、`frontend/src/app/pages.tsx`

## 要解决什么

「工作台」(`home`)和「剪辑」(`editor`)曾经是两个平级 tab，共享同一个 `projectId`，却各有一套进入规则：

- 在首页新建项目 → 留在首页并高亮；在顶栏切换器新建 → 直接进剪辑；
- 点侧栏「剪辑」而没有选中项目 → `App` 静默落到项目列表的**第一个**；
- 项目被删掉 → 编辑器静默换成另一个项目；
- 剪辑页无项目时的空态和首页的空态各有一个「新建项目」，行为还不一样。

这不是两个页面该不该合并的问题，而是**同一个项目状态有三处入口、两种行为、一个静默兜底**。

## 决定

1. **只保留「剪辑」一个项目入口。** `home` 从 `StudioView` / 导航 / `contracts/studio-views.json` /
   深链白名单里删除。
2. **剪辑页有两个状态**：没有选中项目时渲染项目浏览器（原 `HomeView`），选中后渲染编辑器。
   项目浏览器静态导入（首屏），编辑器仍懒加载。
3. **侧栏只换页，不清状态；顶栏面包屑里的「剪辑」才是回项目列表。**
   项目 id 在 hash 的 `p` 里，所以从别的 tab 回到剪辑仍是刚才那条时间线；面包屑点「剪辑」才清掉
   `projectId`、回到项目列表。旧地址 `#/home` 没有保留任何旧逻辑 —— 它只是不再被识别，
   按默认页落到项目浏览器。
4. **新建项目只有一个行为**：建完直接打开它。Home 的命名弹窗仍保留，但提交走
   `App` 的同一个 `createProject`，不再「留在原地高亮」。
5. **不再兜到第一个项目**。`projectId` 指向一个已不存在的项目时，清掉它、回到项目列表并说明一句；
   没有 `projectId` 时就是项目列表。
6. **剪辑页的项目切换器只负责切换项目和新建**；回项目列表走顶栏面包屑，不再额外放「全部项目」。
   没有选中项目时 header 仍是「剪辑」，不改成「项目」。

## 后果

- `#/home` 没有独立页面，也没有旧逻辑兼容分支；`mosael://open?join=…` 落到 `editor`。
- 第一屏仍然是项目列表，且没有把 `mp4box` / 时间线 / dnd-kit 拖进主包（`pageChunks.test.ts` 的 eager 例外仍是项目浏览器）。
- 「工作台」这个词不再指首页；它继续指 AI Studio / ComfyUI / 3D 场景各自的内部工作台。
- 项目删除、工作区切换、统计页「项目」磁贴都统一落到项目列表，不再出现「点进去是另一个项目」。
- AI Studio 在侧栏移到「剪辑」上方，并在它前面用 `dividerBefore` 画一条与既有分组线同款的线。
