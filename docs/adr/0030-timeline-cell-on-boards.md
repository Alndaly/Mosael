# ADR 0030:画板上的时间线格 —— 在画布里直接把几段片子拼成一条

## Status

Accepted — 2026-09-28。维护者拍板:

- **每张画板自动建一个同名项目**,这张画板上的时间线格都放进去(画板记着它的项目,改名不丢)。
- **先做时间线格**,数字人的可灵 / HeyGen / Hedra 放在它之后。
- 连线进来的音频格放进音频轨。

## Context

用户:「无限画布缺少时间线节点,有时候我会希望直接在无限画布内处理时间线,比如拼凑视频之类,适当参考一下 TapNow。」

今天在画板上生成了几段视频,要拼成一条得离开画板:去剪辑页建项目、建时间线、从素材库一段段拖进去、导出,再回来。
画板上的「生成 → 视频 → 下一镜」本来就是一条线性的故事,最后一步却要换一个地方做。

TapNow 的做法(用户给的截图):画布上一格视频编辑器 —— 上面是预览(播放、当前时间 / 总长、静音、全屏),下面一条
缩略图时间条(每段一张缩略图,末尾一个「+」加一段),左边两个按钮:剪刀(在播放头处切开)和下载(导出)。

Mosael 已经有完整的剪辑(时间线、变换、调色、字幕、配音、导出渲染),缺的只是**画板上的一个入口**。

## Decision(提议)

### 1. 时间线格就是一条 Mosael 时间线,不是画板自己的一份片段清单

- 新的格子种类 `sequence`,存 `sequence_id` —— 和 3D 场景格存 `scene_id` 同一个形状。格子里做的每一步都是那条时间线上的
  正常操作(插入、移动、切开、删除,见 domain/sequences),所以撤销、导出、智能体的 `edit_timeline`、在剪辑页里接着精修
  都是现成的,不另起一套。
- 操作条上「在剪辑里打开」直接进剪辑页;画板上只做粗剪(拼、排、切、删、导出)。

### 2. 格子长什么样(参考 TapNow)

- **上半:预览。** 按时间线顺序连着播画面(视频按截取段播,图片按时长停),显示「当前 / 总长」,静音、全屏。
  **它是粗剪预览,不是成片渲染**:变换、调色、字幕、花字在剪辑页和导出里才完整;格子上写明这一点,不假装一致。
  (剪辑页的监视器绑着全局的剪辑状态,一张画板上可能有好几格时间线,所以不直接搬它。)
- **下半:缩略图条。** 主视频轨的每一段一张缩略图、宽度按时长;播放头可拖;段可拖动换顺序;末尾「+」加一段。
- **按钮在格子上方的操作条里**(用户:「这些按钮放到上方弹窗中去」):剪刀(在播放头处把那一段切开)、删除选中的一段、
  在剪辑里打开;导出见 §4。选中一段按 Delete 也能删。
- **拖动用 @dnd-kit/sortable**(和资产参考图墙同一个库),不自己写指针拖动:格子在画布里是缩放过的,库量的是屏幕像素,
  段的位移按开拖时量到的缩放折回。条上不给文本光标;播放头两侧留抓取区,按住左右拖。
- **格子里的每一步都在画板的撤销里。** 画板的撤销栈存的是画布快照,剪、删、排、加片段改的是服务端的时间线:它们在栈里记成
  「时间线的一步」,撤到它时画布不动、调那条时间线自己的撤销(`POST /api/sequences/{id}/undo`),⌘Z 按用户做的先后退。

### 3. 片子怎么进来

- **连线就是「加进来」**:把一格视频 / 图片 / 音频连进时间线格,它的素材接到时间线末尾(视频、图片进主视频轨,音频进
  音频轨)。和资产格连进生成格就等于 `@` 同一个直觉:线在它就在 —— 断开连线**不**从时间线上删(时间线上的片段已经被
  排过、切过,自动删会丢掉这些手工)。
- **「+」**:从这张画板上已有的图片 / 视频格里挑,或从素材库挑。落地:缩略图条末尾一枚「+」,打开画板的素材选择器,
  头里多一枚「这张画板上的」(打开时先按它筛,点掉就是整个素材库)。挑中的和连线进来走同一个接口、同样记进画板的撤销。
- 格子自己生成出来的东西不进时间线(它不是生成格)。

### 4. 导出

- 「导出」起一次正常的导出任务(`start_export`,带「AI 生成」标识的开关,同剪辑页),导出的成片落成**右边一格视频**
  (和 3D 场景格渲白模的产出同一种落法)。
- 落地:时间线格挂内置产出者 `sequence_export`(新放下的时间线格就挂它;已有的由迁移
  `migrate-board-sequence-cells-name-their-producer` 补上),跑的是工作流节点 `export_sequence` 的同一个执行器,宿主给
  时间线(`host_input = ("sequence_id", "sequence")`),和渲白模同一条路(`board_run` 任务、能停、产出派生在右边)。
  节点因此多了 `resolution` / `quality` / `ai_label` 三个字段,取值和剪辑页导出对话框同一张表(`domain/export_presets`)。
- 导出面板**按需打开**:操作条上的「导出」(和「让 AI 写」同一种按需面板,面板名就是产出者名)。选中时间线格多半是要
  剪、要排,每次选中都弹面板会挡着缩略图条。在跑时格子上方一条状态,预览和条照常能用 —— 导出按起跑那一刻的时间线渲。

### 5. 新建

- 「添加 → 新建 → 时间线」放一格空的时间线格;画幅(横 / 竖 / 方)在第一次加片子时跟着第一段定,也可在格子上改。
- 时间线必须属于一个项目(`sequences.project_id` 非空):每张画板第一次放时间线格时建一个同名项目,记在画板上
  (`boards.project_id`),之后这张画板的时间线格都放进去。

## 分步落地

1. 格子种类、建时间线、连线加片段、缩略图条(排序、删除、剪刀)、粗剪预览、在剪辑里打开、画板撤销。**已完成**(2026-09-28)。
2. 导出落成右边一格;「+」挑素材。**已完成**(2026-09-28)。
3. 智能体:`edit_board` 认识时间线格。**已完成**(2026-09-28):`add_item` 不带 `sequence_id` = 新建一条(批准之后才建,
   干跑时它不过引用那一道;boards.timelines.create_pending_sequences),带着就引用已有的;`connect` 进时间线格 = 接到
   末尾,和界面拉线同一件事(append_connected_media,只接新连上的、有素材的);导出照渲白模那样 set_form + run_board_item。
   get_board / list_board_producers / 系统提示都写明了。前端时间线格的缓存挂在 `sequences` 底下,确认卡执行后跟着刷新。
