# ADR 0098 · 智能体做得了一部连续剧:从模板建流、并行跑、看进度、续跑、配嗓子

- 状态:**已采纳**(2026-11-10)。维护者在漫剧第一集做到一半时问「直接使用 Mosael 内的智能体能做到上述所有能力吗」,
  答复是缺五样,随即要求「从官方模板新建工作流、接续中断的运行、为人物资产配嗓子、并行运行、盯进度,这些都应该给
  Mosael 里的智能体补充上」。
- 关联:ADR 0092(从中断处继续)、ADR 0096(按说话的角色配音、系列设定模板)、ADR 0040(技能)。

## 背景

一集漫剧是:系列设定(一次)→ 几场「从主题到完整视频」并行跑几个小时 → 中途有失败的接着跑 → 接成一集。
这些在界面上都点得到,智能体却:

- 只能 `create_workflow` 手写整张图,用不了模板库里的官方模板;
- `run_workflow` 一张卡跑一次,几场要开几张卡;
- 看进度只有 `get_job` 的一个状态和进度数,看不到分镜写好没有、第几镜失败、为什么;
- 中断 / 失败的运行接不上(只能重跑,前面付过钱的步骤再付一遍);
- 改不了人物资产的嗓子(`create_entity` / `attach_entity_reference` 都不碰 `voice`)。

## 决定

都是界面已有的那条路,智能体经确认卡 / 只读工具走同一条:

| 工具 | 做什么 | 走的路 |
|---|---|---|
| `list_workflow_templates`(只读) | 官方模板的 id、说明、要备什么 | `templates.TEMPLATE_CATALOG` |
| `create_workflow` 多 `template_id` | 从官方模板建 | `templates.built_in_template_graph`,**开卡时造好钉进卡里**:卡上审的就是落库的那张;模板和手写图只能二选一 |
| `run_workflow` 多 `runs` | 一张卡并行起几次运行,各带一组开始参数(最多 8 次) | 每次照旧 `check_runnable` + `start_workflow_job`;交回 `job_ids` |
| `get_workflow_run`(只读) | 状态、做完 / 还剩的顶层步骤、子任务按种类与状态计数、最近失败原因、花费、能不能接着跑 | `workflows.run_progress`(读 `workflow_run_steps` 与子任务树、`run_costs`) |
| `continue_workflow_run`(确认卡,ai-cost) | 失败 / 中断 / 取消的运行从中断处接着跑 | `engine.continue_run`,和运行历史里点「从中断处继续」同一条;点头的人认可这次运行钉住的那一版 |
| `set_entity_voice`(直接改) | 给人物配 / 清嗓子 | `engine_catalog.voice_choice` + 资产库存时的 `check_voice` |

外加内置技能 `episodic-series`(「做连续剧」):系列设定 → 按场并行出片 → 盯进度、断了接着跑,系统提示里一句指向它。

新工具都在 `canvas` 那一份(工作台以外哪儿都发);`list_workflow_templates` 也在,不进每一轮都发的通用那份。

## 后果

- 一张卡起 8 次运行是上限:每次都是一整条可能付费的流程,批太多批的人看不清自己批了什么。
- 「盯进度」不替智能体定时轮询:它隔一阵自己调一次 `get_workflow_run`(说明里写了别连着刷);长任务的完成回执照旧发回对话。
- 进度里的「步骤」只看顶层;循环里第几镜在做,看子任务计数(出图、出视频各几个成功 / 在跑 / 失败)。
