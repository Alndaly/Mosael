离线字体使用现有 Inter Variable，中文回退苹方、微软雅黑及系统无衬线；时间码保留等宽字体。旧字体资源仍可供用户自定义样式使用。

- 标准导航宽 224px，收起后 64px；窗口窄于 1200px 时默认收起，手动选择会保存。较矮窗口减少导航行高与间隔，内容区域可独立滚动。
- 上下文栏高 56px，保留 macOS 拖动区和 Windows 系统按钮空间。内嵌发布视图独立的 44px 协议高度没有改变。
- 普通页面使用 20–40px 留白，剪辑与节点画布保留可调整的密集工作面。
- 操作控件采用 6–8px 圆角；菜单 12px，弹窗 16px。头像、状态圆点、播放键等仍采用适合自身语义的形状。
- 共享弹窗保持固定头尾、主体滚动；菜单与弹窗默认实底，轻阴影表达层次。自定义背景、透明度、模糊和 CSS 功能继续可用。
- 选中标签使用下划线或浅蓝底；焦点使用清晰的蓝色边界。浅深主题主文字、辅助文字和主要状态组合均有对比度回归检查。
