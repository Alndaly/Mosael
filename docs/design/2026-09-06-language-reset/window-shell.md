# 顶栏与侧栏重整 · 2026-09-06

本轮处理侧栏收起后工作区按钮像多层方框，以及 macOS 普通窗口系统按钮偏离顶栏中心的问题。

## 结构与交互

侧栏以工作区为起点，取消独立的大尺寸品牌占位。展开时显示工作区图标、名称和切换提示；收起时使用单层正方形按钮，图标居中。展开菜单向下打开，收起菜单向右打开；搜索、切换、新建、重命名、删除和原有权限判断均保留。

顶栏负责当前位置、项目切换和全局操作，取消重复的工作区面包屑。收起按钮与搜索框统一为 36px 高。项目长名称可收缩，右侧操作区不被挤压；原有导航、用户菜单、设置及页面功能保留。

## 原因与修复

旧的紧凑工作区入口实测为 39×50px，外层底色和内层 32px 图标底板叠加，垂直留白也不对称。修改后入口为 39×39px，20px 图标中心与按钮中心偏差为零。

应用顶栏此前已是 56px，但 macOS 红绿灯仍使用 y=15，Windows 原生覆盖栏仍是 44px。现在原生窗口、应用、内嵌浏览器与素材对比顶栏统一为 56px；macOS 的 12px 按钮按中心线计算 y=22。跨运行时常量检查覆盖前端、桌面窗口和内嵌视图。

普通 macOS 窗口左侧预留 88px，全屏后恢复普通页面边距，退出全屏重新预留。Windows 布局保留右侧系统按钮区域。

## 验证

- 隔离的真实 Electron 窗口：检查展开/收起侧栏、普通窗口/全屏及退出全屏；使用原生截图核对系统按钮中心。
- 浏览器：检查深色工作区弹层，以及 980×640 英文浅色窗口的长标题、侧栏滚动与顶栏操作边界。Windows 部分验证的是布局模拟，没有运行 Windows 原生窗口。
- 新增交互测试：展开与收起状态均可搜索和切换工作区；新建入口可达，所有者与只读成员的管理权限保持原逻辑。
- 前端全量测试 184 个文件、1055 项通过；生产构建、桌面端类型检查、共享常量检查 4 项、原生脚本语法和文档规则检查通过。构建仍有已有的大体积分包提示。

原生按钮位置在窗口创建时应用，现有桌面窗口需要重启应用才能看到变化。验证使用独立测试窗口，没有重启用户正在使用的应用。
