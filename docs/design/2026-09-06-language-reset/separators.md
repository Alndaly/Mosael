# 分割线层级

内容分隔统一使用 `divider`：浅色 `#e8ecf2`，深色 `#292d33`，保留 1px 线宽。输入框、按钮和可交互容器继续使用各自的边界与焦点颜色。

- 首页取消筛选栏底边、列表首尾边界和逐行横线。项目按留白排列，悬停与键盘焦点落在行内时显示柔和底色。空列表不产生边线或空白占位。
- 设置组标题不再附带横线；组内条目和组间分隔使用淡色线条。插件连接设置复用同一规则。
- 素材、发布记录、任务和通知列表采用淡色条目分隔。发布列表去掉首尾封口线。
- 全局侧栏、会话面板及任务/插件两栏结构采用相同的淡色分隔；保留必要的容器边界和操作状态。

实际验证：首页全部项目/最近编辑、深色插件页、浅色设置页，以及 820px 窄窗口。确认首页行边界为 0px，设置标题底边为 0px，设置条目间为 1px divider 色。186 个测试文件、1060 项测试通过；生产构建通过。
