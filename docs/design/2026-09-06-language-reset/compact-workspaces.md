# 操作页面的紧凑顶部

AI Studio 和设置页由全局导航标识当前页面，不再重复显示大标题区。

- AI Studio 的对话/生成切换并入当前会话工具栏，保留当前会话名、对话/轨迹切换、工作环境、引擎参数与子智能体入口。模式切换不占用输入框空间。
- 会话索引和内容工具栏采用 56px 高度；长会话名截断，空间不足时允许工具栏换行。820px 及以下为会话列表浮层入口留出位置。
- 设置页直接展示分类、搜索与当前设置章节，保持原有导航和设置能力。
- 工作流编辑器、无限画布和剪辑器继续直接展示编辑界面。首页与集合概览页保留承载数量和主要操作的页面标题，不全局缩小所有页面。

验证：1280×800 深色中文和浅色英文、820×900 窄窗口；对话/生成、对话/轨迹、工作环境、生成参数、会话列表浮层及设置分类切换。前端 186 个测试文件、1060 项测试通过；生产构建通过。
