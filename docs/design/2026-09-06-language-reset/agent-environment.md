# 智能体环境侧栏

智能体环境作为对话旁的信息栏，沿用页面的中性表面色、字阶和边界色。移除独立关闭按钮，统一由对话工具栏的「工作环境」开关控制。

- 宽窗口中，侧栏标题与对话工具栏等高，默认 56px；标题 14px、半粗，状态采用轻量文字与状态点。
- 标题固定，内容独立滚动。信息组之间留 24px，移除每组底部分隔线；只保留标题下方及侧栏边缘的细线。
- 最近工具行至少 32px 高，保留参数、结果展开及全部工具入口。概览、任务计划、子代理和运行状态继续按原条件呈现。
- 1180px 及以下从工具栏下缘展开，无阴影；根据工具栏实际高度定位，避免遮住唯一开关。开关声明展开状态和受控面板关系。

验收使用独立测试服务中的模拟会话，未执行模型或工具调用：

- 1280×800 暗色：两个标题均从 y=56 开始，高 56px；内容与侧栏撑至窗口底部，没有重复关闭按钮。
- 820×500 浅色：展开工具长参数后，正文可滚动，标题保持固定；无横向溢出，原开关可正常关闭。
- 600×600：侧栏顶部等于工具栏底部，开关可点击，无横向溢出。
- 全部 1060 项前端测试及生产构建通过。
