# 3D 场景与镜头

当前开发分支新增的工作区能力，尚未包含在已发布的 1.0.0 安装包中。

从侧栏「3D 场景」进入，可以新建空场景，或打开「三间展厅」示例。
场景、对象和镜头独立保存；建模助手沿用用户选择的对话模型，视频生成时再选择对应的视频模型，不绑定 Astra。

界面分成「搭建场景 → 设计镜头 → 生成素材」三个步骤。可以随时切换步骤，场景数据会保留。
常用操作有文字标签；右上角「操作说明」列出当前设备的操作方式，「视角」可以切换整体、正面和俯视。
顶栏提供「工作台全屏」，保留编辑面板；画面工具栏提供「视图全屏」，只保留画面、视角与播放控制。可再次点击退出或按 Esc；环境不允许系统全屏时仍可铺满应用窗口。全屏中下拉菜单可用，退出会恢复原布局与相机状态。

## 触控板与鼠标

默认使用触控板模式：双指滑动平移，捏合缩放，Shift + 双指滑动环绕观察；按住触控板拖动也可以环绕。视图工具栏显示当前设备的图标按钮，点击即可在触控板和鼠标之间切换，悬停可查看当前模式和切换提示；鼠标模式支持左键环绕、右键平移、滚轮缩放。「操作说明」只展示当前模式的手势说明。

工作流（含子图）和无限画布的工具栏也提供同一入口：触控板双指滑动平移、捏合缩放；鼠标滚轮缩放。三个页面共用并记忆设备选择，切换不会重置当前视角。

手势只作用于 3D 画面，全屏时同样可用。镜头画面保持只读；需要调整构图时切回「编辑视角」，观察摄像机动线时切换「全局动线」。连续捏合有远近限制，不会缩放整个应用。

## 搭建与编辑

- 基础对象：立方体、球体、圆柱、地面、房间、楼梯、人物、桌子、组、点光源和**机位**。机位是场景里的物体——可以在画面中选中、拖动、编组，也可以有多台；镜头只记「用哪台机位、拍多久」，运镜是那台机位的时间轨。机位模型只在编辑视角可见，不会出现在镜头画面和导出的参考帧里。
- 房间包含地面和四面墙，前后各有一个居中的门洞，没有顶板；可调整宽高深和门洞尺寸。楼梯沿局部 +Z 方向升高。
- **走位**：任何物体都可以随时间移动。把它摆到位，在时间条上选一个时刻，点检查器里的「记录此刻」；换个时刻再挪一下，它就会在两点之间走过去。第一次记会连同当前的静止姿态一起记成 0 秒那一档，否则播放时会从静止位置突然跳过去。清除走位后它回到静止——**有没有轨正好等于动不动**。走位会出现在导出的参考帧和参考视频里，那正是交给视频模型最有价值的运动条件。
- 对象支持移动、旋转、缩放、复制、隐藏、删除、编组；检查器里的「所属组」可以把它移进已有的组或移回顶层（不能移进自己的后代——那会形成环）。复制组会复制其后代并生成新 ID。删除组同时删除后代。
- 拖动三维操纵器，或在右侧输入精确数字。位置、尺寸以米为单位，旋转以度为单位。吸附为 0.25 米、15 度及 0.1 缩放步长。
- 几何体可调颜色、粗糙度和金属度；点光源可调颜色和强度。GLB/glTF 模型保留原始材质。
- 导入自包含的 GLB 2.0 或内嵌资源的 glTF 2.0，GLB 不超过 512 MB；内嵌资源的 glTF 不超过 100 MB —— 后者是一整份 JSON、校验必须整份解析，而 GLB 只需读文件头和前面那段 JSON。节点 5000、网格 2000 是实时编辑的上限，超出会明确说明超了多少。不读取模型中引用的外部网址或本地文件。支持 Draco、KTX2(Basis) 和 meshopt 压缩——导出时把压缩打开，同一个场景通常能小好几倍，也就更不容易撞上体积上限。
- 添加的几何体默认放在已有场景旁边，避免重叠；点击对象列表会聚焦该物体。精确位置、旋转和缩放在「精确位置与旋转」中。
- 左键拖动观察、右键平移、滚轮缩放；按 F 聚焦选中对象。工具条和 ⌘/Ctrl+Z、⌘/Ctrl+Shift+Z 支持撤销、重做。

这里提供参数化场景搭建和模型组合，不包含雕刻、布尔建模、骨骼动画编辑或物理模拟。导入的模型作为一个对象操作。

## 设计镜头

画面工具栏提供三种观察方式：

- **编辑视角**：环绕、平移和缩放，找到构图后记录为镜头关键帧。
- **镜头画面**：按照所选镜头的画面比例，查看当前时间的实际取景。
- **全局动线**：独立观察整个场景和金色轨迹，蓝色摄像机随播放或拖动时间轴移动，虚线指向取景中心。右下角同步显示镜头画面，点击小窗可放大为镜头视图。

全局观察支持触控板、鼠标以及整体、正面、俯视切换；F 可重新框入完整动线。它不会修改编辑视角或保存的镜头，来回切换会保留观察角度。播放过程中切换视图不暂停、不重置进度。辅助动线和摄像机标记只在全局观察中显示，不会出现在导出素材中。

时间轴统一放在画面下方，在「设计镜头」「生成素材」和视图全屏中都可使用。右侧参数独立滚动，「下一步」固定在参数区底部。

1. 进入「设计镜头」，在编辑视角中找到构图。
2. 选择「围绕主体」「缓缓推进」或「固定镜头」，基于当前构图创建运镜；全局模式保留动线观察，其他模式切到镜头画面。选择会替换当前镜头轨迹，可撤销。
3. 调整时长和画面比例，点击「播放镜头」预览。
4. 如需手动运镜，展开「自己设置起点和终点」；在编辑视角中分别记录两个构图。在镜头画面中，可用「从当前镜头继续调整」复制当前相机到编辑视角。
5. 底部时间条可以选择中间时刻，再点击「记录此视角」增加途经点。
6. FOV、相机坐标、速度插值等细项在「镜头高级设置」中。
7. 进入「生成素材」，选择当前画面生成图片，或以首尾帧、运镜视频生成视频；也可仅保存预览素材。

每个场景最多 500 个对象、32 个镜头；每个镜头最多 100 个关键帧、120 秒。
插值不自动避障，路径经过墙壁或物体时需调整关键帧。组层级不超过 16 层。

## 导出和视频生成

- **GLB**：导出当前可见几何体和材质；镜头路径保存在场景描述中，不会烘焙进 GLB。
- **JSON**：导出场景描述，保留对象参数、组关系和镜头。模型 ID 指向本场景存储的文件，JSON 本身不打包这些文件。
- **当前镜头画面**：按拍摄相机导出 PNG 到素材库，独立于当前观察视角。
- **镜头预览视频**：优先使用 WebCodecs 逐帧编码 H.264 MP4，30 fps，横屏 1280×720、竖屏 720×1280、方形 1280×1280；固定时间采样与视窗实时帧率无关。环境不支持时回退到实时 WebM 录制，此模式的帧率和时长会受设备负载影响。导出过程中可以取消。
- **首尾帧 / 参考视频 → 视频生成**：创建一张画板，包含可返回编辑的 3D 场景节点、输入素材，以及待生成的视频节点。点击视频节点，自行选择连接、模型及其支持的参数。

画板中的场景卡片展示导出时的镜头快照，不在每个节点中运行 WebGL。编辑场景不会偷偷改掉已经导出的素材；需要新版本时再次导出。
生成模型是否支持首尾帧、参考视频及指定时长，由已有模型能力描述决定。参考视频是条件输入，不保证生成结果严格复现三维轨迹。

## 助手、保存和恢复

助手通过 `list_scenes` / `get_scene` / `create_scene` / `edit_scene` 操作同一份场景。
修改对象时按 ID 合并字段；镜头列表在显式提供时整体替换。禁止通过场景数据执行任意代码。
助手读到的是结构化场景，不能把读取几何数据描述成已经看过渲染画面。

保存使用版本校验，冲突不会覆盖服务器上的新修改。未保存的本地草稿会保留，可重试、导出草稿或重新打开后恢复。
助手修改后，本地没有未保存编辑时会自动同步；如果同时修改导致冲突，需先保留草稿再合并。
每次成功修改创建不可变版本，可通过「版本记录」恢复为新版本。

模型文件随场景保存在后端数据库中，读取与修改都受工作区权限约束。跨工作区的模型、场景引用会被拒绝。

## Blender 加工与场景互通

**打光**是场景数据的一部分：主光有方位角、高度角、强度、色温和影子软硬，并提供按用途分组的预设（产品与静物 / 人物 / 空间与建筑 / 氛围）。每个预设同时给出一段描述这束光的提示词——参考帧靠影子表达「光从哪来」，文字表达「这是什么光」，两样一起交给模型才锁得住；同一场景的几个镜头用同一档，剪到一起才不穿帮。交给模型时可以附一张**灰模**参考图（统一材质、只留光影），默认开启，开关记在本地。

3D 场景列表页有 **从 Blender 获取**：把 Blender 里当前打开的场景取成一个新的 Mosael 场景，不要求先发送过（只取几何体，相机不一起取回并会明确提示）。3D 工具栏另有 **Blender** 入口。安装并启用 Blender MCP 后，可以检测连接、发送当前已保存的模型与镜头，在 Blender 加工后接收回当前场景（一次可撤销的改动；也可以「另存为新场景」保持原场景不动），并下载关联的 `.blend` 工程。智能体模型沿用用户选择。

接收的几何体是整体模型，镜头最多采样 100 个关键帧；高级 Blender 材质/物体动画应保留原生工程。接收是整体替换而不是逐物体合并 —— 它把当前场景的模型与镜头换成 Blender 里的那一版，靠撤销和版本记录兜底，而不是尝试合并双方的改动。本阶段也没有后台 Cycles 渲染队列。完整安装步骤与范围见 [Blender 插件说明](../plugins/examples/blender/README.md)。
