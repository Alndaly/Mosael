# 3D 场景与镜头

当前开发分支新增的工作区能力，尚未包含在已发布的 1.0.0 安装包中。

从侧栏「3D 场景」进入，可以新建空场景，或打开「三间展厅」示例。
场景、对象和镜头独立保存；建模助手沿用用户选择的对话模型，视频生成时再选择对应的视频模型，不绑定 Astra。

界面分成「搭建场景 → 设计镜头 → 生成视频」三个步骤。可以随时切换步骤，场景数据会保留。
常用操作有文字标签；右上角「操作说明」列出鼠标操作，「视角」可以切换整体、正面和俯视。

## 搭建与编辑

- 基础对象：立方体、球体、圆柱、地面、房间、楼梯、组和点光源。
- 房间包含地面和四面墙，前后各有一个居中的门洞，没有顶板；可调整宽高深和门洞尺寸。楼梯沿局部 +Z 方向升高。
- 对象支持移动、旋转、缩放、复制、隐藏、删除、编组；复制组会复制其后代并生成新 ID。删除组同时删除后代。
- 拖动三维操纵器，或在右侧输入精确数字。位置、尺寸以米为单位，旋转以度为单位。吸附为 0.25 米、15 度及 0.1 缩放步长。
- 几何体可调颜色、粗糙度和金属度；点光源可调颜色和强度。GLB/glTF 模型保留原始材质。
- 导入自包含的 GLB 2.0 或内嵌资源的 glTF 2.0，每个文件不超过 25 MB。不读取模型中引用的外部网址或本地文件。Draco/KTX2 压缩资源暂不提供解码器，请导出普通 GLB。
- 添加的几何体默认放在已有场景旁边，避免重叠；点击对象列表会聚焦该物体。精确位置、旋转和缩放在「精确位置与旋转」中。
- 左键拖动观察、右键平移、滚轮缩放；按 F 聚焦选中对象。工具条和 ⌘/Ctrl+Z、⌘/Ctrl+Shift+Z 支持撤销、重做。

这里提供参数化场景搭建和模型组合，不包含雕刻、布尔建模、骨骼动画编辑或物理模拟。导入的模型作为一个对象操作。

## 设计镜头

「编辑视角」和「镜头画面」使用不同的相机。转动观察视角不会修改已经保存的运镜。

1. 进入「设计镜头」，在编辑视角中找到构图。
2. 选择「围绕主体」「缓缓推进」或「固定镜头」，基于当前构图创建运镜并立即查看镜头画面。选择会替换当前镜头轨迹，可撤销。
3. 调整时长和画面比例，点击「播放镜头」预览。
4. 如需手动运镜，展开「自己设置起点和终点」；在编辑视角中分别记录两个构图。在镜头画面中，可用「从当前镜头继续调整」复制当前相机到编辑视角。
5. 底部时间条可以选择中间时刻，再点击「记录此视角」增加途经点。
6. FOV、相机坐标、速度插值等细项在「镜头高级设置」中。
7. 进入「生成视频」，选择首尾帧或运镜视频作为生成参考；也可仅保存预览素材。

每个场景最多 500 个对象、32 个镜头；每个镜头最多 100 个关键帧、120 秒。
插值不自动避障，路径经过墙壁或物体时需调整关键帧。组层级不超过 16 层。

## 导出和视频生成

- **GLB**：导出当前可见几何体和材质；镜头路径保存在场景描述中，不会烘焙进 GLB。
- **JSON**：导出场景描述，保留对象参数、组关系和镜头。模型 ID 指向本场景存储的文件，JSON 本身不打包这些文件。
- **当前镜头画面**：按拍摄相机导出 PNG 到素材库，独立于当前观察视角。
- **镜头预览视频**：优先使用 WebCodecs 逐帧编码 H.264 MP4，30 fps，横屏 1280×720、竖屏 720×1280、方形 1280×1280；固定时间采样与视窗实时帧率无关。环境不支持时回退到实时 WebM 录制，此模式的帧率和时长会受设备负载影响。导出过程中可以取消。
- **首尾帧 / 参考视频 → 视频生成**：创建一张画板，包含可返回编辑的 3D 场景节点、输入素材，以及待生成的视频节点。点击视频节点，自行选择连接、模型及其支持的参数。

画板中的场景卡片展示导出时的镜头快照，不在每个节点中运行 WebGL。编辑场景不会偷偷改掉已经导出的素材；需要新版本时再次导出。
生成模型是否支持首尾帧、参考视频及指定时长，由已有模型能力描述决定。参考视频是条件输入，不保证生成结果严格复现三维轨迹。

## 助手、保存和恢复

助手通过 `list_scenes` / `get_scene` / `create_scene` / `edit_scene` 操作同一份场景。
修改对象时按 ID 合并字段；镜头列表在显式提供时整体替换。禁止通过场景数据执行任意代码。
助手读到的是结构化场景，不能把读取几何数据描述成已经看过渲染画面。

保存使用版本校验，冲突不会覆盖服务器上的新修改。未保存的本地草稿会保留，可重试、导出草稿或重新打开后恢复。
助手修改后，本地没有未保存编辑时会自动同步；如果同时修改导致冲突，需先保留草稿再合并。
每次成功修改创建不可变版本，可通过「版本记录」恢复为新版本。

模型文件随场景保存在后端数据库中，读取与修改都受工作区权限约束。跨工作区的模型、场景引用会被拒绝。
