## 这一版为什么发

v2.6.3 发布时发现 R2 上 Windows 安装包（`Mosael Setup 2.6.3.exe`，带空格）和更新元数据（`Mosael.Setup.2.6.3.exe`，
跟 GitHub 的改名）对不上，配了 R2 更新源的 Windows 应用内更新会 404。`aab955191` 把安装包命名定为
`Mosael-Setup-${version}.${ext}`、元数据脚本遇到空白直接报错。公开版本不覆盖，所以发 2.6.4 把它带出去。

**本版验证了改名在真包上生效**：构建产物就叫 `Mosael-Setup-2.6.4.exe`，`latest.yml` 的 `path` 同名；GitHub Release
上 16 个附件的名字与本地文件逐字一致（不再被 GitHub 改名）；R2 `latest/` 里 `latest.yml` 指向的 exe 与 blockmap
直接返回 200，**不再需要手工在 R2 上补一份带点名字的副本**。
