# Mosael 1.2.0 发布检查

日期：2026-09-09。以 v1.1.0 与当前分支的差异为重点，执行全仓测试和构建，并复查保存、导出、版本迁移、权限与桌面桥接边界。这里记录实际覆盖范围，不代表形式化证明或每行代码均无缺陷。

## 已确认并修复

- 镜头使用中的相机被删除后，保存遭到服务端拒绝。前端阻止删除被引用相机及其祖先组，键盘、列表和检查器共用同一入口。
- Blender worker 仍需要镜头帧序列，而发送边界直接传入新对象轨道格式。发送时显式投影，补齐可选目标/FOV，保持存储快照不变。
- Blender 采样在第一帧前发生负向外推；改为保持首帧。
- 接回烘焙相机帧时遗漏线性插值；同时移除已被整体 GLB 替代的父组引用，避免接回校验失败。
- 灰模参数未通过视口公开 ref 转发，导致灰模与原材质图相同；现已传递。
- 导出只清除顶层机位辅助对象，GLB 未清除辅助对象；参考帧与 GLB 共用递归清理的场景副本。
- 云端检查发现中文 3D 指南缺少保存历史小节，且导航序号与工作流重复；补齐双语内容并分配独立序号，4 项同步检查与官网 8 项测试通过。
- 正式签名构建暴露 `app-builder-lib@26.15.3` 的密码传递错误：证书导入成功后，使用证书密码解锁随机密码的临时钥匙串。通过 pnpm 补丁传递正确的钥匙串密码；回归测试先失败后通过，并用本机临时证书实际验证导入与访问控制配置，验证后删除测试钥匙串和私钥。

## 验证范围

- 后端：发布提交的完整 pytest，3072 项通过，覆盖路由权限、工作流、任务、媒体、插件、沙箱、笔记、版本迁移与数据库约束，包括修复后的 Blender 回归。
- 前端：发布提交的完整 Vitest，231 文件、1336 项通过；TypeScript 与生产构建通过。
- 浏览器扩展：67 项测试、类型检查与打包通过。
- 桌面：Electron 类型检查，preload、publisher、system bundle 构建通过；sidecar 构建与测试通过。
- 手动源码复查：场景采样/删除/导出、Blender 往返、磁盘模型迁移与模型归属、评论作者权限与提及、标记数据校验、浏览器池 WebAuthn 边界、沙箱与工作区权限。
- 文档：扫描 93 份现行及历史 Markdown/MDX，更新适用范围、发布链接、3D 与协作说明；历史设计保留历史身份。工具清单、结构性约束和工作流下载目录由现有脚本核对。
- 发布门禁已在 Linux 重跑完整测试，并分别在 macOS/Windows 打包后启动 Electron、迁移旧数据库和验证渲染器加载，全部通过。

- 实际 WebGL 导出：通过公开视口 ref 分别导出普通参考图、灰模与 GLB；两张 PNG 内容不同，GLB 不含 editorOnly 对象，渲染器未报错。

- 官网生产构建与 8 项文档/媒体测试通过；中英文 3D 指南在 1440px 与 390px 宽度下无页面横向溢出、无页面运行错误。

## 外部能力边界

本次没有调用付费生成模型、向社交平台发布或替用户执行真实账户登录。Blender 边界与 worker 使用隔离测试；不将这些测试描述为新一次真实 Blender 完整工程往返。Touch ID 接入增加了正式签名、Developer ID 描述文件和安装包权限读取。独立签名程序已实际完成钥匙串写入与清理；完整 Electron 包已通过启动、旧数据库升级和渲染器验证，WebAuthn 返回 configured=true、device available=true。本地 QA 为绕开网络上的 Apple 时间戳失败，显式关闭时间戳与公证；该 QA 包不作为分发产物。正式分发包随后独立通过了云端签名、安全时间戳、Apple 公证、票据与 Gatekeeper 验证；该包在当前 Mac 上的完整启动检查同样返回 configured=true、device available=true。高级 Blender 动画/材质与跨设备 Passkey 的限制已写入用户文档。
