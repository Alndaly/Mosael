# Mosael 1.2.0 发布检查

日期：2026-09-09。以 v1.1.0 与当前分支的差异为重点，执行全仓测试和构建，并复查保存、导出、版本迁移、权限与桌面桥接边界。这里记录实际覆盖范围，不代表形式化证明或每行代码均无缺陷。

## 已确认并修复

- 镜头使用中的相机被删除后，保存遭到服务端拒绝。前端阻止删除被引用相机及其祖先组，键盘、列表和检查器共用同一入口。
- Blender worker 仍需要镜头帧序列，而发送边界直接传入新对象轨道格式。发送时显式投影，补齐可选目标/FOV，保持存储快照不变。
- Blender 采样在第一帧前发生负向外推；改为保持首帧。
- 接回烘焙相机帧时遗漏线性插值；同时移除已被整体 GLB 替代的父组引用，避免接回校验失败。
- 灰模参数未通过视口公开 ref 转发，导致灰模与原材质图相同；现已传递。
- 导出只清除顶层机位辅助对象，GLB 未清除辅助对象；参考帧与 GLB 共用递归清理的场景副本。

## 验证范围

- 后端：完整 pytest（3067 项通过的基线），覆盖路由权限、工作流、任务、媒体、插件、沙箱、笔记、版本迁移与数据库约束。修复后的 Blender 聚焦回归 14 项通过。
- 前端：修复后完整 Vitest，230 文件、1322 项通过；TypeScript 与生产构建通过。
- 浏览器扩展：67 项测试、类型检查与打包通过。
- 桌面：Electron 类型检查，preload、publisher、system bundle 构建通过；sidecar 构建与测试通过。
- 手动源码复查：场景采样/删除/导出、Blender 往返、磁盘模型迁移与模型归属、评论作者权限与提及、标记数据校验、浏览器池 WebAuthn 边界、沙箱与工作区权限。
- 文档：扫描 93 份现行及历史 Markdown/MDX，更新适用范围、发布链接、3D 与协作说明；历史设计保留历史身份。工具清单、结构性约束和工作流下载目录由现有脚本核对。
- 发布门禁仍会在 Linux 重跑完整测试，并分别在 macOS/Windows 打包后启动 Electron、迁移旧数据库和验证渲染器加载。

- 实际 WebGL 导出：通过公开视口 ref 分别导出普通参考图、灰模与 GLB；两张 PNG 内容不同，GLB 不含 editorOnly 对象，渲染器未报错。

- 官网生产构建与 8 项文档/媒体测试通过；中英文 3D 指南在 1440px 与 390px 宽度下无页面横向溢出、无页面运行错误。

## 外部能力边界

本次没有调用付费生成模型、向社交平台发布或替用户执行真实账户登录。Blender 边界与 worker 使用隔离测试；不将这些测试描述为新一次真实 Blender 完整工程往返。Touch ID 需要正确签名与 keychain entitlement，当前未签名发行包不启用。高级 Blender 动画/材质与跨设备 Passkey 的限制已写入用户文档。
