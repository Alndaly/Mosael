## 这一版做了什么

全部是录制相关的一批修正(2.1.0 发布后才发现/才做的),以及两处界面问题:

| 现场 | 改法 |
|---|---|
| 录屏时没法同时录麦克风 | 屏幕档新增「麦克风」开关,系统声音 + 解说用 Web Audio 混成**一条**音轨(默认关、记住选择);麦克风取不到只降级成「没有解说」 |
| 录制中没有音频可视化 | 录制中在**视频左下角**显示电平(红点左上、计时右下,各占一角;双画面时上让一格) |
| iPhone / 外接麦克风电平不动 | 设备签名进依赖(换设备重建分析图)、建好先 resume 并在指针按下与每 500ms 重试、必要时改读 float 数据 |
| 闲置界面显示 `00:04` | 计时器只在真的在录时走,否则 `00:00` 并归零 |
| 已允许屏幕录制仍提示没权限 | 文案写明「允许后要重启才生效」;窗口回到前台与每 3 秒回读状态,授权后红框自动收掉 |
| 资产页空态没居中 | 空 / 载入中 / 出错时容器自己撑满剩余高度,空态居中(结构测试钉住) |
| 打包版跑过后 `pnpm dev` 起不来 | 新增 `pnpm dev:isolated`(独立数据目录),不碰用户数据与那把被封存的钥匙 |
