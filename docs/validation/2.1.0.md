## 这一版的关键改动(与验证相关的部分)

- **Computer Use 坐标换算**:Retina 截图是物理像素、`sendInputEvent` 认 CSS;点 / 输入 / 滚动不再全落在左上角;

  (另有 `weixin://` 与「同一账号两份分区」的迁移两条);
- **让位协议声明化 + 坐标换算收成一份**:四条手工通道删除,`publish/coords.cjs` 是唯一的乘法所在地;
- **站点契约 + 每日冒烟**:`contracts/platform-contracts.json`、`scripts/platform-smoke.cjs`、每日 workflow;
- **DB**:`migrate-browser-profiles-pin-identity`(身份钉进档案),schema 版本 36 → 38。

## 已知事项

- **屏幕录制权限(macOS)**:这一版补了「请求屏幕权限」与「打开系统设置」两个**不同**的动作,并把 dev 应用改成
  Developer ID 签名 + helper 用自己的 bundle id,TCC 才认得出应用。但 macOS 的归属规则是:从终端启动的开发实例
  由 **Terminal** 承担权限归属,系统不会为应用自己记账 —— 开发时验证屏幕录制请用打包版(从 Finder / DMG 打开)。
  已在打包版上复核:应用以 `dev.mosael.app` 身份出现在 TCC 请求里(`AUTHREQ_SUBJECT: dev.mosael.app`,
  `staticCode` 通过),剩余一步只能由用户在系统设置里手动勾选(或被 `+` 添加)——这是 macOS 的规则,不是应用行为。
- **2.1.1 待办**(已合进 main、未进这一版):录制计时器在闲置时归零;录屏幕时同步录麦克风(Web Audio 混音)。
