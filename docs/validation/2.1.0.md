## 这一版的关键改动(与验证相关的部分)

- **Computer Use 修复坐标换算**:Retina 截图是物理像素、`sendInputEvent` 认 CSS;点 / 输入 / 滚动不再全落在左上角,
  一轮结束自动退出「被控制中」;
- **内嵌浏览器身份**:`chrome` 档改走 CDP(`Emulation.setUserAgentOverride`),UA / `Sec-CH-UA` /
  `navigator.userAgentData` 三处一致;视频号登录修好(另有 `weixin://` 与分区迁移两条);
- **让位协议声明化 + 坐标换算收成一份**:四条手工通道删除,`publish/coords.cjs` 是唯一的乘法所在地;
- **站点契约 + 每日冒烟**:`contracts/platform-contracts.json`、`scripts/platform-smoke.cjs`、
  `.github/workflows/platform-smoke.yml`;本机实测七家全过;
- **DB**:`migrate-browser-profiles-pin-identity`,schema 版本 36 → 38。
