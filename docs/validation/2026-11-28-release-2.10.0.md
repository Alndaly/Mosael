- 签名检查：`verify-mac-signing.cjs --signature-only` 通过，WebAuthn keychain group 为 `27W3D2ZUT9.dev.mosael.app.webauthn`，版本 `2.10.0`。

- App 装订后：`stapler validate`、Gatekeeper `spctl` 通过；`bundle.smoke.mjs` 在无 `MOSAEL_CLOUD_URL` 覆盖下通过（cloud configured、renderer、backend health、DB 升级、Touch ID）。
- 最终更新 ZIP 由 `pack-mac-update.mjs` 从已装订 App 重新生成；解包后再次验证版本、签名和公证票据。
- DMG 由已装订 App + `/Applications` 链接生成，使用 Developer ID 签名后再提交公证：**Accepted**，submission `50410ad5-1555-4c91-8be1-f0315f8cbd24`。
- DMG `stapler validate`、`spctl --assess` 通过；只读挂载后内部 App 版本 `2.10.0`、签名和票据均通过。

## Windows

- 构建 run 的 Windows 产物未做 Authenticode 签名：CI 只有 `CSC_*` / `MACOS_PROVISION_PROFILE`，没有 `WIN_CSC_LINK`、`WIN_CSC_KEY_PASSWORD`、`WIN_PUBLISHER_NAME`；PE 安全目录为空。
