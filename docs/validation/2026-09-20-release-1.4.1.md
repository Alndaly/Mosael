### 时间戳那一步遇到的代理问题(与 1.4.0 同一处)

第一次 `codesign --timestamp` 报 `The timestamp service is not available.`。实测原因:

```
经代理 http://127.0.0.1:7897 → timestamp.apple.com  502
直连(--noproxy '*')          → timestamp.apple.com  302
```

`codesign` 走的是**系统**网络代理,而终端里的 `HTTP_PROXY` 是另一组。按 RELEASING.md 的做法处理:
脚本保存 Wi-Fi 服务当前的代理例外列表 → 临时追加 `timestamp.apple.com` 与 `*.apple.com` →
**仅为 codesign 这一条命令**清掉 `HTTP(S)_PROXY` / `ALL_PROXY` → `trap` 在退出/中断/被杀时还原。
签完已逐行核对例外列表与原值一致,没有留下任何永久网络改动。脚本见
`/tmp/mosael-release-1.4.1/sign-dmg.sh`(工作目录在仓库外,不入 Git)。
