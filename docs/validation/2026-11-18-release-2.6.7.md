## 本版重点

### Computer Use

- 本地操作层补齐元素令牌点击 / 输入 / 拖拽、区域放大、hover、指针按下与抬起、中键、三击、修饰键点击、按住键、水平滚动、批量动作、文字等待与断言。
- 批量动作最多 8 步顺序执行，失败即停；L1 / L3 都支持，结束或失败自动截图并作为图片块回到模型上下文。
- 剪贴板读写要求部署管理员且每次确认；OCR 使用本地 macOS Vision；受保护应用的全桌面截图直接拒绝。

### 素材

- 新增 `extract_audio`：从已有视频生成新的 `.m4a`，原视频不变；链接只要求音频时，遇到带画面的回源文件会自动抽轨。

### 工作台

- ComfyUI 表单按钮、页签和运行结果卡片统一到胶囊形与标准间距。
