## 这一版做了什么

完整用户可见变更见 GitHub Release 说明与 `CHANGELOG.md` 的 2.2.1 段。本版相对 2.2.0 的关键变化:

| 现场 | 改法 |
|---|---|
| 桌面 Computer Use 只有观察 | 补齐 macOS 权限引导、点击 / 输入 / 滚动确认卡、受保护应用拒绝、动作前后截图回放和全局急停提示 |
| 飞书只能确认 | `ask_user` 支持单选 / 多选 / 自由文本表单卡;确认卡与问题卡补齐事务、幂等、消息 id 生命周期 |
| 飞书入站会丢消息 | 持久收件箱、跨重启 drain、`FeishuError` 统一、绑定码原子单次使用与审计 |
| 智能体环境默认收起 | AI tab 默认展开右侧 sidebar;后台任务、最近工具、全部工具弹窗统一行语法与悬停下划线动作 |
| 工具卡片信息太少 | 全部工具弹窗加宽到 64rem、响应式卡片网格;显示只读 / 需确认 / 会提问 / 插件来源与参数数量 |
| 全部放行确认框被设置浮层盖住 | 从浮层打开的模态抬到 popper 之上(z 130) |
| 思考档位字段宽度不撑满 | 禁用态提示层不再按内容收缩,与权限模式 / 视频分析方式同宽 |
| 依赖落后 | 前端 / 扩展 / sidecar / 官网 / 三个 uv lock 升级;Electron 45、Next 16.4、FastAPI 0.162 等落地 |
