## 这一版做了什么

| 现场 | 改法 |
|---|---|
| 应用内下载报 `ENOENT: …/app-update.yml` | `build/app-update.yml` 通过 `extraResources` 内嵌 macOS / Windows 包,声明 GitHub 更新源和缓存目录;打包冒烟强制检查 |
| macOS 下载完成后不能重启安装 | 在 `quitAndInstall` 前显式退出托盘常驻拦截;注销系统能力时也不再拦截退出关窗,让 Squirrel 等待旧进程退出并替换、重启 |
| Windows 完整版 FFmpeg 上游更新 | 一键安装清单更新到 `autobuild-2026-10-25-13-00`,下载地址和 SHA-256 重新生成 |
