## 没做什么

- **本机没跑 Windows 安装包**:它由云端那次构建验证启动与数据库升级,附件按「同一次构建」
  收录,不声称它带 Windows 代码签名。
- **浏览器里没有实机复核 3D 页全屏和分割线**:dev server 停在登录页,而代替用户登录不在允许
  的事情里。这两处由 `fullscreenIsJustTheViewport.test.ts` 双向钉住(样式里藏哪几块,以及
  那几个类名在 `SceneStudio.tsx` 里真的用着 —— 只测 CSS 的话,类名打错一个字母就是「藏了个
  不存在的东西」,而没有任何东西会报错)。
