## 这一版做了什么

| 现场 | 改法 |
|---|---|
| 发布只有视频形状 | 抖音图文 / 文章、小红书图文 / 长文、X 图文 / 长文、TikTok 图文、B 站专栏、视频号图文全部接上;
  发布页与工作流发布节点共用同一套「内容类型 + 素材 + 正文 + 平台选项」;封面由平台声明 required / optional / none |
| 发布靠平台各自硬编码 | 七家平台的入口、成功信号、浮层与真机核对上限收进站点契约,每天用不登录的浏览器冒烟 |
| 「工作台」和「剪辑」两个 tab 各有一套进入规则 | 首页并入剪辑页:无项目是项目浏览器,选中后是时间线;侧栏换页不清状态,面包屑回项目列表;
  新建统一建完打开;不再静默落到第一个项目;AI Studio 移到剪辑上方并加分组线 |
| 录音时看不出有没有声音 | 说话输入加三格实时电平(dB 映射、上升快、间隙缓降) |
| Computer Use 有永远走不通的 publish 分支 | 从契约 / 主进程 / 后端 / 测试整个删除;渲染层截图接线漏改的旧签名一并修掉 |
| 飞书机器人与界面细节 | 机器人可编辑、删除先确认、重启即时反馈;打包长连接不再走 `python -m`;
  深色阴影改大模糊低 alpha,图片加载失败有兜底 |
