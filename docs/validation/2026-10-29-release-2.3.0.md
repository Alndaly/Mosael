## 一个待确认的点

`latest.yml` 里 Windows 的下载名是 **`Mosael.Setup.2.3.0.exe`**（空格→点），而本地文件叫
`Mosael Setup 2.3.0.exe`。这是 `scripts/write-update-metadata.mjs` 有意做的（GitHub 会把上传名里的
空格规范化成点），v2.2.4 的 Release 里附件名也确实是 `Mosael.Setup.2.2.4.exe`——所以上传时
**按元数据写的名字上传**（或上传后确认 GitHub 已规范化），否则应用内更新会 404。
