### 这一轮踩到的两个坑（已写进 docs/RELEASING.md）

1. **控制台单文件上限 300 MB**：DMG(349 MB) / ZIP(308 MB) 传不上去，必须用 S3 分段上传
   （`publish-r2.mjs` 的 `PutObject` 对这两件不适用）；
2. **Cloudflare 的 IPv6 会"接受连接但不回数据"**，而 AWS SDK 默认没有传输超时 —— 进程会一直挂着
   看不出错（踩了三次）。所有 R2 操作都要 `NODE_OPTIONS=--dns-result-order=ipv4first`：
   IPv4 秒通、IPv6 死等。
