# 在工作流和无限画布中引用笔记

笔记中的品牌规范、脚本、产品资料，可以直接作为创作的参考来源。引用范围限于当前工作区，回收站中的笔记不会出现在检索结果中。

## 工作流

在「添加节点 → 知识库」中选择：

| 节点 | 用法 | 主要输出 |
| --- | --- | --- |
| 检索笔记 | 按标题、正文、标签、专题检索，支持中英文；默认返回 10 条，可设置起始位置继续查询 | 笔记列表、ID 列表、摘要文本、数量、是否还有结果 |
| 读取笔记 | 点击选择笔记，或连接上游笔记 ID；高级选项可指定版本，留空读取最新版本 | 完整正文、Markdown、标题、标签、版本、来源链接 |
| 保存为笔记 | 将文案或上游正文保存为一篇新笔记，可添加标签 | 新笔记 ID、标题、版本、来源链接 |

例如：`读取笔记 → AI 文本生成 → 保存为笔记`。将读取节点的 `text` 连接到文本生成的提示词或系统提示，将生成节点的 `text` 连接到保存节点的 `markdown`。模型由用户自行选择。

批量处理可以使用 `检索笔记 → 循环·遍历 → 读取笔记`。检索的 `notes` 是对象数组，每项包含 `note_id`、`revision`、`title`、`excerpt`、`truncated` 和 `citation_url`；摘要最多 1000 字，完整内容应交给读取节点。每次最多查询 50 条，`has_more` 为真时可增加 `offset` 继续查询。

保存节点每次执行创建一篇新笔记，不覆盖原始资料。读取节点的来源链接包含本次读取的版本，可用于可追溯的文案引用。当前检索使用关键词匹配，不需要配置嵌入模型。

## 无限画布

1. 点击顶部「添加 → 文档」。
2. 在文档卡片中点击「选择笔记」，按标题、正文、标签或专题搜索。
3. 从文档右侧的连接点，拖线到图片、视频、便签或音频节点。
4. 在下游填写创作要求并选择模型。图片和视频表单显示引用的文档标签；正文作为参考资料提交，不覆盖用户自己写的提示词。

文档卡片预览 Markdown，支持滚动、拖动和调整大小。正文与内嵌图片均可作为拖动节点的区域，图片不会触发原生拖出并创建额外节点。切换评论或标记模式时，文档标题栏保持固定高度。预览最多显示前 6000 字，生成使用完整引用正文，仍受所选模型的输入限制。便签写作将正文作为上下文，音频节点将正文填入配音内容。

文档固定引用选择时的版本。修改原笔记不会悄悄改变画布输入；点击卡片底部「更新到最新版本」后才更新引用并自动保存。卡片顶部可以更换笔记，底部「打开原文」进入笔记编辑页面。普通打开不会自动弹出版本记录。

原文被移入回收站、删除或无法读取时，卡片显示不可用提示；相关下游生成入口暂时显示修复提示，避免漏掉参考内容继续生成。已有失效节点仍可移动和移除。

## 智能体与接口

智能体可通过 `search_notes`、`read_note` 获取来源，并用 `edit_board` 的 `add_item` 操作创建 `document` 节点：

```json
{"kind":"add_item","type":"document","note_id":"笔记 ID","note_revision":1}
```

随后通过 `connect` 连接下游节点。画布数据只保存笔记 ID、版本和标题，不复制整篇正文；读取引用时服务端验证工作区和回收站状态。

`GET /api/notes/{note_id}/reference?workspace_id=...&revision=...` 返回完整引用正文与来源链接。省略版本读取最新内容。新引用会在保存画布时验证，已删除来源的历史引用仍允许移动或移除。

改正文用 `edit_note`：按段**替换**或在某段前后**插入**，锚点是正文原文本身(必须恰好出现一次)，走编辑档确认卡 —— 卡上画出每一处的「原文 → 新文」，批准时落在那一刻的正文上；那段原文已经被改掉就失败、不写。旧的一版留在版本记录里。末尾追加用 `append_note`，新建用 `create_note`。笔记页的 AI 助手每条消息都带着当前这篇和选区(选区给的是正文 Markdown 原文和位置)，所以锚点能逐字照抄。

版本号是**版本记录里的那个数**，画板文档格、来源和 `&revision=N` 链接钉的都是它；同一个人连续的手动编辑(停笔不超过 5 分钟、一版最长 30 分钟)合成一版，只改收藏、回收站、标签、主题不开新版。并发判断另用保存序号 `save_seq`(见 CONTEXT.md)。

另外两条进出笔记的路:`POST /api/boards/{board_id}/notes` 把一段字作为便签追加到一张画板的空位上(笔记选区工具条的「加到画板」)，便签带 `source_note`(笔记、版本、标题)，引用表把它记成画板 → 笔记;`POST /api/notes/from-page` 把浏览器会话交来的渲染后 HTML 挑出正文、转成 Markdown 存成新笔记，来源里记网址和页面标题。
