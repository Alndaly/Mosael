# 待补录的界面画面

官网文档里的截图和演示视频是在真实应用里拍的(见 [README](README.md))。界面改了之后不会每次都重拍,
这里按版本记下**哪些画面已经过时**,下次集中补录时照着这份清单拍,拍完一项删一项。

**这份清单只给维护者看,不上官网。** 它此前写在官网「关于项目」页的一段正文里,每发一版往后接一句,
九个版本下来成了一大段读者看不懂的流水账(2026-09-24 被指出)。读者需要知道的只有一句:截图可能
比应用旧,以应用里实际看到的为准 —— 那一句留在官网上。

发版时把这一版改过、而截图没跟上的界面加在最上面(见 [RELEASING.md](../RELEASING.md))。
