# 设计语言

Mosael 界面上所有控件长什么样、多高、什么时候用哪一种,以这一份为准。基础组件(`frontend/src/components/ui/`)只从这里定下的
token 取值,业务代码只挑档位和变体,不在 className 里改高度、内边距、圆角、字号。

规格样张:开发构建里打开 `#/dev/design`(`frontend/src/dev/DesignSheet.tsx`),每一档、每一类控件、每一种状态,顶上切浅色 / 深色。
样张里摆的都是真组件 —— 改了基础组件或 token,它跟着变;和这份文档对不上时以文档为准,样张(或基础组件)是 bug。

> 这份文档回答「该是什么样」。具体某条规则由哪道棘轮守着,见末尾「谁守着」;已定的几件事和还没落地的见「定稿与落地」。

## 一、三条总规则

1. **档位跟着场景走,不跟着「这里看着顺眼」。** 同一种场景在哪一页都是同一档。挑档的依据是下面「场景 → 档位」那张表,
   不是旁边那个控件碰巧是多高。
2. **一个容器一个档。** 一张表单、一个侧栏面板、一条工具条、一张卡片里,字段、按钮、下拉、分段控件、图标按钮都是同一档。
   例外只有两种:行内动作(它本来就不占行高)和固定尺寸的小控件(开关、复选、单选,它们垂直居中在这一档的行高里)。
3. **一种控件一个样子。** 下拉框不论是 Select、可搜索的下拉、组合框还是时间选择,外观是同一种字段外观;分段控件、开关、
   复选、单选、胶囊筛选、页签各只有一种样式。没有基础件的先补基础件,不在业务代码里自己画。

## 二、刻度

| 档 | 高度 | 文字控件左右留白 | 字号 | 图标(文字按钮里) | 方形图标按钮 |
|---|---|---|---|---|---|
| `xs` | 28px | 按钮 10px、字段 8px | 12px(`text-ui-xs`) | 14px | 28px |
| `sm` | 32px | 按钮 12px、字段 10px | 14px(`text-ui-sm`) | 16px | 32px |
| `md` | 40px | 按钮 16px、字段 12px | 14px | 16px | 40px |
| `lg` | 44px | 按钮 24px | 14px | 16px | —— |
| 行内 | 24px,上下各收 2px(不撑高那一行) | 6px | 12px,不加粗 | 14px | —— |

- 刻度住在 `components/ui/control-size.ts`(`CONTROL_HEIGHT`、`CONTROL_SQUARE`、`CONTROL_ICON`、`FIELD_SIZE`、`FIELD_TEXTAREA`、
  `FIELD_INVALID`、`SEGMENTED_SIZE`、`CHIP_SIZE`、`INLINE_ACTION_SIZE`),按钮、字段、下拉触发器、分段控件、胶囊筛选都从这里取。
  **别处不写 `h-7` / `h-8` / `h-10` 来对齐**:同高要是构造出来的,不是碰巧都写了同一个数。
- 方形图标按钮和同档文字控件**一样高**:`icon-xs` 28、`icon-sm` 32、`icon` 40。只有这三个名字。
- 字号:界面只用 `text-ui-*` 这几档(11 / 12 / 14 / 16 / 18 / 32px)。
- 圆角:控件 8px(`rounded-md`);外面套一层的容器 = 里面的圆角 + 内边距(分段控件外壳 12px = 8 + 4);复选框 4px;
  胶囊筛选、标签、开关是全圆。不用投影区分控件,用描边和底色。
- 菜单项最矮 36px(`MENU_ITEM`),文字 14px —— 菜单不跟着触发它的那个按钮的档位变。
- `lg` 目前没有用处,只留给登录页、首次引导那种整页只有一个动作的地方。

## 三、场景 → 档位

| 场景 | 档 | 例子 |
|---|---|---|
| 填值的地方:表单、对话框(字段和底部的按钮) | `md` | 新建连接、重命名、导出设置 |
| 侧栏设置面板:右栏参数、检查器、节点表单 | `md` | AI Studio「引擎参数」(模型、音色、语速都是 40)、剪辑检查器、工作流节点检查器 |
| 设置页里填值的那一行(输入框、下拉,以及和它并排的按钮) | `md` | 下载目录 + 「选择…」 |
| 页面头部的动作(`PageHeading` 的 actions) | `md` | 「新建场景」「导入」 |
| 列表页的筛选条:搜索框、排序、选择、标签筛选 | `md` | 资产页、素材库那一条 |
| 画布 / 编辑器的工具条 | `sm` | 画板、工作流、3D 场景的工具条,ComfyUI 工作台顶栏 |
| 窗口顶栏 | `sm` | 收起侧栏、全局搜索、确认中心那颗胶囊、任务中心、通知、主题、语言 |
| 卡片里、列表行尾的次要动作;面板标题栏上的按钮 | `sm` | 设置页列表行的「编辑」、右栏标题旁的关闭 |
| 密集的工具条:时间线、内嵌浏览器顶栏、智能体输入框底栏、弹出层里的小工具行 | `xs` | 剪辑时间线工具、输入框里的「@ 资产」「附件」;那一栏的发送键是主动作,大一档(`sm` 圆钮) |
| 挨着一个值、一行说明的次要动作 | 行内 | 「在 Civitai 上找」「标为 NSFW」「详情」「显示全部」「展开」 |
| 整页只有一个动作(登录、首次引导) | `lg` | —— |

怎么用这张表:

- **先认容器,再认档。** 侧栏面板就是 `md`,哪怕面板很窄;画板工具条就是 `sm`,哪怕旁边有空。窄面板里放不下 `md` 的
  文字按钮时,换成图标按钮(同档、方形),不是降一档。
- **图标按钮和同排的文字控件同档**:`xs` 行里是 `icon-xs`,`sm` 行里是 `icon-sm`,`md` 行里是 `icon`。图标按钮
  不比旁边的按钮矮一截,也不高一截。
- **同一行里只有一个档。** 输入框 40、旁边按钮 32 这种「贴着矮一截」不许出现(`design/controlRhythm.test.ts` 算出来比)。
- 开关(20×36)、复选(16)、单选(16)不跟档变,垂直居中在这一档的行高里;它们的文字标签用 14px。

## 四、按钮

| 变体 | 叫法 | 什么时候用 |
|---|---|---|
| `default` | 主 | 这一屏 / 这个弹窗**唯一**的主动作。实心、强调色 |
| `secondary` | 次 | 和主动作并排、分量比描边重一点的次要动作(「重试」);填充底色、无描边 |
| `outline` | 描边 | 和主动作并排的次要动作(「取消」「导入」);描边和输入框是同一种描边 |
| `ghost` | 幽灵 | 工具条、卡片角上不带边框的按钮;悬停才显出底色 |
| `inline` | 行内 | 挨着一个值、一行说明的次要动作。比正文小一档、次要色、悬停才显出底色、不撑高那一行;不写 `size` |
| `destructive` | 危险 | **只**用在确认弹窗里那颗「删除」「清空」上。页面上不直接摆实心红按钮;菜单里的危险项是红字(`MENU_ITEM_DESTRUCTIVE`) |

- **一屏只有一个主动作。** 并排的第二个动作用描边或次。列表真取回来是空的时,主动作只在正中的空状态里摆一颗,页头不再摆
  同一件事的第二颗;空状态里有几个动作时只有一颗实心。
- **只有图标的按钮走 `IconButton`**:名字只写一次(它既是读屏念的 `aria-label`,也是悬停说明的第一行),点不了时说为什么
  (`disabledReason`)。不靠原生 `title`。
- **type**:`Button` / `IconButton` 不写 type 就是 `type="button"`(点了只做 onClick 那件事)。**要提交表单的那一颗写
  `type="submit"`**(在表单外面的用 `form={id}` 指过去),其余不写。填值的弹窗、设置里的一组输入框做成真的 `<form>`:
  在任一格里按回车就是提交 —— 弹窗给 `ModalShell` 传 `onSubmit`,footer 里的提交键用 `ModalSubmit`。只有一个输入框的表单
  (地址栏、改名)不用按钮,回车靠浏览器的隐式提交。棘轮:`design/buttonTypes.test.ts`。
- **在跑**:点下去会发请求、又没有别的即时反馈的按钮接 `loading` —— 第一个图标换成转圈,宽度不变,不能再点。
- 按钮里的图标大小由档位定(上面那张表),**在图标上写 `size={12}` 不生效**,别写。
- `link` 变体不用:要一个文字样子的动作,用 `inline`。
- 不手写原生 `<button>` 拼一个按钮的样子(高度、底色、悬停一样一样抄),要么是 `Button` / `IconButton`,要么是下面那几种
  基础件(`Segmented`、`Chip`、`RadioGroup`、`Tabs` / `CollectionTabs`、`MenuItem`)。
- 只有图标的按钮,图标在哪一档都是 16(`IconButton` 自己钉住);借文字档让宽度跟着内容走的(图标 + 小下拉箭头)也是。

## 五、字段:输入框、下拉、组合框、日期、数字、文本域

一种外观,所有字段都是它:

| 部位 | 规格 |
|---|---|
| 描边 | 1px `--field-border`(描边按钮也是这一种) |
| 底色 | `--field`(弹窗里、玻璃外观下由表面改写,调用处不管) |
| 圆角 | 8px |
| 高度、留白、字号 | 跟档位(`FIELD_SIZE`):`xs` 28 / 8px / 12px,`sm` 32 / 10px / 14px,`md` 40 / 12px / 14px |
| 文本域 | 和 `md` 同一套:留白 12px、上下 8px、14px;最矮 60px,随内容长高 |
| 占位文字 | `--muted-foreground` |
| 聚焦 | 2px `--ring` 聚焦环(字段只要有焦点就显示;按钮只在键盘聚焦时显示) |
| 禁用 | 半透明(50%)、`not-allowed` 指针;说得出为什么点不了时在旁边或悬停里说 |
| 出错 | `aria-invalid` 时描边和聚焦环换成 `--destructive`;错误文字在字段下面,12px、红色 |
| 下拉触发器 | 值一律靠左,箭头 16px、50% 不透明,顶到最右(`fieldTriggerClass` / `FIELD_TRIGGER_CHEVRON`) |

- Select、可搜索的下拉(`SearchableSelect`)、选项选择器(`OptionPicker`)、组合框、时间选择(`TimePicker`)都用
  `fieldTriggerClass(size)`,外观一样;**不自己画触发器**(一个 `<button>` 加一个向下箭头)。
- 输入框、文本域、下拉触发器都认 `aria-invalid`(`FIELD_INVALID`);表单里用 `FormControl` 时它自己挂上。
- 数字就是 `<Input type="number">`,日期就是 `<Input type="date">` / `TimePicker`,不另起一种外观。
- **标签和值的对比,全应用两种:**
  - 填值的地方(表单、侧栏面板):字段标签 14px、中等字重、前景色,在字段上面;说明文字 12px 次要色;错误 12px 红色。
    设置页的行标题 16px 中等字重(那里标签就是这一行的主角),说明 14px 次要色。
  - 只读的「名字 | 值」(概要、详情、属性表):名字 12px 次要色,值 14px 前景色,名字那一列定宽、基线对齐。
  同一个面板里不混两种。

## 六、选择类控件

| 控件 | 用在哪 | 规格 |
|---|---|---|
| 分段控件(`Segmented`;要自己渲染每一项时 `segmentedListClass` / `segmentedItemClass`) | 两到五个互斥选项、选项短、切换立刻生效(「对话 / 创作」「近 7 天 / 30 天」) | 外壳次级底色、内边距,圆角 = 里面 + 内边距(md 12 = 8 + 4;sm、xs 8 = 6 + 2);选中项强调底色 + 强调前景色;**总高度跟档位**:`md` 40(项 32)、`sm` 32(项 28)、`xs` 28(项 24);`fill` 铺满一行、每项等宽 |
| 胶囊筛选(`Chip`) | 一排可以多选或单选的筛选条件,会折行(「全部 · 图像 · 视频」、标签) | 全圆、1px 描边、12px 字、图标 12px;选中:强调底色 + 强调色描边;高 28px。默认是切换按钮(`aria-pressed`),当页签读给 `role="tab"`,当单选读给 `role="radio"` |
| 页签(`Tabs`、列表页的 `CollectionTabs`) | 切换一整块内容(「人物 / 场景 / 道具」) | 底线页签(`TAB_TRIGGER`):14px 中等字重,选中项强调色字 + 2px 底线;单独一条 44px、下面一条分隔线,列表页筛选条里那一排随那一行 40 |
| 列表分组的折叠标题(`GroupToggle`) | 列表里一组可以收起来(会话列表的分组、「来自别处」) | 整行、左边会转的箭头、名字截断、右头这组几项;12px 中等字重次要色,悬停次级底色。表单里的「高级」那种是 `Disclosure`(一行字,没有底色) |
| 开关(`Switch`) | 一个设置的开 / 关,立刻生效 | 20×36,开为强调色;旁边的标签 14px |
| 复选(`Checkbox`) | 多选、「我同意」、全选(有半选态) | 16px,圆角 4px;选中实心强调色 |
| 单选(`RadioGroup`) | 选项多、需要说明文字、或者放在表单里要「确定」才生效 | 16px 圆;选中强调色描边加圆点;每项可带一行说明;底下是原生的同名 radio(方向键、Tab、读屏是浏览器给的) |
| 下拉 | 选项多(> 5)或很长 | 见「字段」 |

- 分段控件和单选的分界:选项短、立刻生效、两到五个 → 分段;要说明、要提交才生效、或超过五个 → 单选 / 下拉。
- 胶囊筛选和分段的分界:会折行、可多选、是「筛」不是「切换视图」 → 胶囊。
- **窄栏里的页签放不下时不折行**:没选中的只剩图标(名字在悬停说明和读屏里),选中的始终带名字;放不放得下按真宽度量
  (工作台右栏的 `WorkbenchTabs`)。一个页签的名字折成两行、把整条撑高,是最难看的那种放不下。
- 被按下 / 选中的切换按钮(工具条上的「选择」「标记」)用 `aria-pressed`,样子是强调底色 + 强调色前景,和分段的选中项同一种。

## 七、图标

- 用 lucide。线宽默认 2,不改。
- 大小跟档位(见刻度表);只有图标的按钮在所有档位都是 16px。
- 装饰性的图标(标题前、空状态里)加 `aria-hidden`;颜色跟着文字或用次要色,不另起颜色。

## 八、动效

时长四档(值在 `design/tokens.css` 的 `--motion-*`):

| 档 | 时长 | 用在哪 |
|---|---|---|
| 快 | 100ms(`duration-100`) | 行上的悬停底色、小箭头转向、悬停才露出的小图标 |
| 中 | 160ms(`duration-160`,只写 `transition-colors` 不写时长就是这一档) | 控件换颜色、浮层 / 菜单 / 说明 / 弹窗进出、折叠区块、东西挪到新位置 |
| 慢 | 240ms(`duration-240`) | 从窗口边滑进来的抽屉、大图放大 |
| 余韵 | 600ms(`duration-600`) | 只给「刚做完」的高亮慢慢退掉 |

- 缓动两种:出现用 `ease-enter`(先快后慢),消失用 `ease-exit`(先慢后快,`data-[state=closed]:ease-exit`)。
- **该动的**:东西出现 / 消失 / 换了位置(让眼睛跟得上去哪了)、状态变了(悬停、选中、刚做完)。
  **不该动的**:进页面时整页飞入、数字滚动、为了「有活力」的装饰性循环。循环动画只给「还在做」(转圈、骨架屏、录音灯、语音浮标)。
- **减少动态**:全局规则把过渡和动画压成一瞬、循环的只走一遍、停在原样;转圈例外 —— 放慢、不停。JS 驱动的动自己判:
  画布视口走 `canvasCameraDuration`,别处用 `matchMedia("(prefers-reduced-motion: reduce)")`。

## 九、视觉焦点

- 一屏一个主动作(见「按钮」)。
- 挨着值的动作用行内档,不比值醒目。
- 提示条(右下角)让开贴底的输入区:贴着窗口底边的输入框挂 `data-toast-avoid`,提示条伸进来就抬到它上面。
- 状态色(成功、警告、错误)只用在表示状态的地方,不拿来装饰;错误态是红字 + 红描边,不是整块红底。

## 十、状态

| 状态 | 规格 |
|---|---|
| 悬停 | 幽灵 / 行内 / 描边:显出次级底色;实心:底色淡 10%。中档时长 |
| 聚焦 | 2px 聚焦环(`--ring`);按钮只在键盘聚焦时、字段只要有焦点就显示 |
| 按下 / 选中 | 强调底色 + 强调色前景(分段选中项、`aria-pressed`、胶囊选中) |
| 禁用 | 50% 不透明、不能点;说得出原因就说(`disabledReason`) |
| 在跑 | 按钮第一个图标换成转圈、不能再点;列表、面板用骨架屏 |
| 出错 | 字段红描边 + 下面一行红字;整块出错用空状态的报错样子(一句人话 + 「重试」+ 折起来的「详情」) |

## 定稿与落地

2026-10 维护者拍板,全部按规格(第 2 步落进基础组件):

1. `md` 方钮 36 → 40,和原来另起的 `icon-lg` 合成一档,只叫 `icon`。顶栏、列表行尾、输入框发送键这几处原来用 36 的,
   按「场景 → 档位」换成了 `icon-sm`;挨着字段、页头那几处是 `icon`。
2. `xs` 文字按钮里的图标 16 → 14;只有图标的按钮不变。
3. 分段控件三档(md 40 / sm 32 / xs 28),原来用 className 压高度的十几处换成了档位。
4. 胶囊筛选 28(`Chip`)。
5. 字段出错时描边和聚焦环变红(`FIELD_INVALID`)。
6. 单选基础件(`RadioGroup`)。
