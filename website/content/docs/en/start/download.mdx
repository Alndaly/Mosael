Mosael is local-first: editing local media and exporting can work offline. A workflow needs a network when its nodes do. Configure a provider or subscription login for remote AI; download model weights before using local transcription or voice cloning.

## Download

Current stable version: **[GitHub Releases](https://github.com/Alndaly/Mosael/releases/latest)**.

Installers are published on **[GitHub Releases](https://github.com/Alndaly/Mosael/releases)**:

| Platform | Artifact | Notes |
| --- | --- | --- |
| macOS | `Mosael-<version>-arm64.dmg` | Apple Silicon (M-series) |
| Windows | `Mosael.Setup.<version>.exe` | Windows 10 / 11 (x64), NSIS installer |

The app silently checks the latest stable Release after launch and prompts you to download; there is also a "Check for updates" button under Settings → Local backend → Version. GitHub prereleases are opt-in and must be downloaded from the Releases page explicitly.

<Aside type="note" title="Installer signing">

Version 1.2.0 is available. The macOS application and DMG are Developer ID signed, securely timestamped and notarized by Apple, with notarization tickets attached. On supported Macs with fingerprints enrolled, the browser pool can use device-bound Touch ID passkeys.

Windows installers remain unsigned and may trigger an unknown-publisher SmartScreen notice. Verify the download source before proceeding.

</Aside>

- The backend engine and ffmpeg are bundled — works out of the box.
- Local transcription / voice-clone models download on first use (hundreds of MB to several GB); keep **10GB+** of disk free.

## Run from source (development)

From the repository root:

```bash
pnpm install
pnpm dev          # backend + frontend + Electron
```

Package the desktop build:

```bash
pnpm build:mac    # frontend + sidecar + publisher + backend (PyInstaller) + .app
pnpm dist:mac     # same flow, produces a .dmg for distribution
```

Local macOS packaging requires a signing identity, provisioning profile and notarization credentials; see the repository’s [macOS signing guide](https://github.com/Alndaly/Mosael/blob/main/docs/MACOS_SIGNING.md).

Official releases are built by CI: maintainers push a `v*` tag and GitHub Actions packages macOS and Windows and attaches both installers to the Release. Tags with a suffix such as `-beta1` remain prereleases and do not replace the latest stable build (see the repository README).

## Where your data lives

Everything (accounts / projects / media / settings) lives on **your own machine** in `~/.mosael` (Windows: `C:\Users\<you>\.mosael`), outside the app bundle — upgrades and reinstalls keep your data.

Set the theme, background and interface font in [Appearance](/docs/guides/appearance). With a remote backend, project data lives on that server. Back up the active backend data directory before upgrading.
