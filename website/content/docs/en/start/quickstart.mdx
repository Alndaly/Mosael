<Steps>

1. **Sign in / create a local account**

   On first launch Mosael asks you to sign in or register a local account (data stays on your machine). You can also switch to a team server.

   <Shot src="/media/screens/en/login.png" alt="Mosael sign-in page" />

2. **Configure model providers (for AI features)**

   Open Settings and use the **AI Chat / AI Image / AI Video / AI Audio** sections to "Add provider", pick a vendor and paste its API key.
   See [Model connections](/docs/guides/providers).

3. **Create a project, import or generate media**

   Create a project from Home. Drag local videos into the **Media** library, or ask the agent in **AI Studio** to generate assets from a description.

4. **Edit on the timeline**

   On the **Edit** page, drag media onto tracks; polish the cut with transcript-driven deletions, ripple delete, speed ramps, color grading, subtitles and filters, then export.

   <Shot src="/media/screens/en/editor.png" alt="Mosael editor: multi-track timeline" />

5. **Review and publish (optional)**

   On the **Publish** page, pick signed-in social accounts, set title/description/tags, review the video, destination and post, then submit.
   See [Publishing](/docs/guides/publishing).

</Steps>

You can start with planning instead of editing: collect a script in [Notes](/docs/guides/notes), lay out references on a [board](/docs/guides/boards), or rehearse a shot in [3D scenes](/docs/guides/scenes). These steps do not require a cloud model connection.

<Aside type="tip" title="Configure before running">

Choose your own model providers, media inputs and publishing accounts. Agent tools that require approval show confirmation cards; a workflow you start executes its configured steps.

</Aside>

After signing in, use [Appearance](/docs/guides/appearance) to preview themes, backgrounds and Chinese/English fonts. Sign into platform accounts in [Browser Pool](/docs/guides/browser-pool) before selecting them in Publish.
