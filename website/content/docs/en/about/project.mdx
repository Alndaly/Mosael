## Tech stack

| Layer | Technology |
| --- | --- |
| Desktop shell | Electron (with a built-in publish executor driving embedded browser views for logins / uploads) |
| Frontend | Vite + React + TypeScript + Tailwind |
| Backend | FastAPI (Python) + SQLite, single source of truth; packaged with PyInstaller |
| AI agent | Embedded Node.js sidecar based on pi-agent-core / pi-ai, using Mosael tools |
| Docs site | Next.js (this site) |

All user data lives locally in `~/.mosael` — no cloud dependency.

<h2 id="media-credits">Capture notes and media credits</h2>

Documentation targets 1.4.1. Unchanged captures retain their original provenance. The 1.4.1 changes are not recaptured yet: the hatched “media offline” placeholder on the timeline, the offline frame in the monitor and the matching notice in the inspector; “Split here” and “Save this frame” now in the timeline toolbar (the row above the monitor is gone, so the editing captures still show the old layout); the new “Max output tokens” field in model settings, the source notes for both limits and the thinking-level hint; the new “permanent delete” badge on confirmation cards; the re-coloured reference chips in agent messages and the “Add reference” button in the composer; the new “Build a 3D blockout” and “Render a blockout reference” nodes on the workflow canvas, the “Topic to finished video” template at v6 and the new asset-group picker on generation nodes; the resizable inspector and agent panes on the 3D scene page; and the whole surface of the agent modelling inside Blender (viewport frames in tool results and the images view_scene brings back). The 1.4.0 changes are not recaptured either: the Generate subtitles and Dub subtitles nodes and the “Translated dubbing with subtitles” official template on the workflow canvas, 3D scene card thumbnails and list alignment, the note editor's code blocks and error notice, the quality note on URL import, the agent's context meter and confirmation-card wording, and in Settings the “Where parameters come from” picker and “Describe this endpoint” parameter-set form, the model-list placeholder shown while a connection expands, the queued-message strip above the agent composer, the regrouped Settings page, the separation engine page and asset action, the AI Studio Audio tab, the subtitle dubbing form now on the editor's Voice tab (the dubbing captures still show the old popover on the Subtitles tab), the noise reduction dialog and Settings → Noise reduction page, the transcript cleanup canvas with its new denoise node (the workflows capture still shows the older graph), the four-way “original audio” field on the dubbing form, the node inspector's dropdowns now showing readable option names, and the task centre that announces a run once. Empty agent and publishing views mean no run has occurred, not a successful AI result or platform post.
