素材库是所有文件进入 Mosael 的地方：本机上传、屏幕/摄像头录制、从链接下载，以及渲染、配音、
AI 生成的产出。它们**走同一条入库路径**，所以无论从哪来，缩略图、波形、时长探测都一样不少。

![素材库：网格视图、标签筛选、多选](/media/screens/media.png)

## 导入

- **导入**：选文件（可以一次选多个），或直接拖进窗口。多个文件逐个上传，某个失败不影响其余，
  最后会说明导入了几个、哪个没进来、为什么。Mac 录屏这类 `.mov` 视频会原样换成 `.mp4` 容器保存
  ——画面和声音数据不重新编码、画质不变，只是在应用里拖进度条不会再卡顿。
- **录制**：录屏幕、摄像头、麦克风，或同时录制屏幕与摄像头；录完直接进库。
- **从链接导入**：见下。

### 同时录制屏幕与摄像头

在「录制素材」里选择「**屏幕 + 摄像头**」，选好摄像头与麦克风后开始录制。两路采集会同步开始、
同步停止，并分别预览。停止后素材库会新增**屏幕录制**和**摄像头录制**两条素材，而不是把摄像头
提前叠进屏幕画面；这样进入剪辑页后仍可分别裁切、调色、缩放和排布。若任一路没有录到有效内容，
本次双录制都不会导入，避免只留下半套素材。

需要自拍式构图时可打开「**镜像摄像头**」。摄像头预览与最终摄像头素材都会水平翻转，屏幕素材保持
原样；这个选择会记住，之后再次录制时继续沿用。

Mosael 不会在打开录制器时直接读取摄像头或麦克风。选择需要设备的录制方式后，点击「**申请权限**」
才会触发系统授权。授权之后，选中含摄像头的录制方式时摄像头立即打开并显示实时画面（镜像开关同样
作用于预览），开始录制时直接沿用这路画面——摄像头刚打开的那一小段曝光还没调好的暗画面不会被录进去；
切到不含摄像头的方式或关闭录制器时摄像头随即释放。要录麦克风的方式（摄像头、屏幕 + 摄像头、麦克风）
在授权后同样会提前打开麦克风，录制器里显示实时音量，开录前就能确认有声音；录制中的控制器上也有这根音量条。如果权限曾被拒绝，录制器会保留可操作的错误状态，并提供对应的系统设置入口与
重试操作。屏幕与系统音频权限由操作系统的共享选择器申请，这是 macOS 对这类权限的系统限制。

开始后录制器会收成右下角的控制器，不会遮住或锁住应用。你可以继续浏览素材、进入剪辑页或使用其他
功能；录制不会因为切页而中断，停止后文件仍会回到**开始录制时**所在的工作区或项目。

录制屏幕时「**系统音频**」默认开启，用来同步收录电脑正在播放的声音；若系统共享选择器另有
「共享音频」选项，也需要在其中允许。系统没有返回音频轨道时，Mosael 会停止本次捕获并提示重新
选择，不会静默生成无声素材；关闭开关则只录画面。「屏幕 + 摄像头」模式下，系统音频随
屏幕素材保存，麦克风随摄像头素材保存，因此两路声音仍能在时间线上分别处理。能否捕获系统音频
取决于当前系统及其共享选择器是否提供该能力。macOS 上若此前拒绝过权限，可从录制器直接进入
「隐私与安全性 → 屏幕与系统音频录制」重新开启。

## 从链接导入

粘一个视频或播放列表链接，先看清单再决定下哪几条。

![从链接导入：输入地址并选择登录身份](/media/screens/url-import.png)

**先探再下**是刻意的：一个链接可能是一条视频，也可能是一整个播放列表——几百条、几十 GB。
所以粘完先探元数据（不碰媒体流），把清单摆出来勾：单条自动勾上，播放列表一条都不勾。

- **音频 / 视频**在下载前选。只要人声去转写的人，不该为此付几百 MB 和一次转码。
- **画质上限**只列这条链接**真有的**档位——探测时就知道它最高能给多少，摆一个选了没用的档位
  是让界面替站点撒谎。选的是"上限"而不是精确值：同一批里每条能给的画质并不一样。
- **列表翻页**：一次列 200 条，往后翻用「下一批」。频道能有上万条，与其把上限提到让人等三分钟，
  不如让他往后翻。

### 需要登录才能看的内容

会员视频、私享列表、地区受限的内容，不带登录态就只能看到"不可用"。而这个应用本来就把所有持久
登录攒在[浏览器池](/docs/guides/browser-pool)里，所以直接**借一个登录身份**即可，不必去别处
导一份 cookie。

可用画质取决于站点、素材与登录状态，以本次探测返回的档位为准。

分 P 视频、合集这类链接，清单里每条都带自己的标题（合集名已在表头，不再重复）；下载后的素材就用
这个标题命名。

取不到时会说清是哪一种：**这个网站或链接类型不支持**、链接里**确实没有**视频或音频、**需要登录身份**
（去上面「登录身份」里选一个已登录的）、内容**不可用**（私密、删除、地区限制），还是**网络连不上**。

下载跑在后台任务里，进度在任务中心；一条失败不拖垮整批，下好的留在库里，失败几条会说出来。

## 标签与筛选

- 顶部按类型筛（视频 / 音频 / 图片），或用标签。标签可以同时勾几个；勾了两个以上时可以选
  「同时带有」还是「带有任一」。
- 多选后可批量打标签、删除。
- 「对比」：多选同一种素材后把它们并排放，用来挑版本。图片并排看；视频铺在一屏里一起播，
  一个播放键控制全部，默认静音、点某一条的喇叭只听它，逐帧和拖时间轴对所有条同时生效。

## 预览与详情

点击素材打开预览：视频使用独立播放控件，音频显示波形和播放进度，图片可直接查看。右侧展示名称、类型与文件信息；长标题和 ID 会在面板内换行。

## 处理声音

音频和视频素材的「更多」菜单与右键菜单里有两项，都**产出新素材，原素材不动**，排成任务在后台跑，
进度在任务面板里看。剪辑台里在片段上右键也有同样两项，作用于这个片段引用的素材。

- **降噪…**：选方式和强度。视频降噪后画面原样保留，只换声音。几种方式各有取舍：

  | 方式 | 适合 | 音乐 | 准备 |
  | --- | --- | --- | --- |
  | 内置降噪 | 空调、风扇、电流声这类持续的底噪 | 不受影响 | 不用装 |
  | DeepFilterNet | 以说话为主的录音，键盘、碗碟、人声嘈杂也能去，说话声最自然 | 会被去掉 | 在「设置 → 本机引擎 → 降噪」下载一次（约 30 MB） |
  | RNNoise | 同上，轻量些，效果不如 DeepFilterNet | 会被压低 | 不用装 |

  默认是内置降噪：说"降噪"时通常没想把配乐也拿掉。内置降噪会先量出这段音频的噪声有多大再下手，
  所以同一个档位对轻重不同的底噪都合适；以说话为主的素材，换成 DeepFilterNet 效果明显更好。
  只想要说话声、其余全部不要，那不是降噪，用下面的「分离人声与背景音」取人声那一份。
- **分离人声与背景音**：拆成「人声」和「背景音」两份新素材。背景音是人声之外的全部：音乐、环境声、
  音效。引擎在本机跑，要先在「设置 → 本机引擎 → 人声分离」里装好；长素材在 CPU 上要跑十几分钟。
  那一页说的「已安装」是真的试着把引擎加载了一遍，不是看目录在不在；装到一半断掉时它会说
  「运行环境不完整」，再点一次「安装」把缺的依赖补齐。

工作流里有同名的「降噪」「分离人声与背景音」节点（在「音频」分类），也可以直接让智能体做——它会
先开一张确认卡。

## 视频转 GIF

右键视频素材选「**转为 GIF**」，可调帧率、宽度、起点与截取时长。转换作为后台任务执行，完成后
新增一条 GIF 素材并记录来源；**原视频不修改、不覆盖**。同一能力也可在工作流使用「视频转 GIF」
节点批量编排。
