「知识库」把你的资料变成可检索的知识，供智能体与工作流的**知识库检索**节点使用。全程本地。

## 导入

![知识库：数据集与文档列表(文档 / 召回测试 / 知识图谱 / 设置)](/media/screens/kb.png)

**新建知识库并导入第一篇文档**——支持 Markdown / PDF / Office 等格式，入库自动分块，状态变为「已就绪」即可被检索：

![操作演示：新建知识库，导入 Markdown 文档并完成分块](/media/gifs/knowledge-base.gif)

左栏顶部三个入口：

- **新建笔记**：直接在内置编辑器里写(tiptap 富文本)。
- **导入网址**：抓取网页正文转 Markdown。
- **导入文件**：文档转换引擎(markitdown / MinerU)把 PDF、Office 等转成 Markdown。

## 检索

搜索框走本地**混合检索**:

- 全文(SQLite FTS5 trigram)+ 向量(嵌入)+ 图谱(实体关系扩展),RRF 融合排序。
- 检索不依赖外部服务，离线可用。

## 用在别处

- **AI 工作台**的智能体会按需检索知识库。
- **工作流**的「知识库检索」节点把命中片段作为文本输出，接给下游 LLM 等节点。

文档可重命名 / 删除(右键)。
