工作流将素材、模型与工具连接成可复用的执行步骤。先配置节点输入并完成就绪检查，再手动运行；需要重复执行时，可设置定时或 Webhook 触发。运行记录保留各节点的输入、结果与错误，方便检查和调整。

## 下载与导入官方模板

[官网工作流列表](/workflows)提供「从主题到完整视频」「口播与访谈智能整理」和「视频译配 · 字幕与配音」三套官方模板。

1. 下载 `.mosael-workflow.json` 文件，无需解压。
2. 在应用中选择目标工作区，进入「工作流」，点击「导入工作流」并选择文件。
3. 打开导入后的工作流，为模型节点选择自己的供应商与模型，填写素材等必需参数，再通过就绪检查后运行。

下载文件不包含账号密钥或私人素材，也不会自动选择本机的默认模型。导入需要 1.5.2 或更新的版本。

| 模板 | 做什么 | 需要 |
| --- | --- | --- |
| 从主题到完整视频 | 主旨 → 并行写脚本与视觉圣经（定下角色与场景）→ **每个角色画一张三视图、每个场景画一张设定图** → 时间分镜（景别、焦段、机位角度、运镜）→ **按分镜自动搭 3D 白模**，每镜一个布景台、一台相机，运镜写在相机轨迹上 → 逐镜（最多 3 镜并发）：渲出白模首尾帧和运镜视频 → 走**首尾帧**（按白模机位画首帧，大幅运镜时加尾帧，再生成视频）或**参考素材**（三视图、设定图和白模运镜视频直接交给视频模型）—— 由分镜逐镜决定，能选哪条取决于视频模型收什么；镜头语言（焦段、机位高度、推拉摇移）从白模机位**算出来**补进提示词 → 按镜头顺序接上时间线 → 口播字幕 → 导出。白模场景留在「3D 场景」里，可以打开调整机位。配了音色时口播**放在这一镜画面开始的那一秒**，比镜头长时加速塞进去（最多 1.5 倍） | 对话模型、能带参考图出图的图像模型（如 Seedream 4）、支持首帧或参考素材的视频模型（如 Seedance 2.0）；口播可选：克隆音色 |
| 口播与访谈智能整理 | **先去除底噪**（内置降噪，不动背景音乐；转写因此更准）→ 带时间码逐字稿 → 诊断停顿、口头禅、重复 → 在新项目里按高置信度范围波纹裁切 → 导出。降噪产出新视频，原片不动 | 对话模型、转写引擎、视频素材 |
| 视频译配 · 字幕与配音 | 逐句转写 → 逐句翻译（AI 模型，节点上可换 Google）→ 按原时间码铺译文字幕 → 逐条配音并变速压回原长度 → 拆掉原声里的人声、保留背景音乐 → 导出。选择「只去掉人声」但分离引擎不可用时会在配音开始前明确失败，不会改成整轨静音 | 转写引擎、对话模型、一把嗓子（克隆音色或引擎音色，Edge 的免费语音不用配置）、提前装好的人声分离引擎 |

降噪节点默认用内置引擎；以说话为主、噪声杂（键盘、碗碟、人声嘈杂）的素材，可以在节点上换成
`deepfilternet`（先在「设置 → 本机引擎 → 降噪」下载），它会把音乐一起去掉。

## 画布与节点

![工作流画布：口播与访谈智能整理官方模板](/media/screens/workflows.png)

**从零搭一条工作流**——「添加节点」放入「LLM 生成」「AI 生成素材」，拖动端口连线；点节点就在它下方就地配置参数，画布还内置 AI 助手可以代劳搭建：

![操作演示：打开节点目录并查看素材转写节点参数](/media/gifs/workflows.gif)

- 入口是工作流卡片列表；打开一张卡片后进入完整画布，左上角返回列表，右上角工具栏管理节点、运行和历史。
- **添加节点**：工具栏「添加节点」选类型。按用途大致分几类：

  | 类别 | 节点 |
  | --- | --- |
  | 流程 | 开始、输出、条件分支、延时、遍历循环、条件循环、子图、调用工作流 |
  | AI | LLM 生成、AI 生成素材、翻译、批量翻译 |
  | 音频 | 素材转写、语音合成、字幕配音、分离人声与背景音、降噪 |
  | 素材与时间线 | 素材、新建项目、新建成片项目、把素材接到时间线、加一条轨道、清空时间线、看一眼时间线、按时间批量整理、时间线高级操作、生成字幕、视频转 GIF、导出时间线、素材筛选、素材打标签、素材整理 |
  | 知识库 | 检索笔记、读取笔记、保存为笔记 |
  | 发布 | 发布、发送通知 |
  | 数据 | HTTP 请求、代码、文本模板、JSON 提取、文本处理 |
  | 插件 | 插件工具 |
  | 浏览器 | 打开 / 导航 / 点击 / 输入 / 上传文件 / 提取 / 等待 / 滚动 / 执行脚本 / 关闭 |
- **连线**表示执行顺序；从节点右侧接点拖到下游节点左侧接点。**条件分支**节点有「真 / 假」两个出口。
  挂在某个出口上的节点，是否运行只看这个分支；它另从别的节点取值的数据连线只决定取什么值，不会让它在分支不成立时也跑起来。
- **遍历循环**默认一项跑完再跑下一项。各项互不依赖时（比如逐镜生成画面），在高级选项里把「同时跑几项」调到 2–4，
  结果仍按原顺序排。任何一项失败后**不再开始新的项**（已经在跑的会跑完，它们提交出去的生成照样会取回来），
  报错会列出所有失败的项和因此没开始的项数。不写「每次迭代的输出」时，每一项交出这一轮的全部产物，连同这一项本身
  （`loop.item`），下游可以再遍历这份结果。
- **语音合成、字幕配音**先选引擎，再选音色：引擎选「克隆音色」时，音色是配音库里的那几把；选了某个引擎，
  音色就换成那个引擎自己的清单。换引擎会清掉已选的音色。
  工具栏可切**连线形态**：曲线(贝塞尔)或折线(直角)，按你的偏好记住。
- 点节点打开**属性面板**——它贴在节点**正下方**，节点**正上方**是一条悬浮键：左边按内容分档
  (**参数** / **高级选项** / **输出变量** / 跑过之后还有**本次产出**，**有才出**)，右边是能对这个节点做的事
  (进子图、删除)。「高级选项」收的是**留空也能跑**的旋钮，第一屏不糊你一脸采样参数。

### 顶部工具栏

与创意画板保持同一顺序：添加与撤销/重做、评论、标记与清单、搜索及视图、AI 助手。工作流专属的就绪检查、运行历史和运行按钮放在右侧一组。

「更多」菜单包含重命名、版本历史、导出为文件和删除；版本历史行尾显示当前版本号，删除单独成组、需确认。菜单可用 ↑↓ 选择、Esc 关闭。⌘F 查找节点，命中的节点在画布上描圈，Enter / ⇧Enter 逐个跳转。窗口较窄时，箭头可浏览其余工具，助手、运行组和「更多」始终可见。

节点浮层与创意画板共用柔和的表面风格：上方操作条切换内容，下方参数表单独立滚动，名称和值两列保持相同控件高度。

### 挡住了怎么办

节点密集或悬浮面板叠在一起时，选中后按 **⌘/Ctrl + ]** 提到最上、**⌘/Ctrl + [** 压到最下。
悬浮面板和画布节点用同一组快捷键，但**节点永远不会盖住悬浮面板**——不然属性面板会被自己正在
编辑的节点埋掉。

节点表单使用半透明模糊背景，与画布内容分层。打开局部智能体窗口后，点击节点会按未被遮挡的可视区域居中；媒体节点提供紧凑预览，详细播放在预览窗口中进行。

## 变量：把上游输出接到下游输入

节点执行后把结果写进上下文，输出变量形如 `{{节点id.输出名}}`(如 `{{llm-1.text}}`)。下游字段用它引用上游数据。

每个字段可在**两种输入方式**间切换(标签行右侧的小胶囊):

- **手动**：直接填值 / 选项；模板字段里敲 **`@`** 唤出上游变量(可继续输入筛选)，或点下方变量 chip 插到光标处。
  这个节点还没有上游时，`@` 会告诉你「先连一条边过来」，而不是毫无反应。
- **连接**：字段变成一个接点，从**上游输出**下拉里选一个，等价于把 `{{上游.输出}}` 绑上去。切回手动会保留原值，不丢数据。

## 就绪检查 / 运行门禁

工具栏「**就绪检查**」聚合所有阻断项：缺必填、模型 / 服务商没配、节点未连接到流程、引用了已删除的节点等。

- 画布上有问题的节点挂**告警角标**(红 = 阻断，琥珀 = 提醒),tooltip 列出问题。
- 有 error 时「运行」按钮禁用；每条问题可点击直达对应节点。
- 删了上游节点后，引用它的字段会标为**失效引用**，可「重新指向」到别的上游输出或移除。

跑起来之后,工具栏那颗「运行」会变成「停止」;任务中心里点开那次运行的详情,左下角也有「取消任务」。
中止是**节点粒度**的:当前这一步跑完后停下,已经产生的结果(素材、时间线、3D 场景)都保留,派生的
子任务一并取消。

「**可用的 3D 道具**」节点把这个工作区里的 3D 模型(通常是在 Blender 里建好再收进来的)列成一份清单 ——
每一份的 id、名字和实测长宽高 —— 接进设计白模布景那个节点的提示词,布景里就能摆上真实道具,而不是
只用方块和圆柱拼。留空表示这个工作区里的全部模型;读不了的(压缩网格、面数超预算、文件不在)不进
清单并注明。

「视频转 GIF」节点接收视频素材 id，可设置帧率、宽度、起点与时长；输出是**新 GIF 素材 id**，
不会覆盖上游视频。

## LLM 生成风格

LLM 节点用**生成风格**(精确 / 均衡 / 创意)替代裸 temperature，降低配置门槛。

## 触发器

设置独立计划与查看历史，请见[定时任务](/docs/guides/scheduler)。

工作流可绑到「定时任务」上，触发方式：手动、定时(cron)、Webhook。也支持**批量**跑同一工作流。

<Aside type="caution" title="定时任务需要应用在运行">

定时调度跑在本机后端里，而后端是 Mosael 的子进程 —— **完全退出应用，定时任务就不会触发**。

所以关窗只是把它收进托盘、并不退出；要真正退出请用托盘菜单或 ⌘Q。想让它开机就守着，在
设置 → 后端里打开「开机时启动」。退出期间错过的任务会在下次启动后补跑一次(按当前时间
重算下次时间，不会把错过的每一次都堆起来跑)。

</Aside>

### 别人改过的版本

版本历史里每一版都写着是谁存的。一次运行用到私有发布账号、浏览器档案或这台电脑上的文件时，除了点运行的人，
**被执行那一版的作者**（或认可过它的人）也要用得了 —— 调用工作流节点调起的子流程，它自己那一版也算。同事改过、
而要借你的东西的那一版，运行会停下并说明是哪条工作流的哪一版；确认改动后，在运行历史或版本历史里点「认可这一版」。
认可不改图、不增版。

## 让 AI 帮你搭

工具栏「AI 助手」复用全局持久会话池：用自然语言描述你想要的流程，它来搭建 / 修改节点；改动先出
确认卡等你批准。左上角标题就是当前会话，点击可搜索或切换；面板既可停靠在画布旁，也可悬浮。

## 评论与标记

顶部评论与旗帜按钮分别进入评论模式和标记模式；两种模式互斥，Esc 退出。它们旁边的眼睛按钮分别一键显示或隐藏评论、标记，不删除内容。标记不在添加节点菜单里。

标记模式下点击空白处放置位置书签，配置名称和跳转快捷键；同一张画布一次只打开一个标记弹窗。快捷键右侧可清除绑定，底部可删除标记。评论模式下点击空白处写评论，支持 `@` 工作区成员；提交后仍保留可交互的提及标签。自己的评论可点击铅笔编辑。相邻评论点可直接切换，不被当前弹窗的透明区域挡住。

模式切换和撤销不改变数据节点的连线。工具组用分割线区分，评论/标记是独立协作层，不参与生成和工作流运行。
