工作流是**做一次，跑无数次**：把做过一次的事变成换个输入就能再跑、没人看着也能跑、成批地跑的流程。开始节点的入参和模板让它可复用；素材、时间线、字幕、导出、发布可以一路做到成品；循环、并发、分支成批处理，失败时说清是哪一条；定时、Webhook、智能体或别的工作流都能调用它；每次运行每个节点的输入、结果与错误都查得到。流程本身就是产品。还在看着改、比几个版本挑一个，用[创意画板](/docs/guides/boards)。

工作流将素材、模型与工具连接成可复用的执行步骤。先配置节点输入并完成就绪检查，再手动运行；需要重复执行时，可设置定时或 Webhook 触发。运行记录保留各节点的输入、结果与错误，方便检查和调整。

## 下载与导入官方模板

[官网工作流列表](/workflows)有全部官方模板的说明、前置条件和中英两份下载；应用里的模板库也能直接添加。

1. 下载 `.mosael-workflow.json` 文件，无需解压。
2. 在应用中选择目标工作区，进入「工作流」，点击「导入工作流」并选择文件。
3. 打开导入后的工作流，为模型节点选择自己的供应商与模型，填写开始节点的必填参数，通过就绪检查后运行。

下载文件不包含账号密钥或私人素材，也不会自动选择本机的默认模型。导入需要 1.8.3 或更新的版本。节点名跟着下载的那一份语言走。

| 用途 | 模板 |
| --- | --- |
| 成片 | **从主题到完整视频**（主旨 → 脚本与视觉圣经 → 角色先到资产库里认，新的画三视图 / 设定图并存成资产 → 分镜 → 自动搭 3D 白模 → 逐镜按白模生成视频 → 口播字幕 → 导出；最贵的一条，默认最多 8 镜）、**长视频切多条竖屏**（挑出最多 12 段，各建一条竖屏时间线配短句字幕） |

### 开始节点：参数、必填与选项

开始节点的参数是一张三列的表：**参数名 / 默认值 / 必填**，「加一项」添一行。

![开始节点的参数表:参数名 / 默认值 / 必填,「加一项」](/media/screens/workflow-start-params.png)

- **每一行一个「必填」勾选**。必填、又没有默认值的，运行时要填；没填就不让跑 —— 不会拿占位示例当真参数跑下去。
- **选项参数**：默认值那一格是下拉（「选一个」），只能从给定的几项里挑。某一项的前提没备好时标「未就绪」，照样能选，运行前会说清缺什么
  （分析类模板的数据来源就是这样）。
- **开始节点有几个参数就有几个输出口**，下游直接从对应的口子接线。
- 引用开始节点没声明的参数、默认值不在选项里、参数名空着或重名，就绪检查都会指出来。

![选项参数:分析类模板的 data_source 是下拉,「内嵌浏览器」和「TikHub · 未就绪」](/media/screens/workflow-start-options.png)

### 循环与分支

- **条件分支**有「真 / 假」两个出口。挂在某个出口上的节点，是否运行只看这个分支；它另从别的节点取值的数据连线只决定取什么值，
  不会让它在分支不成立时也跑起来。条件节点的「左值」接了上游时，画布上会画出它的输入口。条件对空列表、空对象判空，两边都是数时按数值比。
- **循环·遍历**默认一项跑完再跑下一项。各项互不依赖时（比如逐镜生成画面），在高级选项里把「同时跑几项」调到 2–4，结果仍按原顺序排。
  「最多取前几项」给列表封顶；「一项失败时」可选「整条循环失败」（默认：任何一项失败后**不再开始新的项**，已经在跑的会跑完、提交出去的生成照样取回）
  或「记下这一项，接着跑别的」—— 跑完在「失败的项」里列出来、通知里也写明。不写「每次迭代的输出」时，每一项交出这一轮的全部产物，连同这一项本身
  （`loop.item`）。
- **循环·条件**最多 50 轮（可调，上限 1000）。
- **拆成几批**把列表按固定条数切成不重叠、顺序不变的批次，再接循环·遍历。适合评论、检索结果等长清单，避免把全部内容一次塞给模型；它同时输出批次数和原始总条数。
- **语音合成、字幕配音**先选引擎，再选音色：引擎选「克隆音色」时，音色是配音库里的那几把；选了某个引擎，音色就换成那个引擎自己的清单。换引擎会清掉已选的音色。

### 顶部工具栏

与创意画板保持同一顺序：添加与撤销/重做、评论、标记与清单、搜索及视图、AI 助手。工作流专属的就绪检查、运行历史和运行按钮放在右侧一组。

「更多」菜单包含重命名、版本历史、导出为文件和删除；版本历史行尾显示当前版本号，删除单独成组、需确认。菜单可用 ↑↓ 选择、Esc 关闭。⌘F 查找节点（搜整张图，也按 id 搜），命中的节点在画布上描圈，Enter / ⇧Enter 逐个跳转。⌘S 保存，⌘Enter 运行。窗口较窄时，箭头可浏览其余工具，助手、运行组和「更多」始终可见。

### 挡住了怎么办

节点密集或悬浮面板叠在一起时，选中后按 **⌘/Ctrl + ]** 提到最上、**⌘/Ctrl + [** 压到最下。
悬浮面板和画布节点用同一组快捷键，但**节点永远不会盖住悬浮面板**——不然属性面板会被自己正在
编辑的节点埋掉。

节点表单使用半透明模糊背景，与画布内容分层。打开局部智能体窗口后，点击节点会按未被遮挡的可视区域居中；媒体节点提供紧凑预览，详细播放在预览窗口中进行。

## 变量与引用：把上游输出接到下游输入

节点执行后把结果写进上下文，下游字段用 `{{节点id.输出名}}` 这样的引用取上游数据。**界面上不露出 `{{…}}`**：参数、提示词编辑器、
失效引用提示、就绪检查里的引用都显示成「**节点标题 · 输出 · 字段**」；指不到的标红并说明 —— 「找不到节点……它可能被删了、改了名」或
「……没有这个输出」，重新选一个上游输出即可。

![文本模板里的引用显示成「节点标题 · 输出」标签,不露出双花括号的引用写法](/media/screens/workflow-reference-tags.png)

节点卡片上的数据端口与属性一一对应：配置里有哪些具名输入、输出变量里有哪些具名输出，就显示对应端口。流程边只表达先后顺序，数据边明确写出传的是哪个属性。

**画布把引用画成一条淡淡的点线**：只管先后（引用到谁就等谁落定再开始），**不会让被引用的节点运行**，点不中，悬停说明是哪一处引用。
被引用的节点没接进流程、永远不会运行时，这条点线是错误色。

![画布上的引用画成淡淡的点线(只管先后,不会让被引用的节点运行)](/media/screens/workflow-references.png)

<Recording src="/media/videos/workflow-editor.mp4" poster="/media/screens/workflow-references.png" caption="实机操作:引用标签、开始节点参数表、就绪检查与执行历史(一张只用本机节点的工作流)" />

每个字段可在**两种输入方式**间切换(标签行右侧的小胶囊):

- **手动**：直接填值 / 选项；模板字段里敲 **`@`** 唤出上游变量(可继续输入筛选)，或点下方变量 chip 插到光标处。
  指向某样东西的字段（3D 场景、镜头、时间线、轨道、项目、账号、连接……）是下拉：先列这个工作区里的，后面列上游的输出；
  循环体里的 `{{loop.item.…}}` 也能在搜索框里敲出来。跟着别的字段走的下拉（镜头跟着场景、轨道跟着时间线）在那个字段接的是上游时，
  会说清单要到运行时才知道。这个节点还没有上游时，`@` 会告诉你「先连一条边过来」，而不是毫无反应。
- **连接**：字段变成一个接点，从**上游输出**下拉里选一个，等价于把那个引用绑上去。切回手动会保留原值，不丢数据。

「执行脚本」「代码」这类代码字段**不插值引用**：上游的值接到 `input`，作为 JSON 数据交进去 —— 网页里抓来的一段文字不能改写脚本。

## 就绪检查 / 运行门禁

工具栏「**就绪检查**」聚合所有问题，图标上带数字：红 = 阻断，琥珀 = 提醒（不阻塞运行），全部就绪时是「全部就绪，可以运行」。它查：
缺开始节点、缺必填、「几样填一样」的格子一样都没填、失效引用、引用了开始节点没有的参数、值不在选项里、空的循环 / 子图体、体里放了输出节点、
节点没接进流程、**引用了一定不会跑的节点**、模型 / 服务商没配或没钥匙、类型对不上、代码字段里写了引用、插件节点用不了（并说真实原因）……

![就绪清单:「2 项待解决」,开始节点缺两个必填参数,点一条直达那个节点](/media/screens/workflow-readiness-blocked.png)

- 画布上有问题的节点挂**告警角标**，tooltip 列出问题；每条问题可点击直达对应节点。
- 有阻断项时「运行」按钮禁用；按 ⌘Enter 会打开就绪清单。
- **会跑的节点引用了一定不会跑的节点时，运行前就拦下**：说清是谁引用了谁，「把它连进流程」；图是从官方模板建的，可以点顶上的「按新版重建」。
  此前这种引用跑起来只会拿到空的。
- **开跑前的检查只有一套**：编辑器运行、子工作流、智能体开卡、定时任务都用它。子工作流的必填参数、数字人授权、克隆引擎没装、视频模型不收的
  画幅、对话模型都没配，都在任何节点花钱之前说。

跑起来之后，工具栏那颗「运行」会变成「停止运行」；运行中再按 ⌘Enter 不会再起一次。任务中心里点开那次运行的详情，左下角也有「取消任务」。
中止是**节点粒度**的：当前这一步跑完后停下，已经产生的结果（素材、时间线、3D 场景）都保留，派生的子任务一并取消。

![执行历史:一次真实运行的每一个节点和用时(素材筛选、打标签、文本模板、保存为笔记,都在本机跑)](/media/screens/workflow-runs.png)

几个节点的细节：

- 「HTTP 请求」：JSON 请求体里插进来的上游文字按 JSON 转义，自动带 `Content-Type`；「非 2xx 算失败」默认是（高级里可以关）。
- 「浏览器 · 执行脚本」默认给脚本 20 秒；分页读取等确实需要更久的任务，可在高级选项里把超时调到最长 180 秒。
- 「**可用的 3D 道具**」把这个工作区里的 3D 模型列成一份清单（id、名字和实测长宽高），接进设计白模布景那个节点的提示词，布景里就能摆上真实道具。
- 「视频转 GIF」「宫格切分」输出的都是**新素材**，不覆盖上游。
- LLM 节点用「预设」（严谨 / 平衡 / 发散）替代裸 temperature；节点上的最大输出 Token 不会超过模型的输出上限。

## 分析类模板：账号、爆款、评论区

三张分析类模板给一个主页或作品链接（抖音、小红书、B 站），取账号资料、最近作品、视频数据和热门评论，算发布频率、时段、互动率、头部作品、涨跌信号，
写成笔记。为此工作流里有「解析自媒体链接」「整理作品与评论数据」「从链接下载素材」三个节点。

- **数据来源在开始节点的 `data_source` 下拉里二选一**：**内嵌浏览器**（不用配置、不花钱；小红书一定要登录、抖音多半要 —— 在模板的「用内嵌浏览器打开」一步上把会话方式改成
  浏览器池、挑一个已登录的档案；B 站不用登录；页面上的数字是约数）或 **TikHub**（要装 TikHub 插件、建连接、在插件页勾选模板要的那几个工具，按次计费、
  字段全、不用登录）。选了 TikHub 而它没备好（没装插件、没建连接、工具没勾、同一平台多了一条连接），**运行前就说清缺什么**，或者改选内嵌浏览器。
- **评论区洞察真实有多少条就分析多少条**：B 站走它自己的评论接口一页一页翻完（上限 1000 条，超过了如实说，楼中楼回复一并进分析），别的平台读评论区页面；
  全部评论按 80 条一批由模型逐批留观察笔记，最后综合成报告，评论再多也不丢。「评论数」参数只决定附表里列按赞前多少条。
- 没登录的档案打开要登录的平台，照实告诉你「没取到评论」，不会编。

## 触发器

设置独立计划与查看历史，请见[定时任务](/docs/guides/scheduler)。

工作流可绑到「定时任务」上，触发方式：手动、定时(cron)、Webhook。也支持**批量**跑同一工作流。

<Aside type="caution" title="定时任务需要应用在运行">

定时调度跑在本机后端里，而后端是 Mosael 的子进程 —— **完全退出应用，定时任务就不会触发**。

所以关窗只是把它收进托盘、并不退出；要真正退出请用托盘菜单或 ⌘Q。想让它开机就守着，在
设置 → 后端里打开「开机时启动」。退出期间错过的任务会在下次启动后补跑一次(按当前时间
重算下次时间，不会把错过的每一次都堆起来跑)。

</Aside>

### 别人改过的版本

版本历史里每一版都写着是谁存的。一次运行用到私有发布账号、浏览器档案或这台电脑上的文件时，除了点运行的人，
**被执行那一版的作者**（或认可过它的人）也要用得了 —— 调用工作流节点调起的子流程，它自己那一版也算。同事改过、
而要借你的东西的那一版，运行会停下并说明是哪条工作流的哪一版；确认改动后，在运行历史或版本历史里点「认可这一版」。
认可不改图、不增版。

## 让 AI 帮你搭

工具栏「AI 助手」复用全局持久会话池：用自然语言描述你想要的流程，它来搭建 / 修改节点；改动先出
确认卡等你批准。运行工作流的卡标题写着工作流名字，并钉住开卡时那一版 —— 批准之前图被改过就不跑，说清是哪两版。
左上角标题就是当前会话，点击可搜索或切换；面板既可停靠在画布旁，也可悬浮。

## 评论与标记

顶部评论与旗帜按钮分别进入评论模式和标记模式；两种模式互斥，Esc 退出。它们旁边的眼睛按钮分别一键显示或隐藏评论、标记，不删除内容。标记不在添加节点菜单里。

标记模式下点击空白处放置位置书签，配置名称和跳转快捷键；同一张画布一次只打开一个标记弹窗。快捷键右侧可清除绑定，底部可删除标记。评论模式下点击空白处写评论，支持 `@` 工作区成员；提交后仍保留可交互的提及标签。自己的评论可点击铅笔编辑。相邻评论点可直接切换，不被当前弹窗的透明区域挡住。

模式切换和撤销不改变数据节点的连线。工具组用分割线区分，评论/标记是独立协作层，不参与生成和工作流运行。
