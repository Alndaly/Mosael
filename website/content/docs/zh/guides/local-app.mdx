在侧栏打开「设置 → 本机应用」。这一页装的是**这台电脑上 Mosael 自己的事** —— 三行说的都是这一份安装：开机要不要自启、别的程序把文件交给它时怎么办、现在是哪个版本。它们只在这台设备上生效，换台电脑不跟着走；账号与工作区那一级的设置不在这里。「开机时启动」和「打开外部文件」两行只在桌面版里有。

## 开机时启动

「开机时启动」管的是**这一份安装**要不要随系统启动：打开后，登录系统时 Mosael 自动在后台驻留（托盘），关掉窗口只是收进托盘，不算退出。定时任务需要应用在运行才会到点触发（见[定时任务](/docs/guides/scheduler)），要用它就把这一项打开。

系统把这一项登记成待批准时，还要到系统的启动项设置里允许 Mosael（macOS：系统设置 → 通用 → 登录项；Windows：任务管理器 → 启动应用）；受管理的设备上，系统也可能直接拒绝这一项。

## 打开外部文件

「打开外部文件」管的是**别的程序把文件交给 Mosael**时的默认动作 —— 从访达 / 资源管理器的「打开方式」，或把文件拖到程序坞 / 任务栏的 Mosael 图标上：

- **入库**：导入素材库后就停在那儿（默认）。
- **打开预览**：同样先导入素材库，再多开一次预览 —— 文件仍然进了素材库；音频没有预览，只导入。

改完从下一个打开的文件起生效。

## 版本与检查更新

「版本」那一行写着这一份安装现在是哪一版。桌面版里它旁边还有「检查更新」：拿它跟 GitHub Releases 上最新的稳定版比一比，有新版就给一个「查看」入口打开发布页；已经是最新，或者没查通，也都会说清楚。

## 和「后端」的区别

这一页管的是**这台应用自己的行为**。**连的是哪台后端、是哪个工作区**，在「设置 → 后端」：那里是「服务器」（默认本机；填团队服务器地址可以切换，会先探活、再切换并重新登录）、「API 地址」和「工作区」，页面说明写明它仅供排查参考。切换服务器也在那里，把桌面端指到远程后端的步骤见[远程部署](/docs/guides/remote)。
