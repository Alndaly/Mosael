## 对话：智能体操作工程

![AI Studio 对话初始页:还没有对话,底部是输入框](/media/screens/ai-chat.png)

智能体通过 Mosael 的 MCP 工具**直接看你的工程、提改动**：检索素材、编排时间线、发起生成、乃至发布。

右栏「最近工具」旁的计数是**当前可用的工具总数**。它不是写死的：装了插件、
插件里勾了工具，这个数就跟着涨。工作流画布能做的事智能体都能做 —— 这一条由测试钉着，
不是一句愿望(见 [MCP 文档](https://github.com/Alndaly/Mosael/blob/main/docs/MCP.md))。

- **确认卡**：任何会改动工程 / 外部状态的操作，都会先弹确认卡，由你批准后才落地（见下一节）。
- **选择卡**：遇到岔路口——两三条路都说得通、而选哪条取决于你想要什么(发到哪个平台、
  要哪种风格)——它会把选项摊开让你点，单选多选都有，也可以「自己写一个」或者跳过。
  跳过时它按自己的判断继续，不会再问一遍。选择卡没有「本会话始终允许」—— 它问就是因为不知道答案，
  自动回答等于让它自己编一个。
  两种卡都会让它**停在那儿等你**，而不是问完自己接着跑。等太久(十分钟上限)它会按自己的
  判断继续或先收尾；你之后再作答，答案仍然会送到这次对话里。
- **技能**：做某一类事的方法，智能体用到时才读全文；输入框里打 `/` 可以点名用一个。见[智能体技能](/docs/guides/agent-skills)。
- 左栏是**对话记录**，列着你在各处聊过的全部对话，每条独立；支持重命名 / 删除。共享进工作区的别人的会话是只读的。
  不是在 AI Studio 里开的那些，标题下写着在哪开的(「在剪辑《宣传片》里开的」「在笔记《周报》里开的」)，旁边一颗「回到那里」，
  点了就到那一页、接着这段聊。
- **打开时是一段新对话**：点开 AI Studio(或者任何一处的助手)，看到的是一段还没开始的新对话 —— 发出第一句话它才真的建出来、
  进历史；不说话就什么都不留下。这一次打开应用期间，每一处都记得你在聊哪段，换个页面再回来还是那段；重启应用后又从新对话开始，
  以前的都在历史里。
- **名字是聊出来的**：第一句话发出去时名字先是那一句；第一轮回答完，智能体用这段对话的模型照实际聊的内容起一个短名字(比如
  「宣传片脚本第二段改短」)。你改过的名字不会被它改掉；起不出来就留着第一句话。

它能用的工具覆盖素材、文档、资产、笔记、画板、3D 场景、剪辑、工作流和发布：比如新建项目和时间线、复制片段、替换媒体、加轨道时指定放在第几行、
列出画板、查有哪些配音引擎（`list_speech_engines`）、从链接导入素材、读文档、建资产……工具名写错时它会照实收到报错（比如配音引擎点错时列出能用的），
不会编一个。改笔记时它按段替换或插入(`edit_note`)，不再只能整篇重写或追加到末尾。浏览器工具能操作页面里同源框架(iframe)里的元素、把当前页截图存进
素材库(`browser_screenshot`)、看 / 切 / 关会话里开着的几个页面(`browser_page`)。

### 确认卡：跟着对话走

确认卡**出现在发起它的那次工具调用下面**，不是浮在对话末尾。卡上从上到下是：请求方和权限档位、要做的事（一句话）、后果、参数（一行一项，
代码还原换行、按语言高亮，默认露前 8 行，「展开全部 N 行」）、收起的「原始数据」，最后是按钮「允许一次」「本会话始终允许」「拒绝」。
决定之后卡收成工具调用里的一行状态（「已批准 · 已执行」「自动放行 · 执行失败」「已拒绝」……），不用再手动关；失败原因整句保存，长的折起来。
有请求等你确认时，「回到最新」变成「有请求等你确认」，点它直接滚到那张卡。

![一轮真实对话(本机 Ollama 上的 qwen3.5):确认卡出现在 delete_assets 这次工具调用下面,永久删除档只有「允许一次」和「拒绝」](/media/screens/agent-confirm.png)

权限档位写在卡上：**编辑**、**AI 成本**、**渲染成本**、**对外生效**、**永久删除**。「本会话始终允许」**按档位记**：只对同一个工具、不高于当初
那一档的卡生效；**对外生效和永久删除这两档不提供这个按钮**，卡上写「撤不回的操作每次都要你确认」。一张卡执行到一半出错时，已经做了的那部分
一起撤回，不会留下一半。

**改笔记的卡画出「原文 → 新文」**：每一处改动一块 —— 替换的画出差异(删掉的划线、新加的高亮，没变的照常)，换成空的标「删除」，插入的露出锚点那一截
上下文和要插进去的字；长的先露前 400 字，「展开全文」看全部，原始 JSON 照旧收在「原始数据」里。

### 附件、文档与后台任务

- **附件**：点 📎、把文件从访达拖进对话区（「松手添加到对话」）或粘贴截图，三条路同一套规矩。图片、视频、音频进素材库；PDF、Word、PPT、Excel、
  EPUB、Markdown、TXT、CSV、网页进素材库当[文档](/docs/guides/documents)，智能体按段读，短的整篇读，长的先看目录，要看版式时把页面图交给视觉模型；
  别的文本文件（脚本、字幕、配置）内联进消息，每份最多 3000 字；认不出的直接说明是哪一个、为什么。从微信、飞书聊天窗口直接拖出来的文件
  系统不让别的应用读 —— 先存到本机再拖进来。
- 当前消息里的图片直接交给所选模型；导入素材库后的图片 / 视频由 `analyze_asset` 使用**当前会话模型**分析，不会另选一套隐藏的视觉模型。
- **后台任务回执**：智能体起的任务（解析一份附件、一次生成）跑完会在对话里送回一行任务通知（悬停看到「后台任务回执」和任务号），不会出现在你的
  消息队列里；智能体正忙时到的回执攒到这一轮结束，一次交给它。它自己已经盯着跑完的任务不再送回执。
- **带着笔记摘录的消息**：在[笔记](/docs/guides/notes)里带着选区发出去的消息，气泡里多一行摘录(笔记标题 + 那段的开头)，以后翻对话也知道说的是哪段；
  点它回到那篇笔记、选中那一段。
- **从网页交给智能体**：浏览器会话顶栏「用当前页开工 → 交给智能体」在 AI Studio 开一段新对话，把「帮我看看这个网页：」、页面标题和链接放进输入框，等你补一句再发。
- **不会说到冒号就停**：模型停在「我先看看……：」这种半句上会自动续一次；输出被截断、说要调工具却没给出工具调用、供应商暂停这一轮时也续一次，
  仍不行就在对话里写明原因（比如该在模型设置里提高「最大输出 Token」）。

### 每一处有自己的对话

剪辑、笔记、创意画板、工作流、3D 场景，还有 [ComfyUI 工作台](/docs/guides/comfyui)的「助手」页签，都有同一个紧凑的助手面板。
**每一样东西各有各的对话**：每个剪辑项目、每篇笔记、每块画板、每个工作流、每个 3D 场景、工作台里的每一张工作流。在剪辑里聊的，
打开一篇笔记不会接着聊；在一处点「新对话」，只换这一处。

- 面板左上角是当前这段的标题，点它展开：上面是**这里的对话**(在这一处开的，最近的在前)，下面是收着的**其他对话**(别处开的，
  每行写着在哪开的)，搜索时两组一起搜。从「其他对话」里挑一段，就在这里接着聊 —— 它在哪开的不变，标题下会写一句「这段对话是在……里开的」。
- 「新对话」(标题旁的 +)换成一段还没开始的新对话，发第一句话时才建出来，算作在这一处开的。
- **智能体带你走，对话跟着走**：聊着聊着它说「我带你去那篇笔记」，到了那里接着的还是这段对话，活不断；你自己点过去的，看到的是那一处自己的对话。
  它在你离开期间(超过 30 秒)要求的跳转不会把你拽走。
- **免提浮标**对着眼下这一页的对话说(面板收着也算)；在素材、发布、设置这些没有面板的页面，对着 AI Studio 的对话说。
- **工具跟着你在哪说**：在 ComfyUI 工作台里说的话，智能体拿到的是改 ComfyUI 工作流的那套工具；在别处，拿到的是改画板、时间线、3D 场景
  和工作流的那套。所以要改 ComfyUI 里的图，请到工作台的「助手」里说。
- 在剪辑里开的对话会带上那个项目的记忆(智能体为这个项目记下的约定,比如「片头一律用 brand-intro.mp4」)。

面板标题栏空白处用于拖动悬浮窗口，长标题自动省略，控件保持扁平，不再额外套一个选择框。

智能体运行在应用内置的 Node.js 边车中，基于 pi-agent-core / pi-ai。需先[模型连接与配置](/docs/guides/providers)。

### 输入框：每轮都要看的留在外面

输入框那一行只有每次都会用到的东西：附件、麦克风、**模型**、发送。模式切换留在页面顶部。其余进右边那个滑块图标的
**会话设置**——它们是「配好就不再动」的东西：

- **思考**：关闭 / 低 / 中 / 高。开启后，模型的思考过程会流式显示在一个折叠块里，想看就展开，结束后自动收起；收起后「已思考」那一行右侧显示这段思考用了多久，和工具卡的耗时一个写法。
  「关闭」只表示**不主动要求**它思考：k3、DeepSeek reasoner 这类模型无论如何都会思考，它们的思考照常显示。
- **视频分析方式**：
  - **自动**：API Key 连接且当前模型有原生视频 Adapter 时直读整段，否则抽帧并附上已有语音转写；
    订阅/OAuth 模型通过无工具 Gateway 分析采样帧，不要求填写服务地址。
  - **原生视频**：强制整段输入；当前 OAuth Gateway 没有 video block，因此会明确提示改用抽帧，
    不会静默换模型或模式。
  - **抽帧 + 转写**：始终按时间采样画面，并把素材已有转写一并交给当前视觉模型。
- **上下文**：一条水位条 + 「还剩百分之多少」，以及「**立即整理上下文**」。

### 上下文快满了会怎样

聊得够久时，应用会把**早期对话交给模型摘要**、保留最近几轮，腾出空间继续聊。这件事不是悄悄发生的——
对话里会留下一条记录，写明移出了多少条、腾出了大约多少 token，展开能看到摘要本身。

- 触发点是所选模型上下文窗口的 **80%**。每个模型的窗口不一样，在[模型设置](/docs/guides/providers)里可以改。
- 不想等它自己到线，可以随时点「立即整理上下文」——它要花一次模型调用，所以是个明确的按钮而不是自动行为。
- 水位读的是**供应商回报的真实用量**(最后一次调用的输入、输出，以及缓存读写)，此后的新消息才是估算，不是纯猜。
- 留给回答的空间不到 1,024 Token 时，这一轮不会发出去，而是说明窗口多大、要发的有多少：在模型设置里填对这个模型真实的上下文窗口，换一个窗口更大的模型，或先「立即整理上下文」。

### 轨迹：它做了什么、时间花在哪

![轨迹初始页：运行会话后才会出现真实步骤和用量](/media/screens/agent-trace.png)



对话回答「它说了什么」，顶部的「轨迹」标签回答另一个问题：**它做了什么、时间花在哪**。

一屏三条泳道（输入 / 模型 / 工具）把整个会话压成色块，两种投影可切：**顺序**每条记录等宽（不依赖
时间戳，永远画得出来），**时长**按真实耗时排布并把中间的空闲挤掉。下面是逐步的执行流，点开某一步
能看到它的入参、返回、耗时。

轨迹里还有对话看不到的那一半：

- **系统提示**只在**变化的那一轮**记一份。它不是常量——跨会话记忆和当前任务计划都拼在里面，每轮都
  可能不一样，而排查「它为什么突然改了做法」时，这恰恰是第一现场。
- **上下文注入**单独成条。发给模型的是「你打的字 + 这一段上下文」，所以你在轨迹里看到的提问，才是
  模型真正收到的那一份。
- 每一轮的 token 明细（输入 / 输出 / 缓存读）标在轮头。没有用量记录时显示为空，而不是 0——「没记」
  和「没花」是两件事。

### 子智能体：把一段调查派出去

智能体可以把一件独立的活派给**子智能体** —— 只读工具、自己的上下文，回来的只有结论。省的是
上下文，不是算力：一次翻四十轮文件的检索照样要翻，只是翻在别处，你的主对话收到的是答案而
不是翻找过程。

- **派发不阻塞。** 立即拿到回执接着干别的，要不要等、什么时候等由它自己决定。同一条消息里
  派多个就并发跑。
- **一份也不丢。** 没等的报告会在收尾时自动送达。
- **每个子智能体都是一段能点进去的会话**，界面和主对话一模一样，右侧面板和头部入口都能进。
  运行中每一步都看得见。
- 主对话的任务计划和最近工具只显示主智能体这一层；子智能体自己的任务卡、工具步骤留在对应子会话里，避免同一项工作在父子两边重复出现。

不同会话的智能体之间还能**相互 @ 通知**。对方空闲就立即开跑，忙就排队、闲下来再接。这样来的
消息带「来自其他智能体」徽章，所以一段对话不会看起来像在自言自语。

## 创作：图像、视频、语音、播客、音乐

![AI Studio 创作:还没有生成任务,右栏是所选模型的引擎参数(演示用的占位连接,不会真的生成)](/media/screens/ai-generate.png)

「创作」把图像、视频、音乐与音效、语音、播客放在**一个工作台**里：左边是创作会话，中间是这条会话的来回，底部输入框写要什么，右栏调引擎参数；
结果进素材库。

<Loop src="/media/videos/ai-studio.mp4" poster="/media/screens/ai-chat.png" alt="操作演示:对话、轨迹、生成与音频页之间切换" />

- **按种类看**：会话列表上面一排筛选 —— 全部、图像、视频、语音、播客、音乐，选过的记在本机；每条会话后面标着是哪一种。
- **来自别处**：画板、工作流、资产详情页、定时任务、智能体对话、ComfyUI 工作台里生成的，也记成创作会话，收在列表最下面「来自别处」
  （默认合着，带个数）。**一处一条**：同一块画板上的每一次生成都在「创意画板《镜头与灵感》」这一条里，智能体一段对话里批准的出图、
  念字、播客在一条里。标题就是那一处现在的名字（删了写「已删除的创意画板」），行上的「回到那里」带你过去。点开照常看、照常能接着生成。
  很长的会话先显示最近 40 条，往上点「显示更早的」。
- **种类由模型定**：新的一条用什么模型，就是什么会话。模型下拉分组列出图像、视频、音乐与音效、语音（各个配音引擎）、播客；
  选了某一种筛选时，下拉只列这一种。
- **一条会话一族**：图像和视频是一族（可以拿上一张图接着生视频），音乐、语音、播客各是一族。会话里有了记录，下拉只列同一族的模型；
  想换别的种类，点左上角「+」新开一条。
- 生成中的占位、「停止」、「已停止」、失败卡、耗时和价格，五种都是同一套。
- 选模型 → 写提示词 → 发送，任务进队列，完成后结果进素材库。模型默认选中你在设置里设的**默认模型**；没设默认时显示「选择模型」，先选一个才能发送。
- 能不能跑取决于该模型对应**服务商的密钥**是否配好；没有可用模型时右栏会提示去配置。
- 提示词框下面的「@ 资产」能点名资产库里的人物、场景、道具：描述拼进提示词，参考图按模型收得下的张数挂上（见[资产库](/docs/guides/assets)）。
- 挂了驱动音频就是数字人生成（说话照片、改口型）：要先勾「已取得画面中人物的授权」，见[数字人](/docs/guides/digital-humans)。
- **提交出去就会等到结果**：视频生成常要几分钟，排队时更久。Mosael 不会因为"等太久"就放弃一个已经
  付过钱的任务——只有服务商说完成（或失败），或者你在任务中心取消，它才结束。后端中途重启也一样：
  重启后会**接着取回**那一条，而不是让你重新发起（那样会再付一次）。任务中心里点这条任务的「前往」，打开的就是这条创作会话。

### 右栏的控件跟着模型走

不是所有模型都认同样的参数：万相收 `832*480` 这样的像素对，Seedance 收 `720p` 这样的档位；
有的能选时长，有的只有一档。所以右栏**只出现这个模型真的支持的那几项** —— 换个模型，
控件跟着换。
手动输入、尚未收录能力描述符的模型仍可提交提示词，但 Mosael 不会从同供应商另一型号猜出
时长、分辨率或素材输入规则。

- **生图模型声明了分辨率档、画质，就摆出来**，默认停在模型说的那一档(Evolink 的 GPT Image 默认最便宜的低画质、1K)。画质下面一行写着价差：
  按 token 计价的 GPT Image，低画质约是中画质的九分之一、高画质约是中画质的 4 倍，先用低画质试。
- **尺寸只是推荐几档、也收手填的模型**(ComfyUI 的工作流)，下拉里能直接输入「宽x高」，比如 `768x1024`，写法对了多出一项「使用」。
- **选大模型、LoRA 的那一格**(ComfyUI 的工作流)带缩略图、底模和触发词，选中 LoRA 后点「加进提示词」，见[用 ComfyUI 生成](/docs/guides/comfyui)。
  从模型库或工作流库点「用它生成」跳过来时，这里已经选好那张工作流、填好那一格。
- 模型声明了默认值、你又没动的参数，提交时照模型的默认值发，不会落到服务商自己的默认上。

### 首帧、尾帧、参考图

图生视频不止「给一张图」这一种：

| | 意思 |
| --- | --- |
| **首帧** | 从这张画面开始动 |
| **尾帧** | 和首帧一起给，模型会从第一张画面**动到**最后一张 |
| **参考图** | 不作为画面起点，只作为风格 / 主体的参考 |

同样只有支持的模型才出这些控件。每一项都可以选素材库里的图，也可以粘一条外链。

想让智能体来做也一样：让它「用这两张图做首尾帧生成一段 5 秒的视频」，它会先查这个模型
支持什么，再照着发 —— 传了模型不认的参数会被当场挡下，而不是默默跑出一个别的东西。

### 音乐与音效

模型下拉里的「**音乐与音效**」一组：选一个音频模型，就能生成歌曲（带人声）、纯音乐 / BGM、
音效，或者给一段视频配声。它和图像、视频是同一条生成管线：同一个会话、同一套参数描述符，结果照样进素材库、
记用量，花了钱的异步任务后端重启后也会接着取回。

- **提示词**写「怎么唱」：流派、情绪、乐器、速度，或者「雨打铁皮屋顶」这样的音效描述。
- **歌词**是单独的一栏（右栏「歌词」），写要唱的字，可以用 `[Verse]` / `[Chorus]` 标段落；右下角显示字数和这个模型的上限。
  只给歌词、不写提示词也能提交。
- **人声**：选「纯音乐（不要人声）」时歌词栏会灰掉 —— 纯音乐没有歌词，两个都给会被当场拦下。
- **时长**只在模型支持时出现，而且**可以空着**：多数音乐模型按歌词长短自己定曲长。
- **给视频配声**的模型（可灵视频生音效）要挂一段视频；它只收公网链接，本地视频会先经对象存储插件换成限时直链。
- 结果是**播放器**，不是缩略图；一次交回两首的模型（Evolink 上的 Suno）两首都列出来。

各家支持什么、哪些只能按文档接入，见[供应商](/docs/guides/providers)的「音乐与音效」一节。

### 语音

- 输入框里写要念的字（最多 2000 字，右下角写着字数），右栏挑音色（右边的喇叭点一下试听一句）和语速。引擎和剪辑台配音页是同一套：本地音色克隆
  （F5-TTS / Fish Speech）或任一远端引擎；新开的语音会话先落在 Edge（内置、免费、什么都不用配）。
- 本地克隆要先有音色——没有时右栏的提示条带你去设置的「配音与音色」上传或录一段参考音频；本机还没装好克隆引擎时也在这里说。选「阿里云百炼(CosyVoice)」时
  也能挑配音库里的嗓子,念的是它在你百炼账号里的副本;第一次用会问一次要不要把参考音频传上去,
  见[剪辑 → 不装本机引擎,用百炼念自己的音色](/docs/guides/editing)。
- 结果卡和音乐同一张：波形、真实时长、下载、在素材库里打开；标题是音色名，脚注是引擎和耗时。产出的素材叫「音色名 · 文本开头」。
- 打开一条语音会话，右栏停在这条会话上次用的音色和语速上。

### 播客

- 输入框顶上三档：**改写材料**（粘一段材料，两位发音人把它聊成对谈）、**聊一个主题**（先联网查，再两个人讨论）、**照稿念**（自己写稿）。
- **照稿念**一段一行：左边的 A / B 点一下换人，回车接下一段（换另一位念），在空的一段上退格删掉它；粘一大段多行的字自动拆成几段，认得「A:」「B:」
  和发音人名字开头的行。最多 60 段、每段 280 字（火山播客的上限），超了当场标红。
- 右栏挑发音人 A、B（各带试听）和语速。要先在设置的「AI 音频」里连好火山播客；没连好时右栏直接给出去配置的入口。
- 做好的播客下面有「对谈稿」（按发音人标名字）。点「**改稿再念**」把这份稿子装进照稿念，改完再念一遍 —— 这一次只花合成的钱。素材名是「主题 · 播客」，
  对谈稿跟着那段音频存在素材里。

### 以前做的语音和播客

升级之后，之前在「音频」页做的语音、播客并进了创作会话：每人一条「以前的语音」、一条「以前的播客」（按界面语言显示）。那时只存了文字的开头，
这些记录下面写着「之前的版本只存了开头这一段」。任务记录已经被清掉的老产出留在素材库里，不进会话。当时一并收进来的画板「念出来」、
智能体念的，再次升级时挪回了那块画板、那段对话的会话。

画板「念出来」、工作流的配音节点、字幕配音、笔记朗读念出来的不进创作会话 —— 它们属于那张画板、那条时间线、那篇笔记。给时间线上的字幕配音在剪辑台的
「配音」页，见[剪辑](/docs/guides/editing)。

## 飞书绑定

设置 → 飞书机器人可把智能体接到飞书，直接在飞书里对话。

**需要确认的改动会以卡片发到同一个飞书会话，在飞书里点「同意 / 拒绝」即可**，不用切回 Mosael。

谁能批准取决于账号绑定：点按钮的人必须已经把飞书账号绑到 Mosael 账号，并且此刻仍是该
工作区的成员。卡片在群里谁都看得见，但看得见不等于能批。

要用这个功能，还需在飞书开发者后台为该应用做两件事(没有接口可代劳，一键创建也配不了):
事件订阅里添加 `card.action.trigger`、应用功能里打开「交互卡片」，然后重新发布应用。
没配好时机器人会退回纯文本提示，并告诉你要开哪两个开关。
