素材库回答「这个文件是什么」,资产库回答「这是谁」。一个**资产**是一个有名字的东西 —— 一个人物、一个地点、一件道具 ——
它的参考图就是素材库里的图:资产只引用它们,不复制文件。同一个角色常常跨项目用,所以资产归**工作区**,不挂在某个项目下,
归类靠标签。

在左侧导航「素材」旁边打开「资产」,上方按人物 / 场景 / 道具分页签,每张卡片是一个资产的封面。

## 建一个资产

点「新建人物」(或场景、道具),起个名字,就进了它的详情页:

- **描述**:给人看的 —— 这是谁、什么来历。
- **提示词描述**:给模型看的 —— 外貌、服装、材质。生成时 `@` 到它,这一段自动拼进提示词。
- **标签**:用逗号分开;跨项目找东西靠它。
- **种类的专有字段**:人物有**音色**(配音库里的一把嗓子)、**白模里的人偶颜色**、**真人还是虚构**与授权声明;场景有关联的
  **3D 场景**和「时间 / 天气 / 光线」;道具有它的 **3D 模型**。

字段离开时自动保存。

## 参考图墙

详情页左边是一面参考图墙,每张标着角度或用途:正面、侧面、背面、三视图、特写、全身、表情、设定图、细节。

- **从素材库添加**:打开右侧的素材库栏,点「+」挂上,或者把缩略图直接拖到墙上。
- **把文件拖到墙上**:先导进素材库,再挂成参考图。
- **换角度**:每张图下面的下拉。**设封面**、**往前 / 往后挪**、**移出参考图**在它的「⋯」菜单里;也可以直接拖着排先后。
- 封面没设时,卡片用第一张参考图。

**删资产不删素材**:参考图还在素材库里。**删素材时**,引用它的资产少一张参考图,资产本身还在;详情页顶上会说「少了哪一张」,
看过之后可以点「知道了」清掉。素材库里删除前的确认框也会提醒这一点。

素材详情里多了一行「属于哪些资产」;素材库里右键一张图,「设为某个资产的参考图…」可以直接挂过去(顺手设成封面)。

## 变体

同一个人物的冬装、古装、少年时期,是挂在它下面的**变体**。变体继承母体的提示词描述和音色,只换参考图和服装描述 ——
「张三 · 冬装」和「张三」是同一个人。变体自己还没有参考图时,生成用母体的参考图。删有变体的资产时,确认框会写明变体会一起删掉。

## 真人与授权声明

人物要声明是**虚构**还是**真人**。真人要选「这是我本人」或「已取得本人同意」—— 每一项在界面上都写着它是什么意思。
谁、在什么时候声明的由服务端记下。没有声明的真人不能用于之后的数字人功能(「让它说话」);这对应《互联网信息服务深度合成
管理规定》第十四条要求的单独同意。

## 在生成里 @ 资产

在画板的生成格里写提示词时,敲 `@` 的菜单里除了素材,还有资产库里的人物、场景、道具(带封面和种类);AI 工作台的提示词框下面
有「@ 资产」;工作流的「AI 生成素材」节点有一格「资产」;智能体的 `generate_image` / `generate_video` 收 `entity_ids`。
四处是同一件事:

1. 资产的**提示词描述**拼在提示词后面(变体是母体的描述加上它自己的那句)。
2. 从它的参考图里**按先后挑图**挂成参考图:三视图 > 正面 > 全身 > 其余。点名几个资产时轮流挑,不让第一个把名额吃光。
3. 能挂几张**只听所选模型的描述**:它收几张参考图、和已挂的首尾帧能不能混用。描述里查不到的模型一张都不挂,不猜。
4. **挂不下的照实说**:AI 工作台的生成记录上、画板提交之后都会写「挂了几张、几张没挂上、为什么」。

可灵这类「先建主体再引用」的模型:每个 `@` 到的人物用它的参考图建一个主体(正面图在前),名字按图片内容算 —— 同一个人物
下次再用,查到的是同一个主体,不会重复建。

## 画板上的资产格

画板「添加 → 引用 → 资产」放一格**资产格**:封面、名字和种类角标。把它连进一格图片或视频生成,就和在提示词里 `@` 了它一样;
提示词框的 `@` 菜单里,连进来的资产排在最前面。分享画板到社区时,资产格按一张图显示(封面和名字),资产本身的提示词描述和其余
参考图不随画板分享。

## 在哪里用过

详情页最下面列出这个资产**在哪里用过**:哪些画板上有它的资产格或在提示词里 `@` 了它、哪些生成记录点名了它、哪些工作流的
生成节点用了它。点一行过去。

## 分享到社区

资产详情标题旁边的「分享到社区」把这个资产**连同它的变体**发到社区(要先在「设置 → 社区账号」里连上账号)。带出去的是
图片参考图(角度、封面、先后照旧)、描述、提示词描述、标签,以及能公开的字段(白模人偶颜色、时间天气);**音色、3D 场景 /
模型、授权声明原文和本机的任何 id 都不出门**,视频参考也不带。填好标题、简介、标签就发,发布即上架;之后再点是
「发布新版本」—— 社区上还是同一条、同一个链接。标题下面写着它在社区上的状态(已发布 / 审核中,点一下在浏览器里打开)。

**真人人物**要先在本机声明「这是我本人」或「已取得本人同意」,分享时还要在弹窗里再勾一次「已获得本人同意公开」;社区先
人工核对,通过后才公开。被冒用肖像的人可以在社区的资产页上举报(理由「冒用肖像」)。变体不单独分享。

## 从社区导入

资产页右上角的「从社区导入」:贴一个社区资产页的链接(或它的短名),或者在下面按人物 / 场景 / 道具浏览、搜索,点一个就导入。
导入**不需要连社区账号**。每张参考图下载后按分享包里写的哈希核对,有一张对不上就什么都不建;核对过的图作为素材进这个工作区
(来源记为「社区」),再建好资产、变体、角度和封面,并记下它来自社区的哪一条、第几版 —— 详情页标题下写着「来自社区 · v1」,
社区上出了新版本时会提示,可以一键把新版本再导入一份。

导入的**真人人物**,授权声明是「**授权待你确认**」:发布者声明过取得了本人同意,但这台机器上还没有人确认过。在那之前它不能
用于数字人;确认你这边也获得了本人授权之后,在「授权声明」里选一项就行。
