ComfyUI 由随 Mosael 一起发的 **ComfyUI 插件**接入：装好就在「插件」页里，不用去市场找，也不用填 API Key。
一台 ComfyUI 服务器就是一个连接，它带来两样东西：

- **模型**：它里面**保存的每一张工作流**都会作为一个模型，出现在 AI Studio、创意画板和工作流「AI 生成素材」
  节点的模型选择器里，和别家的模型放在一起；
- **工具**：**每张工作流也是一个工具**(「工作流 · 名字」)，入参就是那张图自己的提示词、读素材的节点和可调参数，
  交回全部产出；另有列出工作流和模型文件、看显卡和队列、把 ComfyUI 历史里的产出收进素材库、中断 / 清队列 / 释放显存。
  智能体能直接调它们，工作流节点面板里每个工具就是一个节点。
- **两个目录**：连接标题行上的「**打开模型库**」看这台服务器上的全部模型文件、下载缺的模型；「**打开工作流库**」看、管、导入
  它上面存着的工作流，经 ComfyUI-Manager 装上缺的节点包。
- **工作台**(桌面版)：在 Mosael 里全屏打开这台 ComfyUI 自己的画布，旁边是 Mosael 的模型库、缺失项、应用和运行面板(见下文)。

## 接上一台 ComfyUI

1. 先把 ComfyUI 跑起来(本机默认地址是 `http://127.0.0.1:8188`)。
2. 打开「插件」→ **ComfyUI** → 「新建连接」，填**服务器地址**。填局域网地址(如 `http://192.168.1.20:8188`)
   就能用另一台机器的显卡。ComfyUI 放在要登录的反向代理或 ComfyUI-Login 后面时，把「用户名:密码」或令牌
   填进「**访问凭据**」(前者按 Basic 认证、后者按 Bearer 令牌发)；地址里不要写用户名和密码。
3. 授予它要的权限，打开连接开关:`network:comfyui`(连这台 ComfyUI)、`network:huggingface`、`network:civitai` 与
   `network:modelscope`(模型库解析链接、下载模型时连这几个站)、`network:github`、`network:pypi` 与 `network:pytorch`
   (让 Mosael 在这台电脑上装 ComfyUI 时下载源码、依赖和 PyTorch，见下一节)、`filesystem:write`(ComfyUI 就在这台电脑上时，
   把下载的模型写进它的 models 目录)。插件申报的就是它真会做的这几件事；从更早的版本升级上来的连接会先停用，等你授予新增的几项(见最后一节)。

打开之后 Mosael 会去问这台 ComfyUI 有哪些工作流，连接卡片上「生成模型」一行显示「N 个模型 · 刚刚刷新」；
点「**查看模型**」能看到每个模型是图像还是视频、能做哪几种生成、收哪些素材、有哪些参数。没连上时那一行只写一句该做什么
(「连不上这台 ComfyUI,确认它在运行、地址填对」)，地址和原始报错在悬停说明里。有几台服务器就建几个连接，各自一串模型、
一套工具；连接多了可以收成一行一个(见[插件页](/docs/guides/plugins))。

在「设置 → AI 绘图 / AI 视频」里，ComfyUI 连接显示为「由插件提供」，改地址、改名都到插件页；它的模型可以
像别的模型一样设成默认模型。

## 在这台电脑上跑 ComfyUI

连接卡片上「**在哪跑**」有三种：连一台已经在跑的服务器(上面那样)、**用我自己装的**、**让 Mosael 装**。后两种由 Mosael
替你起停：用到时自动启动(生成、打开模型库或工作台)，退出 Mosael 时停下；端口由 Mosael 从 8189 往上挑一个空的，写进服务器地址。
只有部署管理员能设置，确认框会写明代码在哪台机器上运行。

- **用我自己装的**：填装好的 ComfyUI 目录(Windows 便携版选外层或里面那层都行；桌面版可以点旁边的「选择…」从系统对话框里挑)，Mosael 先试跑一次，摆出 ComfyUI 版本、PyTorch、
  显卡、缺什么；能起才存。ComfyUI-Manager 要 pip 版(V4,新的 ComfyUI 自带)：装了就随 ComfyUI 一起开；克隆进
  `custom_nodes` 的老 Manager Mosael 不支持，检查时会提醒，并给出换成 pip 版的命令(`pip install -r manager_requirements.txt`)。
- **让 Mosael 装**：先看安装计划 —— 这台机器能不能装(Apple 芯片 Mac;Windows 或 Linux 服务器(x86_64)+ NVIDIA 显卡;别的这一版不装，
  会说原因)、装哪种 PyTorch、至少要多少空间(Mac 5 GB、Windows 和 Linux 8 GB)、分几步、从哪儿下载、下载走哪个代理。确认后 Mosael 下载钉死版本的 ComfyUI、建一个独立的 Python 环境、
  装 PyTorch、依赖、ComfyUI-Manager 和 pysssss,最后试起一次。装的时候看得到第几步、正在下哪个文件、多快，能取消，「接着装」从没做完的
  那一步继续。Apple 芯片的 Mac 上全新装一次 4–5 分钟，装完约 2 GB。**不替你下模型**：装好之后点「打开模型库」挑要用的。
- 国内网络慢：在「管理 → 引擎 → 下载源」里换 pip 源，Windows 装 CUDA 版 PyTorch 选「PyTorch 源」里的南京大学镜像，GitHub 慢就填一个
  「GitHub 镜像前缀」(压缩包按 sha256 校验，镜像换不了内容)。下载照样走「设置 → 网络」里的代理。
- Mosael 升级换了自带的 Python 版本时，连接卡片上会说「运行环境要重建」，点一下只重装 Python 环境，源码和模型不动。
- **Linux 服务器**：要 NVIDIA 显卡和它的专有驱动(`nvidia-smi` 能用;在容器里要把显卡带进来，比如 `docker run --gpus all`)、x86_64、
  系统的 glibc 2.28 以上(CentOS 7 那种太旧)。驱动要求和 Windows 一样按显卡挑，只是 Linux 上的驱动版本号自成一列。
- **共用模型文件夹**：已经有一堆模型(另一份 ComfyUI 的 `models`、A1111 / Forge 的 webui 目录)的，在卡片的「共用的模型文件夹」里加上它，
  不用拷第二份。认得出才加，重启后生效;卡片上写明认成什么、加载了没有、看到几个模型。Mosael 只读这些文件夹 —— 模型库下载的新文件
  仍放在它自己的 `models` 里，也不往共用文件夹里写预览图;配置写在 Mosael 的数据目录里，不改你的 ComfyUI 目录。
- **闲置自动停**：不是「保持运行」的，闲置 30 分钟(「高级」里改，0 = 不停)就停下、把显存让出来，下次用到时自己起。有任务在跑或排着时
  不停;工作台开着也算在用。
- **更新、回到上一版**(让 Mosael 装的那一份):卡片上「版本」一行写着装的是哪个，有新的钉死版本就有「更新到 …」。更新会先停下它、换上新源码
  和依赖、试起一次 —— 哪一步没成、或者起不来，都自动换回原来那一版;成了以后能「回到上一版」(不用重下)。模型、自定义节点、工作流和设置
  跟着走。
- **删掉**：删连接时可以一起删 Mosael 装的那一份，并「保留模型」(挪到数据目录的 `local-services/kept-models`,以后在共用模型文件夹里
  一键加回来);不删就留在磁盘上。「用我自己装的」那个目录 Mosael 从来不删。

## 保存的工作流就是模型

在 ComfyUI 里把工作流**保存**(存进 ComfyUI 的 workflows 目录)，**一分钟内**它就出现在选择器里 —— Mosael
每分钟看一眼工作流目录有没有变，变了才重新读一遍；等不及就在插件页点「**刷新模型**」。模型名就是工作流的名字，
是图像还是视频看它的输出节点：接了视频合成节点(VHS Video Combine、Save Video 等)的是视频模型，其余是图像模型。
**只交出一段字的工作流不是模型**(打标签、反推提示词这类，输出节点只有 Show Text 一类)：它交不出图，选了也拿不回
一张图 —— 它照样是一个工具(见下)，在工作流和画板上用。

另外还有两个模型：

- **内置文生图**：ComfyUI 里至少装了一个 checkpoint 模型时出现，什么工作流都没存也能出图；
- **API 模板**：连接配置里粘贴了「导出 (API)」的 JSON 时出现(见最后一节)。

ComfyUI 里删掉的工作流，也会从选择器里消失。

## 参数与输入素材

Mosael 会读出每张工作流**能调什么、收什么**：

| 工作流里 | 在 Mosael 里 |
| --- | --- |
| 采样器 / 引导器上游写提示词的节点 | 提示词、反向提示词 |
| 没有认得的采样器时（MiniMax / 海螺、Kling、Veo 这类 API 节点，WanVideo 一类自带采样器的节点包，包在子图里的 MiniMax H3）：接到产出上的节点里多行的 `prompt` | 提示词；同一个节点上的 `negative_prompt` 是反向提示词 |
| 采样器的 seed、RandomNoise 的 noise_seed | 随机种子(不填每次随机) |
| 生成画布的节点(EmptyLatentImage、Wan / Hunyuan 的视频潜空间节点)的宽高 | 尺寸：不选就用工作流自己的；下拉里是工作流自己的和几档常用尺寸，也能直接输入任意「宽x高」(如 `768x1024`)，每边取整到 8 的倍数、至少 16 |
| 画布节点的 batch_size | 一遍出几张：**按工作流原样**，存着 4 就是一遍 4 张 |
| 有种子的出图工作流(有没有画布都一样) | 「**跑几遍**」(最多 4 遍，没选就是 1 遍)：插件**一遍跑完再提交下一遍**，每遍按工作流原样、换一个种子(填了种子就从它开始依次 +1)，每份产出的种子记在生成参数里；一共交回「跑几遍 × 一遍几张」，这一格下面写着每遍几张、这次一共几张。取消时剩下的不再提交；某一遍失败，出来的照样交回，并说明「跑了 3 遍，出来 2 遍，第 2 遍为什么没出来」。放大这类没有种子的，跑几遍都是同一张，没有这一格 |
| 这一种的保存节点(一个都没存就看预览节点) | 一次交回几份：生成前按这个数摆好占位。不止一个时，参数里多一项「**结果取自**」：选一个就只交回它的，别的保存节点不跑。默认全部；只接了预览节点、其中有的不是最终结果时(两遍出图的第一遍、修脸和放大之前的那张、ControlNet 的控制图、蒙版)，默认「**最终结果**」，只交回最后那个结果节点的图，要每个都交回就选「全部」。只预览读进来的原图或预处理结果(OpenPose 骨架、Canny 线稿、深度图)的预览节点不算产出 |
| checkpoint、LoRA、VAE、文本编码器、放大模型、ControlNet 的加载节点 | 下拉，可选值就是 ComfyUI 里装了的那些文件；每一项带缩略图、底模和触发词(见下面「生成时也看得到模型库」) |
| 步数、CFG、采样器、调度器、降噪强度、帧数…… | 参数面板里的一项，用人话起名(「步数」「采样器」)，常用的在前、细节收进「高级」 |
| LoadImage 节点 | 参考图；视频工作流里接到 `start_image` / `end_image` 的是首帧 / 尾帧(中间先过一道缩放、裁切这类处理的也认得)；图生视频的首帧必须给。有几个读图节点(或起过名)时，每一格按顺序带着节点的名字 |
| LoadImageMask，或只接了 LoadImage 蒙版(alpha)那一路的节点 | 蒙版(局部重绘，白色是要改的地方) |
| LoadVideo / VHS_LoadVideo | 待编辑的视频(视频到视频) |
| LoadAudio | 驱动音频(视频工作流里)或参考音频 |

**只看 ComfyUI 真会跑的那部分图**：能跑到产出的节点和它们的上游。悬空的画布节点不会变成「尺寸」「张数」，下游全被旁路的读图节点
不会变成一格输入，上游断了的预览不算进「一次交回几份」；rgthree 的 Relay、Repeater 这类只在前端的节点不进图，它的「Seed」节点存着的
固定种子也不会每次被换掉。

**缺什么，提交之前一次说全。** Mosael 先对着这台 ComfyUI 的节点和模型清单看一遍：没装的节点、加载节点里选了而这台机器上没有的模型文件，
一次列全，说装在哪、怎么换，什么都不提交 —— 不用装好一个才知道下一个。一部分产出校验不过时(比如修脸、放大那一路要的模型缺了)，
ComfyUI 会照样排上剩下的那一路；Mosael 把这个任务撤掉并说出原因，不会把一张预览图当成结果交回来。

一张工作流里有两个同类节点时(比如两个 KSampler)，参数名会带上区分：给节点起过标题的用标题，没起的写
「第 2 个 KSampler」。悬停在参数名上能看到它原本是哪个节点的哪个输入。文件名前缀这类只和 ComfyUI 那边有关的
输入不列出来。

参数面板里没动过的项不会发出去，工作流保持它自己的值。挂上的素材会先传到 ComfyUI 的 input 目录，再接到对应的
节点上 —— 你在 Mosael 里挑素材库里的就行。**放大、抠图这类没有提示词的工作流**，图是必须给的(否则 ComfyUI
会拿工作流里存着的那张示例图跑)，模式只有「图生图」。

**提示词要不要写，也是从工作流里读的**:没有文字喂进采样器的工作流(放大、抠图、修脸、补帧)不收提示词 ——
AI Studio、画板和工作流节点里不摆提示词框，挂上素材就能生成；写提示词的节点里存着一句话的，提示词可以空着
(空着就用工作流里那一句)；存的是空的、或者粘贴的模板里是 `{{prompt}}` 的，要写。

提示词优化会按工作流选写法：SD 1.5 / SDXL 那一路改成逗号分隔的英文标签并给出反向提示词，Flux 这类保持自然语言。

## 工具：让智能体和工作流直接用 ComfyUI

**每张工作流一个工具。** 保存在 ComfyUI 里的每张工作流(连同粘贴的 API 模板和内置文生图)都会以「工作流 · 名字」出现在工具表、
工作流节点面板和智能体的工具里，表单就是那张图自己的：

- 提示词、反向提示词(没填就用工作流里写好的那一句)；
- 每个读素材的节点一格：「图」「蒙版」「视频」「音频」，只列那一种素材；给节点起过名字的带上名字；
- 每个可调参数一格：名字、范围、可选值和生成参数面板里一样，常用的在前；种子、尺寸、跑几遍收进「高级选项」，跑几遍不填就是 1 遍
  (每遍按工作流画布上存着的 batch_size 出)，尺寸和生成一样能填任意宽高；
- 输出按输出节点分：下游可以直接接「图 · SaveImage」这一路，也有「第一份产出」「全部产出」「文字产出」「摘要」「任务号」。
  后面这五个是给工作流连线用的：在画板上跑一次，右边只落每个输出节点自己的产出(图、视频、音频、一段字)，不会多出
  一张重复的图和几张 JSON / 摘要便签。

在 ComfyUI 里给工作流改名、挪目录，工具还是那一个(ComfyUI 把工作流的 id 写在文件里)；很老的 ComfyUI 存的文件没有
这个 id，改名就会变成另一个工具 —— 在新版 ComfyUI 里打开再存一次就有了，存着的节点会自动迁到新的工具名。在 ComfyUI
外面拷出来的副本和原来那张带着同一个 id，这时它们都按路径起名(不会让副本顶替原来那张)。

没填种子时按工作流里的设定：种子设成「每次随机」的每次换一个，「固定」的用存着的那个。

以前还有一个通用的「按 id 跑工作流」：它不知道要跑哪张图，表单却要你填参数，现在删掉了 —— 它能跑的每一种图都有了
自己的工具。工作流里、画板上用它选了某张图的节点，会**自动改成那张图自己的工具**(连进来的数据边、画板上的绑定一起改；
按节点 id 或节点标题改的值都认得)；新工具里没有位置的几格丢掉，丢了哪几格写在工作流那一版修订的说明里。选的那张图
在 ComfyUI 里已经删掉的，节点原样留着，运行前会报「未知的节点类型」，换一个就好。

其余的工具，默认开放下面带粗体的五个：

| 工具 | 做什么 |
| --- | --- |
| **列出工作流**(只读) | 每张工作流收什么素材(哪个节点读哪一种)、能调什么、交出什么、它看起来在做什么(放大、局部重绘、抠图、修脸、补帧……)，以及跑它用哪个工具 |
| **导入 ComfyUI 产出** | 按任务号(或最近几次)把 ComfyUI 历史里的产出收进素材库，在 ComfyUI 界面里直接跑出来的也行 |
| **服务器状态**(只读) | ComfyUI 版本、显卡与空闲显存、在跑 / 排队的任务数 |
| **列出模型文件**(只读) | 装了哪些 checkpoint、LoRA、VAE、放大模型、ControlNet…… |
| **中断任务** | 停下正在跑的任务；给了任务号就只停那一个，不误伤别人的 |
| 清空队列 | 清掉所有**排队中**的任务(同一台机器上别人排的也会被清)，默认不开放 |
| 释放显存 | 卸载模型、释放显存，默认不开放 |

**用哪一个**：一张工作流自己的工具最好用(入参就是它自己的)。要一段提示词出一张图 / 一段视频，用模型(生成)—— 它有任务中心的进度、
取消、重启后接着等和用量记录，一次可以跑 6 小时。要**原样跑一张处理类的工作流**(放大、抠图、局部重绘、修脸、
补帧)、一次喂好几样素材、或者要拿回所有中间产出，用那张工作流的工具。

**画板上一张工作流只有一个入口：生成。** 交得出图、视频或音频的工作流（预览节点 PreviewImage 这类不算 —— 它写的是临时文件），就是同名的那个模型：
画板上不再单独列它的工具，格子顶部的「⋯」里也不重复 —— 放一格图片(视频、音频)、选这个模型就是它，结果落在原位。几个保存节点的工作流也一样：
生成前按「跑几遍 × 一遍几张」一次摆好占位（「一次落出几格」上是这个总数，每一档写着跑几遍），想只要其中一个节点的，在「参数」里挑「结果取自」。
通过「生成」调 ComfyUI 时没选，跑 1 遍、按工作流原样出。只交出一段字的工作流（打标签、反推提示词）不是模型，在画板上照旧是格子的一项能力。「导入产出」按任务号取东西，不在画板上。
工作流和智能体里工具照旧都在（它多做的 —— 交回全部输出节点、显示出来的文字、预览 —— 留在那边），工具的说明末尾会提一句「只要图片的话，用『AI 生成素材』节点选这个模型」。

工作流的工具一次最多跑 30 分钟，进度一步一步报(在工作流里跑时，执行面板上看得到「采样 12/20」)，取消时会让
ComfyUI 停下这一个任务，**全部产出**收进素材库 —— 每个保存节点的每一个文件，以及显示文字的节点说的话。它占的是显卡，
智能体调它之前会先问你(确认卡)，批准之后在后台跑，不受智能体一次工具调用只等 3 分钟的限制。要跑更久的走生成。

### 预览图、NSFW 和出处

**预览图怎么显示**(工具条上的眼睛图标,模型库、工作台的模型库面板、生成时选模型的下拉都照它,记在这台电脑上):

- **预览图**:清晰 / 轻度模糊 / 重度模糊 / 不显示(只画类型图标);
- **NSFW 预览**:照常 / 模糊 / 不显示。两组各管各的、取更严的那一档 —— 比如「预览图清晰 + NSFW 不显示」。模糊的鼠标移上去或
  键盘停在上面时看清;不显示的不去取图,点开详情能「显示这一张」。以前的「模糊预览图」开关升级时自动换成这里(开着的换成重度模糊)。

**哪些算 NSFW**:卡片和列表上标着「NSFW」,悬停写凭什么。四种依据,任一种说是就算是:

- **手动标记**:右键菜单或详情里「标为 NSFW / 标为不是 NSFW」,压过下面几种;标过的能「改回自动判断」。只记在 Mosael 这边;
- **Civitai**:在 Civitai 上对上了这个文件的版本(见下),Civitai 标着成人内容,或显示的那张示例图分级在 R 以上;
- **元数据**:训练标签里成人标签占到一成、文件名或标题里有这类词 —— 不联网,会漏;
- **本机识别**:在这台电脑上看预览图本身。在「预览图怎么显示」里点「下载(22 MB)」装一个小模型(只有部署管理员能下;图和结果都不出这台
  电脑),之后卡片露面时顺带识别,识别完模型库会自己刷新一次;悬停写「本机识别:NSFW 的可能 87%」。只是提示,不是担保。

**在 Civitai 上找**:右键菜单或详情里的「在 Civitai 上找」。那台 ComfyUI 装了 ComfyUI-Custom-Scripts 时,让它算一遍文件的 SHA256
(大文件要一阵,算过的记在模型旁边),按哈希问 Civitai,对上的就是这个版本;没装时按「Civitai 上记的原始文件名 + 大小」找,恰好
一个才算,并标明是按文件名对上的。找是一个后台任务,在任务中心里看得到、能取消。对上之后:

- 详情里写**原链接**(Civitai 的版本页)和怎么知道的;经 Mosael 下载的模型下载时就记下了来源页(HuggingFace、ModelScope 的文件页也算)。
  找不到就写「没有」—— 不按文件名猜一个链接;
- 底模只认到 SDXL / Wan / Flux 这一层的,按 Civitai 登记的细分成 Illustrious、Wan 2.2……(旁边写「Civitai 上登记的底模」);
- 那台服务器上**没有预览图**的,显示 Civitai 的示例图,角上标「**来自 Civitai**」—— 只在 Mosael 里显示,不改那台 ComfyUI。挑哪一张
  跟着 NSFW 那组设置:照常时用作者排在前的那张,别的用分级最低的;
- 「**存为预览图**」把它写到那台 ComfyUI 上模型的旁边(512 宽,先确认,写明哪台服务器、哪个目录;按文件名对上的会多提醒一句)。
  工具条上「**为缺预览图的模型补图**」逐个找、按哈希对上的直接存回,按文件名对上的不替你存、做完列出来。这两样经
  ComfyUI-Custom-Scripts 的接口写;没装它时按钮是灰的、写着缺什么。那台服务器上已经有预览图的不会被覆盖。

**预览视频**:模型旁边有和它同名的 `.mp4` / `.webm`,或 Civitai 上的示例只有视频(Wan 这类视频模型常这样)时,卡片上是第一帧,
鼠标移上去静音循环播放,详情里能播;模糊着、不显示时不播。存回那台 ComfyUI 的是视频本身(`模型名.mp4`)—— ComfyUI 自己的模型列表
只认图,在那边看不到这类预览。文件名带 `[ ]` 的模型,ComfyUI 找不到它旁边的图,Mosael 按名字直接读。

**右键菜单**:卡片、列表的一行右键,悬停时右上角的「⋯」,或聚焦后按 Shift+F10 / 菜单键,是同一份菜单:打开详情、用它生成、复制
文件名 / 完整路径、在用的工作流、打开原链接、在 Civitai 上找、存为预览图、查看大图(当前筛出来的、看得清的能左右翻;点的是模糊着的
那张时只开它)、标为 / 不是 NSFW。点不了的条目写着为什么。Mosael 不删、不改名、不移动模型文件。

### 下载模型

**缺的模型一键下载。** 工作流里声明了下载地址(ComfyUI 官方模板就是这么写的)、这台服务器上又没有的模型，列在左边底部的

也可以点「**下载模型**」贴一个链接：HuggingFace 上的文件、Civitai 的模型页或下载链接(civitai.red、civitai.green 也认)、
ModelScope(魔搭)的模型页或文件、别的直链都行 —— 先「解析」出文件名、大小和建议放进的目录，确认后下到那台 ComfyUI 上。
开始之后切到「下载记录」看进度，在那里或任务中心里能取消；下完马上就能在生成时选到它。贴的是 ModelScope 的模型页时，
里面只有一个模型文件就下它；有好几个会列出来，请到「模型文件」页点进要的那个，复制它的地址再贴。

![从工作流详情里「缺的模型」点下载：这个模型工作流没写地址，下载框写明要的是 text_encoders 里的哪个文件，等你贴链接](/media/screens/model-download.png)

几件要知道的事：

- **同名文件不会被覆盖**：目录里已经有这个名字时，要先换一个名字(会给你一个建议)。Mosael 不删除、不改名任何模型文件。
- ComfyUI 在**另一台机器**上时，下载由那台机器上的 **ComfyUI-Manager** 去做：看不到按字节的进度，开始之后在 Mosael 里取消只是不再等，
  那台机器上的下载还会继续 —— 下载框里会先说清楚。局域网里用 `--listen 0.0.0.0` 开着的 ComfyUI，Manager 默认不让经网络装模型：
  在那台机器上打开 `ComfyUI/user/__manager/config.ini`，把 `network_mode` 改成 `personal_cloud`，重启 ComfyUI 就行
  (模型库会把原因和这一步写清楚)。
- ComfyUI 就在**这台电脑**上时，Mosael 直接写进它的 models 目录：看得到进度、能取消，开始前会查剩余空间。
- 要同意条款的 HuggingFace 仓库、要登录的 Civitai 模型、私有的 ModelScope 模型，在连接的凭据里填「HuggingFace 令牌」
  「Civitai 令牌」「ModelScope 令牌」。令牌只发给它自己那个站；经 ComfyUI-Manager 下载要带 Civitai 令牌时，下载框会提醒
  它会留在那台机器的任务记录里，HuggingFace、ModelScope 的令牌则经 Manager 带不过去。

**读不出来时**：模型库正中写着「模型库没读出来」和一句该做什么，原始报错收在「详情」里；旁边是「重试」和「去检查连接设置」
(关掉模型库、展开这个连接、停在服务器地址那一格)。

## 工作流库：看、管这台服务器上的工作流

点连接标题行上的「**打开工作流库**」，和模型库同一套样子：

- **左边一列**：全部，然后是那台机器上 `workflows/` 里的**文件夹树** —— 和 ComfyUI 自己左边「工作流」里的文件夹是同一份，按名字排，

  还有「**回收站**」。选一个文件夹只看它和它下面的，搜索框上写着「在「这个文件夹」里搜索 N 张工作流」。
- **工具条**：搜索(名字、路径、缺的节点类型、用到的模型、输入输出的名字都参与)、按种类筛(图像 / 视频 / 音频 / 转不过来的)、

  旁路的半透明；下面写着名字、种类、节点数和「缺几种节点 / 缺几个模型」。

**右键菜单**：在一张卡片(或列表的一行)上右键、点悬停时右上角出现的「⋯」，或者选中它按 Shift+F10 / 菜单键，打开的是同一份菜单：
打开详情、在工作台里打开(网页版是在 ComfyUI 里打开) | 编辑应用表单… | 复制…、改名…、移动到…、导出 JSON | 复制路径 | 下载缺的模型、

还挑不了应用表单的项……)。
详情头上的「更多操作」里也是复制、改名、移动、导出、复制路径和删除。

**改那台机器上的文件**，每次都先确认、写明改的是哪台服务器上 `workflows/` 里的文件：

- **复制 / 改名**：路径可以带子目录，`.json` 不用写；名字不合格(带 `..`、反斜杠、`:*?"<>|`、以点开头)当场说。那台机器上已经有这个名字时
  **不会覆盖**，给你一个建议名。复制默认起一个不撞名的名字；在详情里做完停在新的那一张上，在列表上(右键菜单)做的留在列表上。
- **移动到…**：挑一个文件夹(或 `workflows/` 顶层)，名字不变。也可以直接把卡片拖到左边的文件夹(或「全部」)上，松手弹出同一个确认框，
  那个文件夹已经选好。目标里已经有同名的就不覆盖，给建议名；Mosael 里有地方在用它的，确认框里说一声 —— 换了路径，它们跑的时候会说找不到这个模型。
- **删除**：不是真删，是挪进那台机器上的回收目录(`.mosael-trash/workflows`)，确认框里还列出 Mosael 里谁在用它(删了之后它们跑的时候会
  说找不到这个模型)。删过的在左边「回收站」里，能恢复；原处被占了就换个名字。Mosael 不提供清空 —— 真要删掉，在那台机器上删这个目录。
- **导出 JSON**：下载到这台电脑，不碰那台机器。**复制路径**：把它相对 `workflows/` 的路径放进剪贴板。

**文件夹**：左边一列顶上的「**新建文件夹**」建在选中的那个文件夹里(没选就建在顶层)；文件夹上右键(或悬停时的「⋯」、Shift+F10)
还有「新建子文件夹…」「改名…」「删除…」。也都先确认，经 ComfyUI 自己的接口改：

- **新建**：ComfyUI 没有「建目录」的接口，Mosael 往里面写一个隐藏的占位文件 `.mosael-folder`(ComfyUI 写文件时会把目录建出来)。
  ComfyUI 自己的侧栏只列有工作流的文件夹，所以空文件夹在那边要等挪进去一张才看得见。已经有这个名字(不分大小写)就不建，给建议名。
- **改名**：路径里换了上级就是挪到别的文件夹里。整个目录一次挪过去，里面的工作流跟着换路径 —— 确认框里写着几张，Mosael 里在用其中哪几张。
  目标已经有了不合并进去，给建议名；不能挪进它自己里面。
- **删除只删空的**：里面还有文件(工作流，或者拷进去的压缩包这类别的文件)时菜单上点不了，写着还有几个 —— 先把它们挪走或一张张删掉
  (各自确认、各自在回收站里能恢复)。空的文件夹挪进回收目录(ComfyUI 的接口删不了目录，Mosael 也不硬删)，回收站里不多出一条。
  删之前 Mosael 再问一遍那台机器:这期间在 ComfyUI 里往里面存了东西，就不删，照实说里面现在有几个。

改完之后工作流库、生成模型和工具清单跟着刷新。改之前插件都现查一遍那台机器:要挪的那张已经不在了、目标被占了、文件夹里又有了东西，
都照实说出来、不硬改，列表也跟着重新读一遍。

**打开一张只有一个按钮**：桌面版是「**在工作台里打开**」—— 在这个连接自己的内嵌浏览器里打开这台 ComfyUI 的画布，并打开这一张
(和在它左边「工作流」里点开一样；开着、改过还没存的不会丢)，旁边是 Mosael 的面板(见下文「工作台」，面板能收起来，收起来就是一块
干净的 ComfyUI 画布)；网页版没有工作台，是「**在 ComfyUI 里打开**」—— 在新标签页里打开 ComfyUI，并告诉你在左边「工作流」里点开哪一张。
在 ComfyUI 里存好、回到 Mosael，工作流库自己刷新，还停在原来那一张。ComfyUI 放在要登录的反向代理后面时，第一次要在那个内嵌浏览器里登一次。

**新建**：工具条上的「**新建**」在这台 ComfyUI 自己的画布上开一张新的工作流 —— 桌面版打开工作台、在画布上执行 ComfyUI 菜单里
「工作流 → 新建」那条命令(开在新标签里，开着的那几张不动)；网页版在新标签页里打开 ComfyUI，在那边点「新建」。在 ComfyUI 里搭好、
Ctrl+S 存好，回到 Mosael，工作流库自己刷新，新的那张就在列表里。这版 ComfyUI 前端没有这条命令时，Mosael 说清楚、画布照样开着，
自己在 ComfyUI 里点「新建」就行。

**画布操控方式**：工作台顶栏上有一个「**触控板 / 鼠标**」开关。触控板是双指滑动平移、捏合缩放(左键拖是框选)；鼠标是滚轮缩放、
拖动空白处平移(ComfyUI 自己的缺省)。在 Mac 上默认是触控板，别处默认是鼠标；每个连接各记各的，记在这台电脑上。它**只在 Mosael 里
这个连接上生效**：ComfyUI 把这个设置存在服务器上，Mosael 设好之后拦下写回服务器的那一下，所以在 Mac 上连别人 Windows 上的 ComfyUI、
切成触控板，坐在那台机器前面的人用的还是他自己的设置。每次 ComfyUI 页面重新载入后都会再设一次。ComfyUI 前端太旧、没有这个设置时，
开关藏起来，留一个小图标说明为什么。

### 应用：挑出给别人填的几项

一张工作流动辄几十项参数，填的人只需要其中三五项。在详情里点「**应用**」那一节的「**编辑应用表单**」，像搭一张表单那样把它搭出来。
最上面是**应用名**和**说明**(给填表的人看的一句话)，下面一行小字说它存在哪。再往下是这几块：

- **工作流里能填的**(左边)：这张工作流全部能填的项，**按节点分组** —— 组名是节点的名字：你在 ComfyUI 里给节点起过标题就用标题，
  没起就用 ComfyUI 给这类节点的名字(「K 采样器」「Lora Loader 🐍」)，不是 `LoraLoader|pysssss` 这种内部类名；种子、尺寸、跑几遍
  在「整张图」那一组。每一行写着名字和工作流里现在的值，点「**+**」放进表单，已经在表单上的打着勾，再点一下拿掉；能搜名字或节点。
  悬停看得到 ComfyUI 给这一格的说明和节点号、类名(排错用)。子图里面的节点这一版还不能放进来。
- **表单**(中间)：挑进来的项一张一张卡片，左边一个种类图标(文字、图片、模型、数字、选项……)。按住手柄**拖**着排顺序，键盘上
  聚焦手柄按 ↑ ↓ 也行；名字**就地改**(「人物照片」「风格」)；卡片上的「**设置**」里：文字项可以定成**主提示词**(写进 AI 工作台、
  画板的提示词框，关掉就是表单上单独的一格文字)，下拉和选模型文件的项可以**收窄可选值**(只许从你勾的那几个里挑)，也能上移下移、
  拿掉。表单还空着时点「**按推荐先挑一版**」：提示词、反向提示词、主模型、种子、尺寸、跑几遍，加上每一个读图 / 视频 / 音频的
  槽位，挑好再改。一项都不挑也行 —— 那样用的人看到的是全部能填的项。
- **结果取自**(表单下面)：工作流有几个出图的节点时，在要的那个上点「**只要这个节点的图**」。以后在 AI 工作台、画板、工作流节点里
  用这张工作流时，只取标了的节点出的图，其他预览节点的不要；一个都不标就按 Mosael 猜的最终结果。标了的写着「结果取自这个节点」，
  能撤销。「结果取自」照旧能每次改。
- **预览**(右边)：用的人看到的就是这样，用的是生成面板那套控件，能试着填，不会存。表单还空着时，这里画的是现在用的人看到的那张
  (全部能填的项)。

尾上写着有没有没保存的修改；有修改时关掉会先问一句。点「**保存到工作流…**」先确认是哪台服务器上的哪个文件：应用表单**存进这张工作流
文件里**，复制、导出、拷到另一台 ComfyUI 都跟着走，用同一台 ComfyUI 的人看到的是同一张表；只改应用表单这部分，工作流别的地方一个字
都不动。这张工作流要是正开在 ComfyUI 里、又有没存的改动，在那边保存时会盖掉这次的修改；它刚在 ComfyUI 里存过的话 Mosael 不写，
让你重新打开再改。一项都不挑就是去掉应用表单。

工作台的「应用」面板里是同一个编辑器；那一列窄，三块换成「**挑项 / 表单 / 预览**」三个标签。窗口太窄时弹窗也一样。

有了应用表单之后：

- 表单上只有挑的那几项，按你排的顺序、用你起的名字；工具「工作流 · 名字」的入参也只剩这几项。
- **没挑的项照工作流原样跑**：没定成主提示词的提示词格用工作流里存的那句，没挑种子就照工作流自己的设定(固定的留着)，
  画板格子里以前存着的值不再写进图。
- 几个读图节点各有名字：AI 工作台缩略图角上、画板素材格的悬停说明、工作流节点那一格下面都标着「人物」「背景」，
  第几张接到哪个节点一目了然。
- 工作流在 ComfyUI 里改过、某一项对不上了(节点静音或删了、那一格被拉成了连线、收窄的可选值没了)，它不进表单；
  编辑器里那一项标着原因：只是收窄的可选值没了的，点「**只留还在的可选值**」就又能用；别的点「拿掉」，或者「去掉失效的 N 项」
  一次去掉。工作流库的详情里也列着，点「**去掉失效的…**」一键去掉。

### 导入别处的工作流并补齐

工具条上的「**导入**」(也可以直接把文件拖到工作流库上)收这几样：

- ComfyUI 里「保存 / 导出」的 JSON 和「导出 (API)」的 JSON，直接贴进来也行；
- ComfyUI 存出来的 PNG / WebP(图里带着工作流)；
- 压缩包(取第一张，别的写在说明里)；
- 链接：HuggingFace、Civitai、ModelScope 上那个文件的地址，或这台 ComfyUI 自己的地址；别的网站请先下载下来再拖进来。

缺的节点和节点包、缺的模型，以及要存成的路径(默认用建议的名字，撞名会给另一个)。确认「存进那台服务器」才写进它的 `workflows/`，
不覆盖已有的。存好停在这一张上，缺的东西在它的详情里补。

## 工作台：在 ComfyUI 自己的画布旁边用 Mosael 的面板

桌面版里，工作流库详情头上的「**在工作台里打开**」、工具条上的「**新建**」、AI Studio「引擎参数」里选中的 ComfyUI 工作流下面的
「**在工作台里打开**」，都会全屏打开**工作台**：左边整块是这台 ComfyUI 自己的画布(就是它自己的界面，每个自定义节点照常能用)，
Mosael 的东西都画在它旁边 ——

- **顶栏**：连接、工作流名、有没存的改动时一个小圆点、画布操控方式(触控板 / 鼠标)、「**保存**」(和在画布里按 Ctrl+S 一样，存进
  那台 ComfyUI 上的工作流文件；没存过的会让你起个名字)、「**运行**」、收起 / 展开右边那一列。右边那一列能拉宽拉窄：拖它的左边沿
  (或在那条边上按左右方向键，双击回到默认宽)，宽度记在本机，画布跟着让。
- **模型库**：在画布上选中一个加载模型的节点(大模型、LoRA、VAE、ControlNet、放大……)，这里只列那个目录的模型，带预览图、底模家族
  和触发词，能搜、能按底模家族筛；点一行就填进那一格(先查它在那一格的下拉里)，点缩略图看大图(这一页看得清的预览图成组翻；点的是模糊着、
  不显示的那张时只开它)。缩略图照「预览图怎么显示」显示，判成 NSFW、来自 Civitai 的带角标，面板上也能改设置。那一格选的文件这台 ComfyUI 上没有，就地「找下载地址」或贴个链接、认一下、确认后下到那个目录；下完画布上的下拉
  会刷新，新文件就在里面。
- **缺失项**：画布上**现在这张**(含没存的改动)缺的节点和模型放在一张清单上，跟着画布走 —— 在 ComfyUI 里换一张工作流、改了图，
  它自己重新检查(「重新检查」也还在)。每一项都能「**定位**」：在画布上选中用它的那个节点、移到中间(好几处的点一下换下一处；在子图里的
  先进那张子图，ComfyUI 前端进不了子图时写明在哪张子图里)。同一个节点包缺的几种节点放一组，一个「装上」(经 ComfyUI-Manager，先就地
  确认，装完要重启 ComfyUI 才加载 —— 重启前先把画布存好)；那台 ComfyUI 没装 Manager 时写明认不出、也装不了。工作流里写了下载地址的
  模型一键「下载」；没写的点「**找下载地址**」，按文件名(先完整的名字，再去掉扩展名)去 Civitai、HuggingFace、ModelScope 搜，列出哪家、
  哪个仓库、确切的文件名、大小、底模，文件名一致的排在前面、从不替你选相近的；点一个就地确认后下到那个目录，搜不到就在那一格贴链接。
  下完、装完它自己重新检查。
- **应用**：工作流库里那个应用表单编辑器，绑在画布上这张上。改完点「写进画布」—— 改的是画布上那几个节点的标记，不写文件；点顶栏的
  「保存」才存进工作流文件，和你在 ComfyUI 里改别的东西是同一次保存。
- **运行与结果**：「运行」跑的是**画布上现在这张(含没存的改动)**，和别处的生成一样是一个生成任务(任务中心看得到、能取消、
  Mosael 重启后接着等，结果进素材库)。画布上照常亮起正在跑的节点，这里写着正在跑哪个节点、第几步；跑完的结果**按来自的节点分组**、
  标着节点名，点一张看大图(这一次的产出成组翻)。每组一个「**只要这个节点的图**」—— 标的是**输出节点**，不是收藏这一张：以后在
  AI 工作台、画板、工作流节点里用这张工作流时，只取它出的图，其他预览节点的不要(标在画布上，保存后生效)。已经标着的那组写「结果取自
  这个节点」，能「撤销」；还标着别的节点时上面也写明结果取自哪几个。在 ComfyUI 里换了一张工作流，这一张跑过的排在前面，换走之前跑的
  收在「其他工作流」里。没存过的新工作流要先存一次才能在这里跑。

工作台和画布通话靠 Mosael 主进程注入的一段固定脚本，只由 Mosael 去读画布、不让页面调到 Mosael。ComfyUI 前端太旧、缺了哪一样，
对应的那一处就写「这版 ComfyUI 前端不支持……」，画布照常是一个能用的 ComfyUI。点「返回 Mosael」回来，工作流库自己刷新。
网页版没有工作台(工作流库里是「在 ComfyUI 里打开」，在新标签页里打开 ComfyUI)。

## 进度、取消与重启

- 生成进度来自 ComfyUI 本身：任务中心里能看到正在跑哪个节点(用你起的节点名)、第几步、第几个节点。
- 在任务中心**取消**，ComfyUI 会真的停下**这一个**任务(正在跑的中断，排队中的从队列里删掉)，不会影响同一台
  机器上别人的任务。
- Mosael 在生成途中重启(比如更新之后)，重新打开会**接着等**那个任务，不会重新提交一遍。
- 一次生成最长可以跑 6 小时；更长的视频请拆成几段。

## 从旧版本升级

以前的版本里 ComfyUI 是「设置 → AI 绘图」里的一家供应商，升级时会自动搬过来：

- 每条旧连接变成 ComfyUI 插件的一个连接(地址、启用状态、粘贴过的模板都保留，`network:comfyui` 已授权)；
- 画板、工作流、定时任务、生成历史里选过的「工作流」改成直接用那个工作流模型，调过的工作流参数原样保留；
- 旧的「workflow」模型：粘过模板的连接变成「API 模板」，没粘的图像生成变成「内置文生图」。没粘模板的
  **视频**原来就跑不起来，保持原样，用到时会提示这个模型不可用，换一个视频工作流即可。

已经接好的 ComfyUI 连接升级之后，新工具会自动出现在工具表里，按上面的默认开放。

**这一版升级上来时连接会先停用一次**：插件如实申报了它真会做的几件事，比以前多四项权限 —— `network:huggingface`、`network:civitai`、
`network:modelscope`(模型库解析链接、下载模型时连这几个站)和 `filesystem:write`(ComfyUI 在这台电脑上时写它的 models 目录)。
连接卡片最上面写着多要了哪几项，点「授予这 4 项」马上恢复，之前授予的不受影响；插件列表上它标着「待授权」。这一版的插件又多申报三项
(`network:github`、`network:pypi`、`network:pytorch`,让 Mosael 装 ComfyUI 时要连这几处),升上来时同样先停用一次、等你授予。插件升级之后，
Mosael 一分钟内会重新读一遍每个连接的模型和工具清单，表单上的默认值(比如跑几遍默认 1 遍)跟着更新，不用手动刷新。

## 认不出的工作流：API 模板

Mosael 读工作流用的是 ComfyUI 保存的界面格式，和 ComfyUI 自己提交时的规矩一样：关掉(旁路)的节点让上游直通下去、
静音的节点不跑，Reroute、Primitive、Get / Set 这些界面上的辅助节点都认，子图会展开成里面的节点，老版本 ComfyUI
存的工作流也读得出。旧式的「组节点」请先在 ComfyUI 里转成子图再保存。个别非常规的(依赖界面扩展动态加输入的自定义
节点)可能转不过来(「列出工作流」会把转不过来的那张和原因一起列出来)。这时在 ComfyUI 里用「**导出 (API)**」
