Mosael 的 AI 能力(智能体对话、文生图 / 视频、配音、转写等)都由你自带账号驱动：多数服务商填 **API Key**，订阅计划则走**授权登录**(见下)。凭据由当前连接的后端保存，调用服务时用于向对应端点鉴权；连接远程后端时，凭据也保存在远端。设置接口只回显掩码或授权状态。

## 按能力分区配置

设置页把 AI 供应商按**能力**分成四个分区，各自独立配置：

| 分区 | 用途 |
| --- | --- |
| **AI 对话** | 智能体与工作流的 LLM 节点 |
| **AI 绘图** | 文生图(图像生成) |
| **AI 视频** | 文生视频 |
| **AI 音频** | 三块：语音合成（TTS 配音）、播客对话、音乐与音效生成 |

每个分区顶部是**默认模型**：为该能力选定默认的供应商与模型；画板、AI Studio、工作流的生成节点都会**预选**它，用到时可临时换。没设默认时这些地方显示「选择模型」，要你先选一个——不会拿列表里排第一的那个顶上。下拉里列的是**模型**(形如「DeepSeek · deepseek-v4-pro」)，不是供应商——同一个供应商下的几个模型会各自出现。

![设置 → AI 对话:默认模型,下面是这项能力的连接(演示里一条占位连接、一条本机 Ollama)](/media/screens/settings-models.png)

**按能力配置供应商**——设置里 AI 对话 / 绘图 / 视频 / 音频各自独立，「添加供应商」后前端只渲染该供应商声明的字段，凭据保存在当前后端：

## 一条连接 = 一个端点 + 一份凭据

供应商**不等于模型，也不等于连接**：一条连接记的是「当前用户连到哪里、用哪份凭据」，它下面可以挂
**任意多个模型**。端点与非密选项、API Key / OAuth 状态分开保存，便于分别更新，但都只属于创建它的
用户；不会显示、选择或回退到别人的连接。点供应商行右侧的展开箭头，看到的就是这条连接的模型列表。

## 添加一个供应商

进对应分区点「**添加供应商**」：

1. 选**服务商**。列表按分区过滤，目录随版本扩充：
   - **AI 对话**：阿里云百炼、Kimi、DeepSeek、MiniMax、OpenAI、OpenAI 兼容端点，以及下面「订阅计划」那一组；
   - **AI 绘图**：阿里云百炼、火山方舟 ARK、OpenAI、OpenAI 兼容端点、Evolink；
   - **AI 视频**：阿里云百炼、火山方舟 ARK、MiniMax、火山引擎 即梦 AI(视觉)、HeyGen、Hedra、Google(Veo)、Evolink、快手可灵 —— 其中即梦、HeyGen、Hedra 和可灵的数字人模型见[数字人](/docs/guides/digital-humans)；
   - **AI 音频**：语音合成（阿里云百炼、OpenAI、火山引擎语音合成）、播客对话（火山引擎播客）、音乐与音效（见下）。
2. 填**名称**(便于区分，如「我的 Kimi」)。
3. 贴 **API Key**(订阅计划没有这一项，改为保存后授权登录)。字段旁有「**获取 API Key ↗**」直达该服务商的密钥控制台。
4. **Base URL**：API Key 连接留空即用该服务商默认(占位符会显示默认值);自建 OpenAI 兼容端点需自己填。
   订阅/OAuth 连接没有也不需要这个字段——端点由对应 Provider Adapter 管理，不要为它编一个服务地址。
5. **模型**可选，填了就作为这条供应商的第一个模型；之后随时可以再加。

添加后可随时**启用 / 停用**，不必删。

### 字节跳动：同一企业，两套产品协议

火山方舟 Ark 的 Seedream / Seedance 生成接口与火山引擎语音技术的 TTS / 播客接口都属于字节跳动，
但控制台、凭据、端点和请求协议不能互换。Mosael 因此把它们归在同一企业命名空间下，同时保留
独立 Adapter 和兼容的连接类型；目录归属不会把两套凭据错误地合并。

火山方舟的**内容审核**拦下请求时(提示词、首帧 / 参考图、参考视频或音频里有它不收的内容，或生成的结果没过)，报错说清是哪一样被拦、
明说这是**服务商的审核、不是 Mosael 拦的**；首帧里是真人照片被当成隐私信息拦下时，建议换不拦真人的模型 —— 比如 Evolink 上的 Seedance。
任务失败但不是审核的，也带上服务商给的错误码和原因。

### Evolink：一个连接挂多个生成引擎

Evolink 是统一图像/视频网关：只需一份 Evolink API Key，同一连接下可分别加入 Seedance、Kling、
Veo、海螺、WAN、Sora、GPT Image、Gemini、Seedream 等模型。Mosael 会把本地参考图先上传到
Evolink Files API；视频与音频输入也走同一入口，但保留首尾帧、参考、编辑源和续写片段等角色。
系统按精确模型 id 提交异步任务，再把限时产物地址立即下载回本地素材库。

这条路由与火山方舟的 Seedance Adapter 相互独立，可按内容策略、地区与账号可用性选择。Mosael
不会在本地额外拦「真人」提示词，但也不承诺绕过审核：最终是否通过仍由 Evolink 当前路由的上游模型决定。

Evolink 的 **GPT Image** 有 `gpt-image-2`、`gpt-image-2-beta`、`gpt-image-2.5-flare`(日常出图)、`gpt-image-2.5-sunburst`(精修)
和 `gpt-image-1.5`。它们按 token 计费，价钱主要由**画质**和**分辨率档**决定(1K 1:1 低画质一张不到一美分，2K 高画质要几毛钱)，
所以 AI Studio、画板和工作流节点里都摆出这两项，默认取最便宜的 —— 低画质、1K、1:1。画质下面有一句价差说明：低画质约是中画质的九分之一、
高画质约是中画质的 4 倍，先用低画质试，定稿再往上调。`gpt-image-2-beta` 固定一张一价、只出 1K，不开放画质。这几个型号默认不启用：
在 Evolink 连接里打开要用的那个，需要的话设成默认生图模型。

### ComfyUI:由插件提供

ComfyUI 不在「添加供应商」的列表里:它由随 Mosael 一起发的 ComfyUI 插件接入,在「插件」页建连接(一台服务器一个)。
接好之后它的连接出现在绘图 / 视频分区里,标着「由插件提供」,模型就是 ComfyUI 里保存的每张工作流,可以设成默认模型。
详见 [用 ComfyUI 生成](/docs/guides/comfyui)。

### 阿里云百炼：CosyVoice 能念配音库里的嗓子

百炼连接的语音合成下有两个引擎：「阿里云百炼(qwen-tts)」和「阿里云百炼(CosyVoice)」，用同一把 Key。CosyVoice 除了系统音色，
还能把配音库里的一把嗓子**复刻到你自己的百炼账号**再用它念：配音时音色下拉多一组「我的克隆音色」，配音库里每把嗓子多一个「复刻到百炼」。

- 复刻这一步免费，念的时候按 CosyVoice 的字符价计费；第一次把某把嗓子传上去要你确认一次，没声明是谁的嗓子不复刻。
- 副本跟着**钥匙**走：同一条连接下每个人用自己的 Key，复刻出来的音色只在那个人的账号里。也跟着**模型**走：连接上配的 CosyVoice 模型
  换了，下次用到时在新模型上再复刻一份，旧的那份不动。
- 百炼把副本删了(一年没被合成用过会自动删)，下次用到时自动重建；在 Mosael 里删掉这把嗓子，百炼上的副本一起删，删不掉的会列出来。
- 百炼语音合成失败时，报错带着百炼回包里的原话(`code: message`)，比如音色不存在、模型不对，而不只是一行状态码。

怎么用见[剪辑 → 不装本机引擎,用百炼念自己的音色](/docs/guides/editing)；要给 CosyVoice 记上价，见下面「成本规则」。

### 音乐与音效

「AI 音频」分区的「音乐与音效生成」管的是**生成**音频的连接（和语音合成是两种能力：一个念字，一个作曲 / 做音效），
有自己的默认模型。已接入的（都是照官方文档写的，2026-09-25 核对；还没有用真实密钥跑过）：

| 服务商 | 模型 | 能做什么 | 说明 |
| --- | --- | --- | --- |
| Google | `lyria-3.5`、`lyria-3-pro-preview`、`lyria-3-clip-preview` | 歌曲、纯音乐、图生音乐 | 同一把 Gemini API Key。没有时长、BPM 这类参数，全靠提示词和歌词 |
| Evolink | `suno-v5.5-beta` 等六个 Suno 型号 | 歌曲、纯音乐 | 一次交回两首；只有 v5.5 能指定时长（10–360 秒） |
| 快手可灵 | `kling-text-to-audio`、`kling-video-to-audio` | 音效；给视频配音效 / 配乐 | 视频 3–20 秒、只收链接；音效 3–10 秒 |
| 阿里云百炼 | `fun-music-v1`、`fun-music-preview`、`qwen-audio-3.1-tts-next` | 歌曲、纯音乐；音效 / 环境声 | 仅北京地域；Fun-Music 要先在模型广场申请 |
| 火山引擎 AI 音乐生成 | `GenSongForTime`、`GenBGMForTime`（后付费）、`GenSongV4`、`GenBGM`（资源包） | 人声歌曲、纯音乐 | 单独一条连接：账号级 **AK + SK**（企业认证账号）；纯音乐描述只收中文 |

OpenAI 目前没有音乐 / 音效生成接口（只有语音合成），所以不在表里。MiniMax 音乐自 2026-08-20 起不再对新用户开放，
也不在表里；MiniMax 连接照常做对话和海螺视频。插件也可以提供音频模型（`kind: "audio"`），
和内置的一样进选择器。

## 管理它下面的模型

展开供应商行：

- **加模型**：底部「添加模型…」是一个**带搜索**的输入框，列出该端点目录里还没配的模型。目录动辄两三百个(百炼有 233 个)，所以是搜索而不是长列表。目录里没有的(私有部署、别名)**直接输入名字**即可加入，和目录来的完全平权，只会额外标一个「目录中已不存在」。
- **启用 / 停用**单个模型：右侧开关。停用的不会出现在默认模型下拉与各处的模型选择器里。
- **模型设置**(齿轮图标):
  - **能力**：这个模型能用在哪些分区(对话 / 图像 / 视频 / 音乐音效 / 配音 / 播客)。没标时按下面「能力标签」一节自动识别。这就是「同一个端点既有对话模型又有生图模型」的表达方式。
  - **上下文长度**：决定这个模型能聊多久、什么时候触发上下文整理。默认取服务商目录，目录没报时用内置的已查证上限；都查不到时云端模型按 128K、本机或局域网的端点（localhost、私有地址）按 64K 算 —— 32K 连工具说明都装不下。可以手动改，下方会说明当前这个值是**你改的 / 目录给的 / 内置的 / 兜底的**。vLLM 报的上下文长度能认出来。
  - **最大输出 Token**：单次回复能写多长，思考过程也算在内。查不到时按上下文长度的四分之一估（封顶 32,768）；不填时实际发出的是一个默认预算，不是模型上限，下方会写明。
  - **高级**(默认收起)：推理模型、支持图片输入、支持 reasoning_effort、支持 json_schema(结构化输出)、支持 developer 角色几个兼容开关。只有端点报错时才需要来翻；json_schema 对查证过的供应商直接给出结论。
  - **参数按什么来**(生图 / 视频模型才有，两种能力都有的模型各配各的)：见下一节。
- **删除**：垃圾桶图标。

> 上下文长度与那几个兼容开关只对**对话模型**显示——给一个生图模型问「支不支持 developer 角色」纯属噪音。

## 能力标签：哪些模型进生成下拉

模型行上那几枚小标签(对话、图像、视频……)就是这个模型的**能力**，决定它出现在哪些下拉里。点标签即可修改；
虚线框的是**自动识别**的，实心的是你标过的。

没标过的模型按这条规则认：

- **生成能力(图像 / 视频 / 音乐音效)和配音要有依据**：内置目录认得这个模型(如 `gpt-image-2`、万相、Seedance、
  Suno)，或连接自己声明过(插件提供的模型)，或你给它写过这种生成的「参数按什么来」，或这家服务商本来就只做
  这一件事(火山语音、火山音乐)。
- **其余一律只当对话模型**——前提是这家服务商做对话；Evolink、方舟这类只做生成的服务商上认不出的模型，
  什么都不是，不进任何下拉。

所以 OpenAI 兼容端点(147ai、Ollama、各种中转)上的对话模型**不会**再冒到画板和 AI Studio 的出图下拉里；反过来，
中转上一个能出图、但名字没被内置目录收录的模型，要你在这里标上「图像」才会出现。这时模型列表顶部会提示：
「这个连接上的模型默认只当对话模型;能出图 / 视频的,在这里标上」。

此前没标过能力的模型，升级时会按这条规则把能力**写成标签**；你设成默认模型的、真出过图 / 视频的，
那项能力照旧保留，你自己标过的一律不动。存着的选择(画板格、工作流节点)若指着一个不再有这项能力的模型，
选择器显示「选择模型」，提交时会说明是「没有标上这项能力」，重新选一个或去标上即可。

## 生图 / 视频模型的参数按什么来

内置的那张表只装我们**查证过**的模型：它支持哪几档尺寸、时长上限多少、要不要参考图。所以模型设置里这一格默认是 **「自动识别」**——按模型名去认。认出来了，生成界面上就会出现对应的旋钮。

认不出来的情况有三种常见来源：你手填的别名(`gpt-image-2-client` 其实就是 gpt-image-2)、私有部署、经中转端点配的同一个模型。这时候会有两条出路：

- **「和某个模型一样」**：直接指一个我们认得的模型。它是**指针**——以后我们把那份描述改宽了，指着它的行跟着变。首选这个。
- **「自己描述这个端点…」**(字段下面的链接)：目录里实在没有对应的(某个中转独有的组合)，就自己写一份参数组：勾出这个端点真会接受的旋钮、每个旋钮有哪几档、一开始停在哪一档，以及它的硬限制和请求形状上的怪脾气。写完保存，这一行就已经指着它了；之后改名、调字段、删除也从同一个地方进去。

有两条要说清楚：

- **我们不按模型名跨供应商猜。** 实测同一个 `qwen-image-edit`：阿里自家只收一张参考图、没有尺寸；经 Evolink 则收 14 张还能选尺寸。猜过去的参数会被端点当场拒掉。
- **认不出来时界面不会装作「这个模型就是没有参数」。** 它会说出这条通道**发得出**哪几项(请求是 Mosael 自己构造的，这一点不用查证)，同时说明没人验证过这个模型收哪些取值，所以生成界面先不摆出来。
- 参数组保存时只校验**形状**(清单得是文字、上限得是正整数、默认值要在清单里)，校验不了「这个端点真的支持吗」——那一条只有端点自己知道，填错了会在生成时被供应商拒掉。

**模型声明了默认值的参数，提交时照发。** AI Studio 的表单会把默认值预填出来；工作流、画板、智能体、定时任务提交时没给的那几项，
同样按模型声明的默认值写进请求，不会省掉之后落到服务商自己的默认上 —— 比如 Evolink 的 gpt-image-2 声明的是最便宜的低画质，
而服务商自己的默认是中画质。你明确给了的值照你给的发。

## 订阅计划：授权登录，不用 API Key

Claude Pro/Max、Kimi Code、ChatGPT Plus/Pro、GitHub Copilot、xAI、OpenRouter 这些**订阅计划**没有可填的密钥。在 AI 对话分区「添加供应商」时选对应条目，保存后回到列表点该行的「**授权登录**」：

1. 部分服务商先让你选**登录方式**(如 Codex 的「浏览器授权 / 设备码」)。
2. 弹窗里会出现**授权链接**或**设备码**，照着在浏览器里完成即可；需要粘贴授权码的会就地给输入框。
3. 授权成功后，该账号**实际可用的模型**会自动带回来(Copilot 的模型随订阅档位变、OpenRouter 有几百个)。

**令牌会自动续期**，不用你管——过期只是订阅制令牌的常态，应用会在用到它、以及每次打开设置页时自己刷新。只有**刷新失败**(在别处登出、授权被吊销)才会用警告色提示「需重新授权」，那时点「重新授权」即可。不想用了点「解除授权」。

AI Studio 用订阅模型分析已有图片或视频时，会继续使用**当前会话模型**：后端凭智能体短期令牌确认
会话身份，再通过无工具、无记忆的 Gateway 发送图片或视频采样帧。它不是公开反向代理，也不要求
`base_url`；视频原生整段输入暂不走这条 Gateway，请使用「自动」或「抽帧 + 转写」。

### 查订阅额度

订阅制的供应商行上会多一个**仪表图标**，点开显示当前计划、各项额度与重置时间。

它是**点击才查**的：这些额度接口都不是服务商承诺的公开 API(基本都是各家自己 CLI 内部在用)，后台定时轮询既容易撞限流，也会在对方改接口后变成一个一直在失败、却没人发现的任务。查不到时会直说是「这家不支持」还是「这次没查成」。

额度按服务商自己的说法显示。Kimi Code 的是百分比：「本周用量 83%」「频率限制 0%」(5 小时一个窗口)，和 Kimi 后台写的一样，
各自带着什么时候恢复 —— 不是「用了 83 次、共 100 次」。

## 能力提供方：每项能力用哪一家

「设置 → 能力提供方」一页列出 Mosael 自己的几项能力各用哪一家。每项一块：「用哪一家」里是**本机引擎和装了对应插件的连接并列可选**，
没配好的逐条写缺什么（不会出现在下拉里），底下一排「用在哪」标签现算这项能力被哪些地方用到；右上角「去插件市场找」打开按这项能力筛好的市场。

![设置 → 能力提供方:每项能力一块 —— 「用哪一家」、没配好的写着缺什么、「用在哪」,右上角「去插件市场找」](/media/screens/settings-capabilities.png)

| 能力 | 本机 / 内置 | 默认 |
| --- | --- | --- |
| 降噪 | 内置降噪、DeepFilterNet、RNNoise | 内置降噪（两个语音模型会去掉音乐，不自动选） |
| 分离人声 | Demucs（本机） | Demucs |
| 文档解析 | 本地解析 | 本地解析；MinerU 这类云端解析必须你自己选，不会自动选 |
| 素材外链 | 无，要对象存储插件的连接 | 只配好一家时自动用它；配了几家没选时，生成时先问你 |
| 配音 | 本地音色克隆、Edge 免费语音、OpenAI、火山、阿里云百炼 | **没有默认**：引擎和音色是成对选的，每个用到的地方自己点名 |
| 转写 | FunASR、WhisperX（本机） | 装好了运行环境的第一个（FunASR 在前）；没装的会指向「管理 → 引擎」 |
| 翻译 | Google 翻译（免费）、对话模型 | Google 翻译；对话模型花钱，要你选了、并用你自己的对话连接 |

**插件不会被悄悄选上**（素材外链只配了一家时除外）：装了转写、翻译或文档解析插件，要在这里设成默认，或在用到的地方点名。
剪辑页的转写和字幕翻译、工作流节点的引擎下拉、输入框的语音输入、文档的「重新解析」都照这一页来。插件作者怎么在这些能力上登记，见[开发插件](/docs/guides/writing-plugins)。

## 出站代理

服务商按地区限制访问时(表现为授权或调用被拒、提示 region not supported)，由部署管理员在管理 → **部署设置 → 出站代理** 填代理地址即可(它是整台部署的出口，只有部署管理员能改)。AI 供应商请求与授权登录都会走它。

- 本机回连**永不走代理**(否则智能体的工具调用会全部失效)，这条不需要你配。
- 内嵌浏览器**不受影响**：发布用的平台登录按发布账号单独配代理，不会被这里带偏。

## 网络抖动时的重试

管理 → **部署设置** 里可以调重试次数(就在出站代理下面:两者回答的都是「AI 调用怎么出去」)。它对**所有** AI 调用生效——对话、生图、生视频、语音、向量化，限流和 502 对它们一视同仁。遇到 429 / 5xx / 连接失败时按指数退避重试，期间不需要你做任何事。

## 成本规则

管理 → **成本规则** 里可给模型配计价(按 token / 按张 / 按秒 / 按条；只有部署管理员能改，其他成员在统计页看到的是按规则算出来的花费)，统计与任务中心会按规则累计 AI 费用；没配的用量标「未定价」。统计页「概览」里 AI 花费那一格的「N 未定价」，部署管理员可以直接点，落在这里；费用按天、按供应商的明细在「AI 用量」一栏，统计范围可选近 7 / 30 / 90 天。

规则按模型成组显示：一张卡片(或列表里的一行)列出这个模型的各项价格，来源标着「手动 / 目录 / 官方价目」。可以搜模型、供应商或备注，按供应商配置、能力、来源、币种筛选；右上角切换卡片 / 列表，选择会记住。列表视图里一个模型一行，价格是一排小块，点哪块就编辑哪一条(删除单条价格在编辑弹窗左下角)。

**分时段价格。**有的厂商按钟点收不同的价(如 DeepSeek 北京时间工作日 9:00–12:00、14:00–18:00 是高峰价，其余时间半价)。编辑规则时在单价下面加「分时段价格」：选时区(厂商用哪个就选哪个，不必自己换算)，再加若干时段 —— 起止时间、适用的星期、这段的单价。它是**同一条规则**的价目：记账时先按供应商、模型挑出这条规则，再按这次调用发生的时刻取价，落不进任何时段就按基础单价。法定节假日分不出来，会按工作日的价估。

**按分辨率分档。**生视频几乎家家按输出分辨率报价(万相 720P 和 1080P、海螺 768P 和 2K 不是一个价)。规则里有一格「**分辨率**」：
留空的那条是这个模型的基础档，其余每档一条(写 720p、1080p、2K 都行，大小写不论)。记账时按这次生成的分辨率挑：写了这一档的用它，
没单列的按基础档算；一个分辨率既没有自己的价、又没有基础档，就是未定价，不拿别的档顶。给某条连接或某个工作区单配的不分档价，
优先于通用的分档价。卡片和列表上每条价写出是哪一档，同一单位的几档挨着排、基础档在前。

**服务商回报了什么，就按什么记。**

- 回包里报了**用量**的，按报的用量乘价目：GPT Image 的文字输入、参考图输入、图像输出 token 各一个单价(计价单位里有「百万图像输入
  Token」)，Seedance 按成片 token，千问生图、Seedream 按服务商说的张数。只是按提示词长度估出来的 token 不计价 —— 宁可标「未定价」，
  一眼看得出缺什么。
- 回包里直接报了**扣费**的(Evolink)，记它报的数，不再按价目估。Evolink 按积分折算成美元，和它后台的账单对得上。
- **失败的调用**：服务商什么都没回(请求被当场拒掉)就记 0，不按请求了几张几秒去算；远端已经生成、扣了费，只是我们这边下载失败的，
  照服务商回报的用量或扣费记。

**免费的记 0、写明免费。** Edge 这类本来就不要钱的配音记 0，标成「免费」，不再算成「未定价」、也不会提醒你去配价格；花费汇总不收这几条，
人民币部署的账上不会冒出一笔 $0。

**语音合成记在连接的厂商名下。** 价目规则(「预填价格」填的、手写的)按厂商配，所以百炼一条连接下的 qwen-tts 和 CosyVoice 都记在
「阿里云百炼」名下，对得上价目表里百炼的语音价(CosyVoice 各型号按每万字符计)。CosyVoice 此前记在引擎名下，和价目永远对不上，念多少都是
「未定价」；升级时老账一并改了过来。升级**不替你建价目规则**：要按挂牌价给 CosyVoice 记账，在成本规则里对百炼那条连接点一次「预填价格」。
复刻音色那一步记一笔免费的用量(`tts / enroll_voice`)，账上看得到哪天、哪把嗓子、传到了哪条连接。

**拿服务商的回包核对。** 万相、MiniMax 回包里的成片秒数和分辨率、Evolink 出图回包里的 token 明细、百炼数字人回包里的时长，都会拿来和记下的计量比一比；
服务商报了扣费又带着明细的，按价目对明细算一遍和扣费比。对不上不改账，只记一条日志、在这条账里留下核对的依据。生视频的计量只记请求里写明的分辨率
(模型声明了默认值的已经写进请求)，不替它猜；「参考图」只数首帧、尾帧、参考图和蒙版。

**工作流的花费算在那次运行上。** 工作流里大模型的调用、生成、配音都挂在那次运行上(连同它派出的子任务)，执行历史里看得到这次运行花了多少，
管理页「谁在花钱」也不再漏掉它们。

**不同币种分开算。**人民币和美元的费用不会加在一起：统计、概览、管理页都按币种各写一笔(「¥12.30 + US$4.50」)，费用图一次画一种，多种币种时可以切换；不做汇率换算。同一次调用命中的几条规则币种不一致时，这次调用标为未定价并注明原因 —— 把规则改成同一种币即可。

「**预填价格**」按两个来源批量生成规则。弹窗里一家一行，可以逐家点「预填」，也可以「**全部预填**」，每家的结果就写在它那一行底下：

- **服务商自己的模型目录**带报价时(如 OpenRouter、订阅登录带回来的目录)以它为准。
- 目录不报价时(多数 OpenAI 兼容端点如此)，用应用内置的**官方价目表**补：DeepSeek、Kimi、阿里云百炼(对话、通义万相视频、图像、语音)、火山方舟(Seedance 视频、Seedream 图像)、火山语音、MiniMax(对话、海螺视频)、OpenAI(对话、GPT Image、TTS)、Anthropic、xAI、Google Veo，以及 Evolink 自己挂牌的 Seedance 和 GPT Image。每条都是在厂商官方定价页上逐条核对过的，规则的备注里写着出处和核对日期；币种按厂商挂牌(国内厂商人民币、海外美元)，接入点是国际站时取国际站价格。按时段变的价(如 DeepSeek 的峰谷)收成分时段价格；按输出分辨率分档的每档一条(万相、海螺、Seedance、Veo)；按上下文长度等分档的只记一档，其余写在备注里。
- 中转服务(自定义 OpenAI 兼容地址、Evolink 等)先查**它自己的**条目(它自己挂的价、它自己起的型号名，比如 147ai 的 `gpt-image-2-client`，备注写明实价未公开、按 OpenAI 官方价参考)；查不到，才在模型 id 唯一对应一家厂商时借用那家的挂牌价，备注会提醒中转商的实际收费可能不同。

两条规矩不变：**只补缺失的，已填的一律不动**(你核对过的价格可能含折扣或企业协议)；标价为 0 的不建规则 —— 那是「未标价 / 订阅内含」，不是「免费」。结果说清从目录、从价目表各建了几条，还有哪些模型没有价格要手动填。

**升级时自动补的几件事**：

- 这一版新加进价目表的型号(各家按分辨率的分档、GPT Image 的文字和参考图输入价、147ai 的 gpt-image-2-client、Evolink 的 Seedance 和
  GPT Image、海螺 H3 的 2K……)，老库升级时按「预填」同样的规矩补上 —— 只补模型行上真会用到的、只补缺的，你已有的规则一条不动；
  一直没点过预填、也没配价的其余型号，升级不替你补。
- **补算老账**：以前费用为空、现在按价目或服务商回报算得出来的生图、生视频、生音频补上费用；当场被拒却按请求记了钱的失败改成不计费；
  当时只按估出来的提示词 token 记了几十 micros 的 GPT Image 按回报的 token 重算。除此之外已经有费用的、算不出来的、分不清的都不动，对话的用量不补。
- **语音合成的老账照现在的口径改**：CosyVoice 的改记在百炼名下(见上面「语音合成记在连接的厂商名下」)；早先还躺在「未定价」里的 Edge 配音
  改成 0、标「免费」，不再算进「N 未定价」。只改费用为空的，已经有数的不动。

## 绑定关系：哪里没配，哪里会提醒

模型和用到它的地方是**绑定**的。没配好时，用到它的地方会给提醒 + 直达配置入口：

- 工作流的 **LLM 节点 / AI 生成节点**：没有可用供应商、或引用的供应商被删，属性面板顶部会出现琥珀 / 红色提示，点「去配置」直达设置。
- **AI Studio**的生成：没有任何可用生成模型时，列表顶部同样提示。

> 生成模型目录始终有内置项；能不能真跑取决于**对应服务商的密钥是否配好**。
