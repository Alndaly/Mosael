Open Studio 的 AI 能力(智能体对话、文生图 / 视频、配音、转写等)都由你自带账号驱动：多数服务商填 **API Key**，订阅计划则走**授权登录**(见下)。凭据只存本机，后端接口只回显掩码提示或「是否已授权」，不回传明文。

## 按能力分区配置

设置页把 AI 供应商按**能力**分成四个分区，各自独立配置：

| 分区 | 用途 |
| --- | --- |
| **AI 对话** | 智能体与工作流的 LLM 节点 |
| **AI 绘图** | 文生图(图像生成) |
| **AI 视频** | 文生视频 |
| **AI 音频** | TTS 配音 / 播客合成 |

每个分区顶部是**默认模型**：为该能力选定默认的供应商与模型；用到时可在对应界面临时覆盖。下拉里列的是**模型**(形如「DeepSeek · deepseek-v4-pro」)，不是供应商——同一个供应商下的几个模型会各自出现。

![设置 → AI 绘图：默认模型 + 已配置的供应商列表](/media/screens/settings-models.png)

**按能力配置供应商**——设置里 AI 对话 / 绘图 / 视频 / 音频各自独立，「添加供应商」后前端只渲染该供应商声明的字段，密钥本地保存：

![操作演示：AI 对话与 AI 绘图的供应商配置入口](/media/gifs/providers.gif)

## 一条供应商 = 一个端点 + 一份凭据

供应商**不等于模型**：一条供应商记的是「连到哪里、用哪份凭据」，它下面可以挂**任意多个模型**。
点供应商行右侧的展开箭头，看到的就是它的模型列表。

## 添加一个供应商

进对应分区点「**添加供应商**」：

1. 选**服务商**(内置阿里云百炼 DashScope、火山方舟 ARK(视频 / Seedream 图像)、Evolink、Kimi、MiniMax、OpenAI、Google、快手 Kling、OpenAI 兼容端点等，目录随版本扩充)。
2. 填**名称**(便于区分，如「我的 Kimi」)。
3. 贴 **API Key**(订阅计划没有这一项，改为保存后授权登录)。字段旁有「**获取 API Key ↗**」直达该服务商的密钥控制台。
4. **Base URL**：API Key 连接留空即用该服务商默认(占位符会显示默认值);自建 OpenAI 兼容端点需自己填。
   订阅/OAuth 连接没有也不需要这个字段——端点由对应 Provider Adapter 管理，不要为它编一个服务地址。
5. **模型**可选，填了就作为这条供应商的第一个模型；之后随时可以再加。

添加后可随时**启用 / 停用**，不必删。

### Evolink：一个连接挂多个生成引擎

Evolink 是统一图像/视频网关：只需一份 Evolink API Key，同一连接下可分别加入 Seedance、Kling、
Veo、海螺、WAN、Sora、GPT Image、Gemini、Seedream 等模型。Open Studio 会把本地参考图先上传到
Evolink Files API，按模型 id 提交异步任务，再把限时产物地址立即下载回本地素材库。

这条路由与火山方舟的 Seedance Adapter 相互独立，可按内容策略、地区与账号可用性选择。Open Studio
不会在本地额外拦「真人」提示词，但也不承诺绕过审核：最终是否通过仍由 Evolink 当前路由的上游模型决定。

## 管理它下面的模型

展开供应商行：

- **加模型**：底部「添加模型…」是一个**带搜索**的输入框，列出该端点目录里还没配的模型。目录动辄两三百个(百炼有 233 个)，所以是搜索而不是长列表。目录里没有的(私有部署、别名)**直接输入名字**即可加入，和目录来的完全平权，只会额外标一个「目录中已不存在」。
- **启用 / 停用**单个模型：右侧开关。停用的不会出现在默认模型下拉与各处的模型选择器里。
- **模型设置**(齿轮图标):
  - **能力**：这个模型能用在哪些分区(chat / image / video / tts / podcast)。留空表示跟随服务商预设。这就是「同一个端点既有对话模型又有生图模型」的表达方式。
  - **上下文长度**：决定这个模型能聊多久、什么时候触发上下文整理。默认取服务商目录；目录查不到时用保守的 32000,可以手动改。下方会说明当前这个值是**你改的 / 目录给的 / 兜底的**。
  - **高级**(默认收起)：推理模型、视觉、推理强度、developer 角色四个兼容开关。只有端点报错时才需要来翻，平时一个都不用动。
- **删除**：垃圾桶图标。

> 上下文长度与那几个兼容开关只对**对话模型**显示——给一个生图模型问「支不支持 developer 角色」纯属噪音。

## 订阅计划：授权登录，不用 API Key

Claude Pro/Max、Kimi Code、ChatGPT Plus/Pro、GitHub Copilot、xAI、OpenRouter 这些**订阅计划**没有可填的密钥。在 AI 对话分区「添加供应商」时选对应条目，保存后回到列表点该行的「**授权登录**」：

1. 部分服务商先让你选**登录方式**(如 Codex 的「浏览器授权 / 设备码」)。
2. 弹窗里会出现**授权链接**或**设备码**，照着在浏览器里完成即可；需要粘贴授权码的会就地给输入框。
3. 授权成功后，该账号**实际可用的模型**会自动带回来(Copilot 的模型随订阅档位变、OpenRouter 有几百个)。

**令牌会自动续期**，不用你管——过期只是订阅制令牌的常态，应用会在用到它、以及每次打开设置页时自己刷新。只有**刷新失败**(在别处登出、授权被吊销)才会用警告色提示「需重新授权」，那时点「重新授权」即可。不想用了点「解除授权」。

AI 工作台用订阅模型分析已有图片或视频时，会继续使用**当前会话模型**：后端凭智能体短期令牌确认
会话身份，再通过无工具、无记忆的 Gateway 发送图片或视频采样帧。它不是公开反向代理，也不要求
`base_url`；视频原生整段输入暂不走这条 Gateway，请使用「自动」或「抽帧 + 转写」。

### 查订阅额度

订阅制的供应商行上会多一个**仪表图标**，点开显示当前计划、各项额度与重置时间。

它是**点击才查**的：这些额度接口都不是服务商承诺的公开 API(基本都是各家自己 CLI 内部在用)，后台定时轮询既容易撞限流，也会在对方改接口后变成一个一直在失败、却没人发现的任务。查不到时会直说是「这家不支持」还是「这次没查成」。

## 出站代理

服务商按地区限制访问时(表现为授权或调用被拒、提示 region not supported)，在设置 → **本地后端 → 出站代理** 填代理地址即可。AI 供应商请求与授权登录都会走它。

- 本机回连**永不走代理**(否则智能体的工具调用会全部失效)，这条不需要你配。
- 内嵌浏览器**不受影响**：发布用的平台登录按发布账号单独配代理，不会被这里带偏。

## 网络抖动时的重试

设置 → **AI 运行时** 可以调重试次数。它对**所有** AI 调用生效——对话、生图、生视频、语音、向量化，限流和 502 对它们一视同仁。遇到 429 / 5xx / 连接失败时按指数退避重试，期间不需要你做任何事。

## 成本规则

设置 → **成本规则** 里可给模型配计价(按 token / 按张 / 按秒)，首页与任务中心会按规则累计 AI 费用；没配的用量标「未定价」。

服务商的模型目录带公开报价时(如 OpenRouter)，可点「**按目录预填**」批量生成规则 —— **只补缺失的，已填的一律不动**(你核对过的价格可能含折扣或企业协议)。目录里标价为 0 的不会建规则：那是「未标价 / 订阅内含」，不是「免费」。

## 绑定关系：哪里没配，哪里会提醒

模型和用到它的地方是**绑定**的。没配好时，用到它的地方会给提醒 + 直达配置入口：

- 工作流的 **LLM 节点 / AI 生成节点**：没有可用供应商、或引用的供应商被删，属性面板顶部会出现琥珀 / 红色提示，点「去配置」直达设置。
- **AI 工作台**的生成：没有任何可用生成模型时，列表顶部同样提示。

> 生成模型目录始终有内置项；能不能真跑取决于**对应服务商的密钥是否配好**。
