Open Studio 的 Chrome 扩展使用浏览器原生 **Side Panel**，不会在网页上盖一层浮动窗口。当前支持
YouTube 与 B 站视频页；切换标签页时，侧栏会自动跟随。

## 安装

从 GitHub Release 下载 `open-studio-browser-extension.zip` 并解压：

1. 打开 `chrome://extensions`。
2. 打开「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压目录。
4. 把 Open Studio 视频助手固定到工具栏。

开发者也可以运行 `pnpm build:extension`，然后加载仓库中的 `browser-extension/dist/`。

## 逐字稿与跳转

打开视频后点击扩展图标。侧栏会读取站点已有字幕，整理成带时间的逐字稿：

- 点击一行，播放器跳到对应时间。
- 播放过程中，当前句自动高亮。
- 搜索同时匹配原文和译文。
- 切到另一个视频标签页，侧栏重新读取当前页面。

没有字幕的视频不会假装有逐字稿。先把它导入 Open Studio，再使用素材转写。

## 翻译、导入与截帧

这三项操作第一次使用时需要在侧栏设置中连接 Open Studio：填写本机后端地址（默认
`http://127.0.0.1:8800`），用 Open Studio 账号登录，并选择工作区与可选项目。

- **翻译**：选择目标语言后一次完成；长逐字稿会自动分批，顺序不变。
- **导入视频**：把当前页面链接作为后台下载任务提交到素材库。
- **截取当前帧**：截取播放器当前可见画面、裁成 PNG 后走普通素材上传接口。

密码只用于换取会话，不会保存。扩展不申请 Cookie 权限，也不导出 Chrome 登录态。因此会员、私享或
地区受限视频的下载，仍应在 Open Studio 内使用对应的[浏览器池](/zh/docs/guides/browser-pool)档案。

## 为什么需要这些权限

| 权限 | 用途 |
| --- | --- |
| Side Panel | 打开 Chrome 原生右侧栏 |
| Tabs / Active Tab | 跟随视频页、执行跳转与截取可见画面 |
| Storage | 保存 Open Studio 会话和目标工作区 |
| YouTube / B 站 | 读取当前页面播放器与字幕信息 |
| localhost / 127.0.0.1 | 调用本机 Open Studio API |

当前要求 Chrome 116+。截帧时播放器必须至少有一部分在视口内。
