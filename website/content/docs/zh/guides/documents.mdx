研究资料、品牌手册、客户给的 PPT、一张参数表 —— 这些东西以前要先复制成文字才能用。现在它们直接进**素材库**,
导入时在本机解析一遍:打开就能读全文,智能体能读,画板和工作流能接,也能一键存成一篇可编辑的[笔记](/docs/guides/notes)。

## 导入

在素材库点「导入」选文件,或把文件拖进窗口,和视频、图片走同一条路(可以一次选多个)。认得的格式:

| 种类 | 格式 | 怎么分段 |
| --- | --- | --- |
| PDF | `.pdf` | 按页,每页还有一张页面图 |
| 演示文稿 | `.pptx`(装了 LibreOffice 也收 `.ppt`) | 按幻灯片:标题、要点、演讲者备注 |
| Word | `.docx`(装了 LibreOffice 也收 `.doc`) | 按章 |
| 表格 | `.xlsx`(装了 LibreOffice 也收 `.xls`)、`.csv` | 按表 |
| 其他文本 | `.md`、`.txt`、`.html`、`.epub` | 按章或整篇 |

素材库顶部的类型筛选里多了「文档」,卡片上写着格式和页数。压缩包这类素材库不收的文件,导入时会直接说清楚能导什么,
不会被当成视频塞进去。

![素材库的「文档」筛选:文档卡片上写着格式、页数和大小](/media/screens/media-documents.png)

## 本机解析

导入之后就在本机解析一遍:**不出本机、不花钱**。解析出来的是按页 / 幻灯片 / 表 / 章切好的 Markdown,外加文档里的插图;
PDF 每一页还渲一张页面图。

- 本机装了 **LibreOffice** 时多做两件事:PPT、Word 也渲出每一页的版式图(智能体能看到幻灯片长什么样),老格式
  `doc / ppt / xls` 先转成新格式再解析。没装就只有文字和插图,详情里会提示。
- 页数很多时只渲前 200 页的页面图,文字照样全抽;表格太大时只取前 2000 行、40 列。这些都写在详情里,不会悄悄截掉。
- 解析在后台排队进行,同时导入好几份 PDF 也会交替进行。解析中可以点「停止」,停下的记成「解析已停止」,不算失败,随时可以重新解析。
- 本地解析管得了原生的数字文档,管不了扫描件和复杂版式:抽出来的字很少时,详情里会提醒「可能是扫描件或图片版」,
  这时换一家解析(见下)。

## 阅读文档

点开一份文档素材是三栏阅读器:**左边**是解析出的全文,**中间**是原版的每一页(文档原件 · 只读),**右边**是元信息。
点左栏某一段的标题,中间那栏就滚到对应那一页。顶上写着这份是哪一家解析的、一共几页(几张、几表、几章)。

![三栏阅读器:左边是本机解析出的全文,中间是原版的每一页,右边是元信息](/media/screens/document-reader.png)

## 换一家重新解析

扫描件、图片版 PDF、多栏排版、带公式和复杂表格的文档,本地解析会吃力。装了文档解析插件(随应用内置的
**MinerU 文档解析**就是一家)之后:

- **某一份文档**:在阅读器里点「重新解析」,选「用 MinerU 解析」这类选项。新的解析存成这份文档的又一次解析,
  智能体、画板、工作流用的是最新成功的那一次。
- **以后都默认用它**:在「设置 → 能力提供方 → 文档解析」里把它设成默认。

导入时照旧**先用本地解析**;把文档交给云端解析,必须是你自己点名的 —— 装了插件也不会悄悄把文档传上去。
MinerU 的接入、网络设置和额度见[安装与使用插件](/docs/guides/plugins)。

## 转为笔记

想在原文上改、让 AI 接着写,把它「转为笔记」:素材库右键 / ⋯ 菜单里、阅读器里都有。全文存成一篇新笔记,
文档里的插图这时才进素材库,笔记的来源记着原文档。原文档不动,还在素材库里。

## 在画板、工作流和智能体里用

- **画板**:把 PDF / Word / PPT / Excel 拖进画板(或粘贴、「添加 → 从库里放 → 素材」挑一份),就是一格文档格,
  格子里是解析出的全文。连进写作、生成格时,喂给模型的就是这份全文(由后端按连线读取,还在解析、解析失败的会直接说明)。
  操作条上「转为笔记」把它换成一篇可编辑、能「让 AI 写」的笔记。详见[创意画板](/docs/guides/boards)。
- **工作流**:「文档转 Markdown」节点把一份文档转成 Markdown 正文,可以只取某几页 / 几张幻灯片(「从第几段」「到第几段」),
  也可以点名用哪一家的解析;留空时用已有的最新一份,还没解析过就先在本机解析。
- **智能体**:在对话里直接附上 PDF / Word / PPT / Excel / Markdown(点 📎 或从访达拖进对话区)。短的整篇交给它,
  长的先给目录,它按需一段段读,大表能从一段中间接着读;要看某几页的版式、图表、截图时,它会把那几页的页面图交给视觉模型看。
  详见 [AI Studio 与智能体](/docs/guides/ai-studio)。
