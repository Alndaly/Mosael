素材库放你的**媒体**，笔记放你的**文字**。它们都是工作区级的，同一个工作区里的人看到同一份。

笔记不只是一个记事本 —— 它是**素材的另一半**：智能体答完可以存下来，逐字稿和字幕可以整份
存进去，画板能引用它，工作流能检索和读取它。所以这一页的重点不是"怎么打字"，而是**东西怎么
流进来、又怎么流出去**。

## 从别处存进来

四个地方都有「保存到笔记」，写进去的东西都带着**来源**：

| 从哪存 | 存下来的是什么 |
| --- | --- |
| AI 工作台的一条回答 | 那段回答，来源指回这条消息 |
| 画板上的便签 | 便签正文，来源指回那块画板 |
| 剪辑 → 逐字稿 | 整份逐字稿；选中了片段就只存选中的那些 |
| 剪辑 → 字幕 | 整条字幕轨；有译文时原文与译文一起写入 |

对话框里可以**新建一篇**，也可以**追加到已有笔记**。逐字稿和字幕还多一个「正文形状」的选择：

- **正文** —— 连着说的句子并成段落，停顿超过 1.5 秒另起一段。当稿子用、准备二次改写时选它。
- **带时间戳引用** —— 每句一个引用块，后面跟着素材名和时间。回看时想一句一句对回视频时选它。

两种形状**共用同一份来源**：出处是事实，不随排版变。

追加到一篇**正在被别人编辑**的笔记不会打断对方 —— 追加的内容会并进他当前的草稿，他继续
打字，不会看到冲突提示。

## 写

正文是所见即所得的编辑器，顶部工具栏一行放完：段落样式（正文、一级到六级标题）、粗体、斜体、
删除线、三种列表（无序、有序、任务）、插入（引用块、代码块、分隔线、图片）、网页链接、表格、
撤销重做。

几个值得单独说的：

- **图片**可以粘贴、拖入或从工具栏插入；选中之后就近改链接和替代文字。
- **代码块**能选语言，按明暗主题做语法高亮，右上角一键复制。它保留 Markdown，也进撤销栈。
- **输入 `@`** 引用另一篇笔记 —— 引用会**钉住当时那个版本号**，但点开默认显示最新正文；想看
  当时引的那一版，用「查看引用版本」。
- 右上角三个模式：**编辑 / 阅读 / Markdown**。最后一个直接看源码。

标题栏左边的状态会说话：`已保存` / `保存中…` / `草稿待保存`。**关掉页面不会丢** —— 未保存的
草稿留在本机，下次打开这篇笔记时自动恢复。

### 万一撞上冲突

两个人同时改同一篇的同一处时，你会看到「笔记已有新版本」。这时**不会覆盖任何一方**：

1. 点「重试保存」再试一次；
2. 或点「载入最新版本」—— 它会**先把你的草稿导出成 .md 文件**，再拉服务端那一版。

所以最坏情况是你手上多一个 .md，不是丢字。

## 整理

左侧列表支持搜索（标题、正文、标签）、**收藏**、**回收站**和**专题**筛选。

点「多选笔记」进入多选：可以按住 <kbd>Shift</kbd> 连选、全选当前列表，然后批量收藏、导出
Markdown、移入回收站、恢复或彻底删除。右键单篇有打开、重命名、创建副本、复制笔记链接。

**导入 Markdown** 在列表标题栏，接受 `.md` / `.markdown` / `.txt`，单个文件上限 500 KB。

「彻底删除」会连同**所有历史版本**一起永久删除，无法恢复。已经引用过它的地方仍然保留引用，
但点不开来源了。

## 版本记录

每次保存都是一个不可变版本。右上角「更多 → 版本记录」按时间列出，点一条看那时的内容，
「恢复此版本」会**创建一个新版本**而不是抹掉后面的历史。

## 来源与属性

「更多 → 来源与属性」里是这篇笔记的出处清单，以及**专题**和**标签**（都用逗号分隔）。
从素材、对话或画板存进来的摘录会自动出现在这里，点一下就回到原处 —— 素材摘录还会带上时间点。

## 流出去：画布与工作流

### 无限画布

画板上新增了**文档**节点：选一篇笔记，它就把**那个版本**的正文钉住。把它连到文案、图片、
视频或配音节点，正文就作为输入传下去。节点上可以「打开原文」「更新到最新版本」「更换笔记」。

原文被移入回收站或删除时，节点会明确说「笔记不可用」，而不是安静地传一段空文字。

### 工作流

工作流的**知识库**分类下有三个节点：

| 节点 | 做什么 |
| --- | --- |
| **检索笔记** | 按标题、正文、标签与专题检索，返回带来源的摘要 |
| **读取笔记** | 输出完整 Markdown 正文和来源链接；版本留空读最新，也可钉一个历史版本 |
| **保存为笔记** | 把文案或上游输出存成新笔记，**不覆盖**已有文档 |

「检索笔记」返回的是摘要不是全文 —— 要全文就把它接到「读取笔记」。这样一次检索几十篇的结果
不会把上下文撑爆。

## 智能体引用

智能体回答里出现的笔记和网页来源是**可点的**，点开直接跳到那篇笔记的那个版本。它检索到什么、
引用了哪一版，都留在回答里可以复查 —— 不是让你信它记得对。
