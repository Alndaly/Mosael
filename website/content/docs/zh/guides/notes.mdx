在「笔记」中保存脚本、研究资料、逐字稿和会话摘录。笔记属于工作区，支持富文本编辑、Markdown、来源引用与版本历史；保存后的内容可被画板、工作流与智能体引用。PDF、Word、PPT 这类文件不在这里，它们作为[文档素材](/docs/guides/documents)进素材库，需要时一键「转为笔记」。

## 从别处存进来

这几个地方都能把内容存成笔记，写进去的东西都带着**来源**：

| 从哪存 | 存下来的是什么 |
| --- | --- |
| AI Studio 的一条回答 | 那段回答，来源指回这条消息 |
| 画板上的便签 | 便签正文，来源指回那块画板 |
| 剪辑 → 逐字稿 | 整份逐字稿；选中了片段就只存选中的那些 |
| 剪辑 → 字幕 | 整条字幕轨；有译文时原文与译文一起写入 |
| 文档素材的「转为笔记」 | 解析出的全文，文档里的插图这时才进素材库，来源指回原文档 |
| 浏览器会话顶栏的「存成笔记」 | 整页正文(登录后看到的那一页)或页面上选中的文字，来源是网页地址和标题，见[浏览器池](/docs/guides/browser-pool) |

对话框里可以**新建一篇**，也可以**追加到已有笔记**。逐字稿和字幕还多一个「正文形状」的选择：

- **正文** —— 连着说的句子并成段落，停顿超过 1.5 秒另起一段。当稿子用、准备二次改写时选它。
- **带时间戳引用** —— 每句一个引用块，后面跟着素材名和时间。回看时想一句一句对回视频时选它。

两种形状**共用同一份来源**：出处是事实，不随排版变。

追加到一篇**正在被别人编辑**的笔记不会打断对方 —— 追加的内容会并进他当前的草稿，他继续
打字，不会看到冲突提示。

## 写

正文是所见即所得的编辑器。顶栏左边全是编辑格式，从左到右：侧栏开关(收起笔记列表、专注写作)| 段落样式(正文、一级到六级标题)|
粗体、斜体、删除线、高亮 | 无序、有序、任务三种列表 | 插入▾(引用块、代码块、分隔线、引用笔记、图片)、网页链接、表格 | 撤销、重做。
右边是文档级的：保存状态 · **Markdown** · **AI 助手** · 收藏 · 更多。窗口窄了不换行，按优先级把插入、撤销重做、列表、粗体那几组
收进最右边的「更多格式」(竖的 ⋮)，段落样式一直在。

![笔记页：顶栏左边是编辑格式，右边是保存状态、Markdown、AI 助手、收藏和更多；正文里「转场一律用穿门推进」是一段高亮](/media/screens/notes.png)

每颗按钮悬停都有说明，带着快捷键：粗体 <kbd>⌘B</kbd>、斜体 <kbd>⌘I</kbd>、删除线 <kbd>⇧⌘S</kbd>、高亮 <kbd>⇧⌘H</kbd>、
三种列表 <kbd>⇧⌘8</kbd> / <kbd>⇧⌘7</kbd> / <kbd>⇧⌘9</kbd>、段落样式 <kbd>⌥⌘0</kbd>–<kbd>⌥⌘6</kbd>、撤销 <kbd>⌘Z</kbd>、
重做 <kbd>⇧⌘Z</kbd>(Windows 上把 ⌘ 换成 Ctrl)。点不了的按钮也说为什么，比如「没有可撤销的操作」。

![悬停「粗体」:说明里带着快捷键键帽 ⌘B](/media/screens/notes-hint.png)

![「插入」菜单：每一项名字下面一行淡色说明，如「插入图片 · 也可粘贴或拖入」](/media/screens/notes-insert-menu.png)

几个值得单独说的：

- **图片**可以粘贴、拖入或从「插入」里选；选中之后就近改链接和替代文字。
- **代码块**能选语言，按明暗主题做语法高亮，右上角一键复制。它保留 Markdown，也进撤销栈。
- **高亮**存成 `==文字==`(和 Obsidian、Typora 同一种写法)，里面还能套粗体这类格式；直接输入 `==字==` 或粘贴进来也会变成高亮。
  导出的 Markdown 原样带着 `==`，正文里本来就写着的 `==` 不会凭空变成高亮。
- **输入 `@`** 引用另一篇笔记 —— 引用会**钉住当时那个版本号**，但点开默认显示最新正文；想看
  当时引的那一版，用「查看引用版本」。
- **Markdown** 是一颗能按下的切换：按下看源码(这时格式按钮收起)，再点一次回到编辑。

![按下「Markdown」看源码](/media/screens/notes-markdown.png)

顶栏右侧的保存状态会说话：`已保存` / `保存中…` / `草稿待保存`。**关掉页面不会丢** —— 未保存的
草稿留在本机，下次打开这篇笔记时自动恢复。

### 万一撞上冲突

两个人同时改同一篇的同一处时，你会看到「笔记已有新版本」。这时**不会覆盖任何一方**：

1. 点「重试保存」再试一次；
2. 或点「载入最新版本」—— 它会**先把你的草稿导出成 .md 文件**，再拉服务端那一版。

所以最坏情况是你手上多一个 .md，不是丢字。

## 选中一段：选区工具条

在正文里选中一段字，选区上方浮出一条工具条(贴着窗口顶部时翻到下方)：

- **格式**：粗体、斜体、删除线、行内代码(<kbd>⌘E</kbd>)、高亮、加链接(就地填地址)/ 去掉链接；已经有的格式显示成按下。
- **AI 动作**(下拉)：润色、改写、扩写、缩写、翻译(选区里有中文就译成英文，否则译成中文)、总结、解释、续写，每一项悬停有说明。
  点了直接在 AI 助手里跑(见下一节)。
- **问 AI**：带着这段打开 AI 助手，光标放进输入框，问什么自己写。
- **复制**(纯文字)、**转成无序列表 / 待办**。
- **引用到对话**：把这段挂到 AI 助手的输入框上，不发送、也不抢走光标。
- **朗读**：用你在「设置 → 语音对话」里选的音色念出来，没选过就用免费的 Edge 语音；提示条上能「停止朗读」，或「存为音频素材」
  (这一步才生成一份音频进素材库)。用的是收费音色时，和对话里念一句一样按字计费。
- **存到笔记**：打开保存对话框，存成一篇新笔记或追加到别的笔记。
- **加到画板**：挑一张画板(上次加过的排最前，能搜，找不到就用搜索框里的字新建一张)，这段字作为一张便签摆在画板的空位上，
  不压住已有的格子；便签底下写着「来自笔记「…」」，点了回到这篇、定位到这段。提示里点「打开画板」直接看到那张便签。

![选中正文里的一段，上方浮出选区工具条](/media/screens/notes-selection.png)

![选区工具条的「AI 动作」:润色、改写、扩写、缩写、翻译、总结、解释、续写](/media/screens/notes-ai-actions.png)

键盘也能用：<kbd>Tab</kbd> 进工具条，方向键、<kbd>Home</kbd> / <kbd>End</kbd> 移动，<kbd>Esc</kbd> 收起并回到正文。
窗口很窄时工具条只剩「问 AI」和「更多」。

## AI 助手

顶栏右侧「**AI 助手**」打开和剪辑页、画板同一个助手面板，它知道你正在看哪一篇：每条消息都自动带上这篇的标题和正文(长的只带开头，
需要时它自己分段读)，以及你选中的那一段 —— 选区以一个小条显示在输入框上，点掉就不带。面板停靠时占一栏、左边缘可以拖宽，
窗口放不下时改成盖在正文右侧；开没开、停靠还是浮动、多宽，都记在本机。换一篇笔记，对话不换。

![AI 助手停靠在笔记右侧，输入框上挂着选中的那段；正文变窄了，格式按钮收进了「更多格式」(⋮)](/media/screens/notes-agent.png)

- **总结、解释、列提纲**这类，它直接在对话里回答，不改笔记。
- **要改正文**时(选区工具条上的润色、改写、扩写、缩写、翻译、续写，或者你自己说「把这段改得口语一些」)，它按段替换或插入，
  先出一张确认卡：每一处画出「原文 → 新文」，删掉的划线、新加的高亮。批准了才改，改完能撤销，旧的一版留在版本记录里。
  你在它改之前已经动过那一段的话，这一步失败、不会写错地方。
- 带着选区发出去的消息，气泡里多一行摘录(笔记标题 + 那段的开头)，以后翻对话也知道「这段」是哪段；点它回到笔记、选中那一段。

面板开着时，智能体直接追加的内容(不走确认卡的那种)几秒内就出现在正文里。

## 整理

左侧列表支持搜索（标题、正文、标签）、**收藏**、**回收站**和**专题**筛选；列表右边沿可以拖动调宽，
宽度会记住。切到别的页再回来，打开的仍是这个工作区上次那篇，「全部笔记 / 收藏 / 回收站」也停在原来那一栏。

点「多选笔记」进入多选：可以按住 <kbd>Shift</kbd> 连选、全选当前列表，然后批量收藏、导出
Markdown、移入回收站、恢复或彻底删除。右键单篇有打开、重命名、创建副本。

**导入 Markdown**（箭头指进盒子的「导入」图标）在列表标题栏，接受 `.md` / `.markdown` / `.txt`，单个文件上限 500 KB；可以一次选多个，
也可以直接把文件拖进笔记页，每个文件成一篇，建完打开最后一篇。只拖图片进正文时仍是插入图片。

回收站里的笔记打开后顶部有一条提示，可以直接「移出回收站」或「彻底删除」。

「彻底删除」会连同**所有历史版本**一起永久删除，无法恢复。已经引用过它的地方仍然保留引用，
但点不开来源了。

## 版本记录

正文的每一次改动都记在版本记录里。右上角「更多 → 版本记录」打开一个大弹窗：左边按天列出版本（今天、昨天、具体日期），
右边是选中那一版的内容，正文按阅读宽度排。

- **连续的手动编辑合成一版**：同一个人接连打字（停笔不超过 5 分钟，一版最长 30 分钟）只记成一版，自动保存改写的是同一版；
  停笔超过 5 分钟、换了人，或者中间有智能体修改、恢复、存到笔记，就另起一版。每一版写着改了多少，比如「+120 −30 字」
  「改了标题」，悬停时间能看到这一版从几点写到几点。
- 收藏、移进回收站、改标签和主题**不记版本**；恢复某一版也只恢复标题、正文和来源，这些属性保持现在的样子。
  只是打开一篇导入的或经接口、工作流写进来的笔记(比如文末是表格)，编辑器补齐结构不算改动，不会自动存出一版看不出改了什么的「手动编辑」。
- 每一项写清**怎么来的**：手动编辑、智能体修改、存到笔记、从版本 N 恢复……别人写的会带上名字。
- 右边可以切换**预览 / 和当前版本对比 / 和上一版对比**：删掉的字划线，新加的字高亮，大段没改的折起来。
- 顶上那一版标着「当前版本」。「恢复此版本」会先让你确认，然后**新建一个版本**，原有的版本都还在；
  「复制这一版的内容」复制那一版的 Markdown 正文。列表里可以用上下键切换版本。

![版本记录：今天的 6 个版本 —— 新建、手动编辑、存到笔记、从版本 2 恢复……每一项写着改了多少，顶上那一版标着「当前版本」](/media/screens/notes-history.png)

![版本 4 和上一版对比：没改的几行折起来，删掉的字划线、新加的字高亮；右上角是「恢复此版本」](/media/screens/notes-history-compare.png)

从老版本升级上来时，老库里每次自动保存都落下的碎版本会按上面的规矩合并，版本号重排成连着的；画板文档格、来源和链接里
指着老版本号的地方一并改指过去，不会断。老版本是怎么来的，能从任务、对话和运行记录里推出来的都补上了，推不出来的记成手动编辑。

## 来源与属性

「更多 → 来源与属性」里是这篇笔记的出处清单，以及**专题**和**标签**（都用逗号分隔）。
从素材、对话或画板存进来的摘录会自动出现在这里，点一下就回到原处 —— 素材摘录还会带上时间点。

## 流出去：画布与工作流

### 无限画布

画板上的**文档格**引用一篇笔记：选中它，上方操作条点「选择笔记」（引用之后是「更换笔记」），它就把**那个版本**的正文钉住，
格子底部写着 `v版本号`。把它连到便签、图片、视频或音频格，正文就作为输入传下去。底部可以「更新到最新版本」「打开原文」。
操作条上的「让 AI 写」能从头写一篇（存成新笔记并引用它），或把引用着的这篇改写成它的新一版（旧版还在）。

原文被移入回收站或删除时，节点会明确说「笔记不可用」，而不是安静地传一段空文字。

反过来，选区工具条的「加到画板」把正文里的一段放成画板上的一张便签，便签记着来自哪篇笔记的哪一版(见上)。

### 工作流

工作流的**知识库**分类下有这几个节点：

| 节点 | 做什么 |
| --- | --- |
| **检索笔记** | 按标题、正文、标签与专题检索，返回带来源的摘要 |
| **读取笔记** | 输出完整 Markdown 正文和来源链接；版本留空读最新，也可钉一个历史版本 |
| **保存为笔记** | 把文案或上游输出存成新笔记，**不覆盖**已有笔记 |
| **文档转 Markdown** | 把一份 PDF / Word / PPT / Excel 文档素材转成 Markdown 正文，可只取某几页（见[文档](/docs/guides/documents)） |

「检索笔记」返回的是摘要不是全文 —— 要全文就把它接到「读取笔记」。这样一次检索几十篇的结果
不会把上下文撑爆。

## 智能体引用

智能体回答里出现的笔记和网页来源是**可点的**，点开直接跳到那篇笔记的那个版本。它检索到什么、
引用了哪一版，都留在回答里可以复查 —— 不是让你信它记得对。
