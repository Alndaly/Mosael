浏览器池集中保存平台账号和通用浏览器档案，供发布、工作流自动化、链接导入与智能体复用。每个档案拥有独立的登录状态、站点存储与代理配置；使用哪个身份由档案授权决定。

## 两类档案

- **发布账号**绑定平台（TikTok / YouTube / 抖音 / B站 / 小红书 / 视频号）。发布表单从这里选择，
  绑定这件事本身也是 Mosael 判断该走哪套上传流程的依据。
- **通用档案**对应任意其他站点，工作流的 RPA 节点和智能体的浏览器工具用它。

两类的建立方式一样：**添加账号 / 新建档案**，然后在内嵌浏览器窗口里像平时用 Chrome 一样登录。Mosael
不经手也不保存你的密码 —— 它留下的是站点发回来的那段会话。

## 通用档案：一个一直保留的浏览器

通用档案卡片的主按钮是**打开**，它回到你上次停下的那一页：内嵌视图还开着，就原样亮出来；重启过、
视图已经没了，就打开上次收起时记下的那个地址。第一次打开时才会问你要去哪个网址。要换一个站点，
点旁边的**打开其他网址**（铅笔图标）—— 只有这个入口会把页面导航走。

在里面登录过的网站，下次打开、以及工作流和智能体用这个档案时，都还是登录状态。手动打开也会更新
卡片上的「最近使用」，副标题带上最后停留的站点。

通用档案卡片上**没有登录状态徽标**：它可以装任何网站，Mosael 认不出你在某个任意站点上登没登录，
与其猜一个，不如不说。


## 打开之后：浏览器会话

点「打开」后整个窗口是这个档案的浏览器(只在桌面版里有)。顶栏左边是后退、前进、刷新和地址栏，右边是**页面工具**和「返回 Mosael」；
左边一列是这个会话开着的**页面列表**。「返回 Mosael」把浏览器收起来，网页在后台留着；没在网页里打字时，连按两次 <kbd>Esc</kbd> 也能回来
(焦点在网页的输入框里时，<kbd>Esc</kbd> 留给网页 —— 收起补全、退出编辑常要连按 <kbd>Esc</kbd>)。

**键盘焦点跟着你走。** 打开之后焦点就在网页里，可以直接打字、滚动；用鼠标点完顶栏的后退、前进、刷新，或在页面列表里切页、开新页、关页，
键盘回到网页；地址栏里回车打开、或按 <kbd>Esc</kbd> 撤销之后也回到网页。用键盘在顶栏里走的，焦点留在顶栏接着走。收起浏览器回到 Mosael 时，
焦点落回打开之前的那颗按钮。

**底下开着的弹窗不会被关掉。** 比如从工作流库「在工作台里打开」进来：点顶栏、页面列表、地址栏，在地址栏里按 <kbd>Esc</kbd>，底下的工作流库都还开着；
点「返回 Mosael」回来，它还停在原来那一张。

### 顶栏的页面工具

五颗按钮只有图标，悬停看名字和一句说明(说明画在网页上面，往下出，不压住地址栏)；点不了的时候按钮是灰的，悬停写着名字、说明和为什么点不了
(还没打开网页、上一个操作还没做完；页面还在加载时，找视频、找图片、读正文要等它加载完)。它们都只作用于眼前这一页，用的是这个档案的登录态。

| 工具 | 做什么 |
| --- | --- |
| **截屏** | 「可见区域」「整页长图」「框选区域」三选一。整页长图一次画完，吸顶的导航条不会每屏重复一遍；超过 15000 像素只截前面一段并如实提示。框选时在冻住的画面上拖一个框，<kbd>Esc</kbd> 取消。截图带着来源网址、页面标题和截取时间存进素材库 |
| **下载视频** | 右侧打开一栏，列出这一页能下的视频。B 站、抖音、小红书、YouTube 这类平台的页面是一张卡，按整页走[从链接导入](/docs/guides/media)；普通网页列出播放器和网络里找到的视频文件、HLS 流、DASH 流。在后台下载，栏里和任务中心里都有进度、能取消，下完进素材库并记下所在页面。受 DRM 保护或加密的标着「受保护，无法下载」，Mosael 不尝试绕过 |
| **采集图片** | 右侧列出页面上够大的图(小图标、追踪像素已经滤掉)，勾选后「存进素材库」，每张记下所在页面和图片自己的地址。防盗链的站点也取得到 —— 取图时带着这个档案和来源页 |
| **存成笔记** | 「整页正文」或「选中的文字」。整页正文读的是你此刻看到的那一页(登录后才看得到的正文也在)，挑出文章主体、去掉导航和侧栏；笔记开头一行写着来源，来源里记着网址和页面标题。什么都没选时先提醒你，不建空笔记 |
| **用当前页开工** | 「视频爆款拆解」「账号运营诊断」「评论区洞察」：建好(或打开你已经建过的那张)官方模板，把这一页的链接填进开始节点，数据来源选内嵌浏览器、用的就是这个档案；绑着定时任务的那张不动，另建一张。不替你点运行 —— 浏览器收起，停在那张图上，检查一下就能跑。「交给智能体」：新开一条对话，把「帮我看看这个网页：」、页面标题和链接放进输入框，不替你发送 |

做完的提示也说在顶栏里，比如「已存进素材库 · 查看」「已存成笔记 · 打开」，点一下浏览器收起、直接打开那一份。

### 网页里的下载直接进素材库

在浏览器会话里点网页上的下载链接，不会弹系统保存框：文件下完直接存进当前工作区的素材库，记下下载地址、所在页面和时间，
顶栏说「已存进素材库」，点「查看」过去。浏览器收起之后才下完的也照样存。素材库不收的类型(安装包、压缩包这类)和超过 2 GB
的文件当场停下，说清为什么。

### 页面列表

一个浏览器会话可以同时开几个页面，左边一列列出它们：网站图标加标题，悬停看网址，当前这一页高亮。点哪页切到哪页，单页可以关
(只剩一页时不关)，拖动能排序；顶上「新建页面」输入网址或要搜的词，回车就开。网页里在新窗口打开的链接(`target=_blank`、
`window.open`)不再弹出一个小窗，而是进这个列表并切过去；第三方登录的弹窗照常回调，办完自己关掉，回到原来那一页。
一个会话最多同时开 10 个页面，开满了会提示先关掉几个。

列表能收起成一条图标，收起与否记在本机。收起时鼠标停在图标条上，列表临时展开、盖在网页上，看得到每页的标题和网址；
移开就收回，网页不会被推来推去。想让它一直展开，在临时展开的列表里点「固定展开」。收起、展开、临时展开都带一段很短的过渡，
过渡中网页定格一瞬(约 0.2 秒)，跟着列表一起滑，不会一顿一顿地跳；系统设了「减少动态效果」就不做过渡。列表里被截断的标题，
悬停看全文，说明往右出、画在网页上面。

## 工作流和智能体用的悬浮浏览器

工作流或智能体打开浏览器时，它以一张卡片悬浮在窗口右下角，你能看着它操作：

- **标题写明属于谁**：工作流开的写着「工作流名 · 10-04 16:23 的运行」，点标题跳到那条工作流、执行历史停在那一次；
  会话里开了几页时标着「第 2 页，共 3 页」。
- **四角四边都能拖拽缩放**，手柄平时藏着，指针停在这个浏览器上(包括网页上)时出现。只缩放不平移：拖角时对角不动、拖边时对边不动；
  宽高按页面比例联动，里面始终是完整的 1280×800 桌面视口。聚焦到角上之后方向键也能缩放(按住 <kbd>⇧</kbd> 走大步)。
- **几张叠在一起时**，最上面那张的标题条(拖动、静音、关闭)和缩放手柄不会被下面的网页盖住；下面几张只露标题条，网页照常在后面跑。
- **应用窗口缩小时**，卡片按同样的大小上下限和比例夹回窗口里，夹过的位置和大小会记住。
- 标题栏的扬声器按钮控制这一块网页的声音。解除静音会同时恢复 Electron 音频和网页播放器自身的静音、音量与由 Mosael 暂停的播放状态；
  切集或网页稍后才创建播放器也会继续同步。卡片的标题条、圆角和边缘都会拦住鼠标，不会把点击落到下面的工作流节点上。
- Mosael 窗口被别的窗口挡住、或不在当前桌面时，自动化照常渲染，滚动加载不会停住。

## 登录，以及保持登录

发布账号的卡片上有状态徽标：**已登录**、**需登录**、**检测中**。**复检**会打开站点，找一份「你确实还是
登录态」的证据，结果和时间戳落在卡片上。会话死了，卡片当场说，而不是留到下一次发布失败。

复检刻意采信证据而不是「页面打开了」：把加载成功当成登录成功，正是账号池一边坚称你已登录、
一边每次上传都失败的成因。同一个道理也用在登录过程中：登录页上的东西不算证据 —— 视频号登录页上
「微信快捷登录」那张卡片不会被当成已登录；反过来，TikTok 登录完把你留在推荐信息流上、页面里还藏着
一个看不见的登录弹窗，也照样判为已登录，内嵌浏览器自己收起。

### 退出登录与重新登录

- **退出登录**（发布账号）/ **清除登录数据**（通用档案）在卡片的 ⋯ 菜单和右键菜单里。它清掉这个档案
  分区里的 cookie、本地存储和缓存；发布账号随即回到「需登录」，通用档案里登录过的网站全部退出，
  档案本身保留。在网站自己的页面上点「退出」靠不住：有的平台只让当前页面那段会话失效，分区里别处的
  cookie 还在，下次打开照样是登录状态。清掉分区是唯一确定的做法。
- **退出后重新登录**（钥匙图标，发布账号已登录时出现）先做上面这一步，再打开登录页。只打开登录页
  不够：网站见到分区里还有有效会话，往往直接把你从登录页弹回首页，换号也换不成。

每个档案还能单独设**代理**，入口在卡片右键菜单里。会话和出口地址成对绑定，多数平台期望的
也是这个。

## 谁可以用一个档案

这一节值得读仔细。

- **发布**用的是绑在目标平台上的那个账号。绑定就是为这件事服务的，不再额外问你。
- **工作流**在节点上明写档案（`profile_id`，节点的会话模式为 `pool` 时必填），所以你搭出来的
  流程自己说清了用哪个身份。
- **智能体**在打开档案之前必须先问。借用登录身份被归为**外部**动作，会弹一张点名档案的确认
  卡 —— 你没交出去的身份，它够不着。

最后这条有两个细节值得知道，因为它们决定了一次批准到底买到了什么：

- 这张卡属于「对外生效」档，**没有「本会话始终允许」**：每次打开档案都要你点一次「允许一次」，
  自动放行也不会替你批。
- 批准针对的是**打开**这个动作。页面打开之后，智能体在里面的操作 —— 输入、点击、求值 ——
  被归为只读，不会各自再弹一张卡。所以一次通过的 `browser_pool_open`，读作「你可以在这个站点
  上以这个身份行事」，而不是「你可以做恰好一个动作」。

据此判断就好：这是一个关于「让智能体穿哪个身份」的决定，所以卡片上真正该问自己的是，愿不愿意
让它以那个账号的名义行事。

卡片上的开关关掉之后，这个档案对发布和智能体都不可见，但既没被删掉也没退出登录。

## 团队部署里的共享

账号和档案**归建它的人**，默认私有：同一个工作区的其他成员看不到它，也**用不了**它 —— 猜到 id、
在工作流里填上它、让智能体去开它，都会被拒，并提示「这个浏览器档案属于别人且没有共享出来」。

自己拥有的档案可以从右键菜单**共享**进工作区。其他成员随后就能用它发布、在工作流里选它 ——
而凭据始终没有经过任何人之手，因为共享出去的是会话，不是密码。发布账号和它的浏览器档案是同一个
身份，一起共享、一起收回；收回之后，别人新发起的发布和打开都会被拒。

共享是**借出去用，不是交出去管**：改名、停用 / 启用、改代理、复检、登录 / 重新登录、退出登录与清除数据、
删除都只有主人能做 —— 工作区管理员也不行。共享给你的卡片上只留「打开」，别的按钮不摆出来；直接调接口也会
被拒，并提示只有主人能做。

「谁在用」按下面算：

- 发布页、浏览器池、从链接导入：当前登录的人。
- 手动运行的工作流：点运行的人。**定时任务和 webhook 触发的运行替任务主人用** —— 图里的账号和档案
  得是主人自己的，或已共享进工作区的；**被执行的那一版图要是别人改的，改它的人也得用得了**，否则要主人
  「认可这一版」（见[定时任务](/docs/guides/scheduler)）。
- 智能体：批准那张确认卡的人。

工作流里「发布账号」「浏览器池档案」的下拉只列你能用的那些。

### 工作流和智能体开的浏览器会话

工作流的「打开浏览器」节点有三种会话：

- **临时**：用完即清，什么都不留。
- **具名持久**：按名字保留登录。**同一个工作区里同一个名字就是同一份登录**，换个名字就是另一份，不同工作区各是各的；名字可以是任意文字（含中文），最多 80 个字。同一份登录同一时刻只给一次运行，被占着时直接说「正被另一次运行占用」，不会两次运行抢同一个标签页。
- **浏览器池**：复用上面这些已登录档案，同一个档案同一时刻只开一个会话。

智能体开的浏览器会话归那次对话；没人关、空闲超过 15 分钟会自动收回，不会一直占着同名会话。工作流开的会话在那次运行结束之前不收 —— 两个浏览器步骤之间隔着一段很长的生成很正常。

自动化里点开了一个在新窗口打开的链接时，新页面进这个会话的页面列表，**下一步自动就在新页面上**；要切回去或关掉它，用「浏览器·切换页面」
节点。自动化里点开的下载直接进素材库，「浏览器·导航」「浏览器·点击」节点多一个素材 id 输出，素材的出处记着是哪次运行、哪个节点。
会话结束或取消时，它开过的页面全部收回。这些节点的细节见[可视化工作流 → 浏览器节点](/docs/guides/workflows)。

## 数据在哪

会话落在 Electron 的用户数据目录（`Partitions/`）下，不在 SQLite 库里。它天然是**按机器**的：
一段浏览器会话绑定创建它的那个浏览器，所以切到团队后端不会把登录一起带过去。

## Passkey 与平台认证器

浏览器池已接入可发现凭据的账号选择，并按实际环境能力判断 WebAuthn。macOS 正式包通过 Developer ID 签名、专用描述文件和 Apple 公证，支持在兼容设备上通过 Touch ID 注册、使用设备绑定 passkey。需要 Mac 已设置指纹；从源码运行的未签名开发版不启用此能力。设备绑定凭据按浏览器档案隔离，不会从 iCloud 或手机自动同步；跨设备扫码 passkey 暂不可用。站点允许时可选择密码或其他登录方式。
