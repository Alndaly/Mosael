创意画板是**想法摊开、边看边做**的地方：把素材、文字和生成结果摊在一张桌上，看、比、改，直到一个想法成形。内容就是界面，摆放和分组就是整理；同一句提示词可以并排试几个模型，挑一个接着做；每一格都记得自己是怎么来的，能重新生成、再跑一次。想把做法固定下来、换个输入让它自己再跑，用[工作流](/docs/guides/workflows)。

在创意画板上放置便签、文档、图片、视频、音频和 3D 场景，用分组整理内容。**连接两个节点，会把上游内容作为下游输入**，例如将参考图交给视频节点，或将文档交给文案节点 —— 一根线的意思是「参考它」，不是「然后做它」。

拖动连线到节点左右可见的 **＋** 区域即可连接。选中节点后，上方显示操作条，下方显示生成或编辑表单。

**把东西放上画板**：从访达或资源管理器把图片、视频、音频拖进画布，它们先进素材库，再按种类各放一格，落在松手的位置。⌘V 粘贴同理：截图或复制的媒体文件各放一格，一段文字落成一张便签，摆在视野中间。光标在便签、提示词框或任何输入框里时，粘贴照常贴进那里，不会往画布上放东西。

## 连一条线能带来什么

连线不是装饰，下游节点会照着上游的东西改自己的表单：

| 上游 → 下游 | 下游拿到什么 |
| --- | --- |
| 便签 → 图片 / 视频 | 那段文字自动填进提示词 |
| 便签 → 音频 | 那段文字就是要念的内容 |
| 便签 → 便签 | 上游的字作为**材料**发给模型（和"要求"分开） |
| 图片 → 图片 | 挂成参考图 |
| 图片 → 视频 | 一张挂首帧，多张挂参考 |
| 图片 / 视频 → 便签 | 模型**看着写**：图片直接看，视频抽帧看 |
| 音频 → 便签 | 有转写就把转写当材料 |

上游填进来的东西**不覆盖你自己写的**：只有输入框还空着、或里面正好是上一次自动填进去的
那段时才替换。

## 顶部工具栏

按钮从左到右按用途排列：添加与撤销/重做、评论与讨论中心、标记与标记清单、视图与导航、AI 助手。组间以细分割线区分。

删除整张画板在「更多」菜单中，点击后仍需确认。工具栏可切**连线形态**：曲线(贝塞尔)或折线(直角)，画板单独记住你的选择。⌘F 查找节点：按名字、正文、提示词、类型搜，起了名的节点在结果里显示名字，命中的节点在画布上描圈，Enter / ⇧Enter 跳到下一个 / 上一个，Esc 关闭。

画板列表里，卡片右上角的 ⋯ 和右键菜单有同一组动作：打开、重命名、创建副本、删除(需确认)。标题栏的「选择」进入多选，可全选、批量删除；部分删不掉时会说明几项失败，失败的保持勾选。创建副本不带正在生成的格子，它们在副本里退回空槽、提示词保留。窗口较窄时，使用工具条两端的箭头浏览按钮；AI 助手和「更多」保持可见。

## 节点上能做什么

选中一个节点，上方是操作条，下方是它的表单。每一块表单长的都是同一个样子：最上面一排是连进来的
上游（芯片、挂上的素材），正文是提示词或要处理的那段字，底栏是几枚设置芯片（模型、音色、目标语言……）、
一个「参数」按钮收着其余的设置，最右边一枚圆形的发送键。正文再长，底栏也钉在面板底边。

- **图片 / 视频**：还空着时下面挂提示词面板 —— 模型、比例、清晰度、时长这些**由模型描述符
  决定**，换个模型这一行自己就变。有产出之后操作条上是一排图标：「预览」「剪一段」「换一份」，接着是这一格的
  **能力**（见下面「格子自己的能力」）。
- **便签**：选中一张便签**不会弹出写作面板** —— 选中多半是要挪一挪、换个颜色。要 AI 帮忙时点操作条上的
  **「让 AI 写」**：空的是"从头写"，有字的是"照我说的改"（写完之后想"短一半""换个语气"）；再点一次收起。
  从一格长出来的「生成文案」便签会直接打开它。工具交回的结构化数据（按代码排版的便签）没有这个按钮。
  双击便签仍然是手动编辑。
- **音频**：选音色 + 要念的文字（配音）。空的音频格上方的操作条里可以在几种产出方式之间切换：「配音」、
  生成模型支持音频之后的「生成」（音乐、音效），以及插件提供的生成器（多了收进「⋯」）。
- **分组框**：把一堆东西圈起来命名。框选几项之后按 <kbd>⌘</kbd><kbd>G</kbd> 直接成组。

提示词、模型、时长、引用素材与任务状态都保存在**节点自己的结构**里。关闭表单、切换节点或重新
打开画板不会靠临时 UI 状态重建，因此二次点击不会换文案、丢占位或把失败节点继续显示为 loading；
失败会停在终态并显示可理解的原因。视频模型若声明连续时长区间，面板提供区间内的数字输入。

每个节点本身也会显示运行状态：等待执行是轻主色描边，生成中有动态光晕，失败是红色，取消则用弱化虚线；
**完成时闪一下就安静下来**，不留一圈绿框 —— 格子里的内容本身就是完成的证据。**每一种在跑的格子都有「停止」**
（生成、配音、写字、剪一段、一项能力），停下的是那一次任务；已经提交给供应商的远端生成，供应商可能照样计费。
跑挂了的格子写「生成失败」或「运行失败」和原因，不是「没能发起」。状态不只藏在任务中心或空槽里的转圈中，因此已有产物的节点重跑失败时也看得出来。
新产物落地或手动换素材后，表单会从该节点保存的数据重新载入；失败与取消不会清空输入，方便直接修改
后重试。

### 给节点起名

每个节点上方那一行显示它的名字，没起名时显示类型（「图片」「视频」「分组」……）。一张板上摆着
好几张图时，起了名才分得清哪张是哪张。**双击那一行就地改名**，或选中节点后点操作条上的铅笔
「重命名」：<kbd>Enter</kbd> 或点别处确认，<kbd>Esc</kbd> 放弃；用输入法打字时选词的 Enter
不会提前确认。清空名字就退回显示类型。名字最长 120 字，一次改名在撤销里是一步。

分组框的名字和别的节点是同一个：画板查找、画板列表的缩略图、复制出来的副本和 AI 助手认的都是它。

### `@` 引用素材

提示词框里按 `@` 可以引用素材库里的东西，菜单跟着光标走。挑中的会变成正文里的一个**行内
标签**——它就长在句子里，"把 @创作者.png 里的人放到街上"读起来是一句话。提交时它一分为二：
名字留在提示词里（有好几张图时模型得知道你说的是哪张），素材本身作为输入发出去。

### 剪一段

视频给**帧条**、音频给**波形**，拖两头定起止。填数字的问题不在麻烦，在于你不知道第 3.2 秒
是什么；想精确到某一帧时，右边的数字框仍然更快。

**原素材不动**，剪出来的是一份新素材、落到新的一格 —— 画板上每一步都该是可回头的。

## 格子自己的能力：把手里的内容变成新内容

画板上**没有单独的工具格**。把手里这一格变成新东西，是**这一格自己会做的事**：选中一段音频，它上方的操作条上
多出一排图标 —— 转写、分离人声与背景音、降噪；选中一段视频，还有「视频转 GIF」；选中一张便签或一篇文档，有
「翻译」。插件提供的内容工具也一样：吃一张图的 ComfyUI 工作流（放大、抠图、修脸）挂在图片格上，吃一段视频的挂在
视频格上。内置的排在前面、直接摆出来，多了收进「⋯」；每一枚悬停都说它对这一格做什么。

**点一枚，它的面板挂在格子下面；点另一枚，下面那块换成它的；再点一次收起**（按 <kbd>Esc</kbd> 或选别的格子也收起）。
「剪一段」「让 AI 写」也是这一排里的一枚，同样换掉下面那一块。面板最上面写着这一下对哪一格做什么 ——
「降噪 · 旁白：去掉音频或视频里的底噪」——**这一格的内容就是输入**，不用再挑、不用再连；下面是它自己的设置：

- **底栏是挑一个的设置**（「目标语言 英语」「引擎」），芯片上写的是选中的值，还没选时写字段名；必填的排前面，
  至多三枚。其余的在「参数」里，里面有必填还空着时按钮上有个小点。
- **还差什么没填，圆形的发送键是灰的**，悬停说差哪几样 —— 翻译要先挑目标语言。
- 工具还要别的输入时（比如给视频配一段音频），把那一格**连进这一格**，面板上面一排是它的上游芯片，点哪一格就从哪一格
  取：便签给字、文档给钉住的那一版正文、图片 / 视频 / 音频给素材、3D 场景给场景。值在**点运行那一刻**从画布上取，
  改了上游的字，下次运行就跟着变；删掉那根线，绑定也跟着摘掉。
- **每一项的设置存在这一格上**，下次再点开还是上次的样子；这一格自己的东西（图、字、提示词）不动。

**产出落在右边**：每跑一次，结果都**新建成这一格右边的一列格子**并连上线 —— 图片、视频、音频各是那一种格子，
别的文件落成写着文件名的便签，文字落成便签，结构化数据落成按代码排版的便签；这一格自己一个字段不动。只落工具的
**成品**：给工作流连线用的输出(素材 id 列表、摘要、任务号这一类)不落。上一次的产出留着，不会被覆盖。一次最多
新建 12 格，多出来的合进最后一张便签。

**在跑的时候**，格子自己的内容照常显示，底边挂一条「正在运行 · 素材转写」、进度和**停止**（会真的停下插件进程，
任务中心里那条任务一并取消）。跑挂了不给这一格套红框：选中它时底边写着原因，面板里也写着，改一改再点一次。

**不吃画板内容的插件生成器**（按提示词出图的 ComfyUI 工作流、Manim / Remotion 的动画）不是某一格的能力，是
**空格子的一种填法**：放一格空的图片（视频、音频），在它上方的操作条里切到那个生成器，面板就是它的表单；跑出来的
那张图填进这一格，别的产出（一段说明……）新建在右边。

画板上**只有「内容 → 内容」的工具**。调用工作流、HTTP 请求、文本模板、JSON 提取、字符串处理、
检索笔记这类流程和数据步骤，只列清单、看状态、上传的插件工具，以及**按另一个系统里的编号去取东西**的插件工具
(按任务号导入 ComfyUI 产出、按 fs_id 从网盘导入、按对象路径从对象存储取回)，不在画板上 —— 它们在
[工作流](/docs/guides/workflows)和对话里用；要把一个文件放上画板，从素材库拖进来。表单也**只有创作者要填的参数**：
参数映射、原始 JSON、代码这种给搭流程的人看的字段不在画板上；必须填这种字段的工具（比如要一串结构化步骤的讲解视频）
在工作流或对话里用。

**同一件事只有一个入口。** 一个插件工具和某个生成模型是同一件事时 —— 比如 ComfyUI 里只有一个存下来的图片 / 视频 /
音频输出节点的工作流(预览节点不算)，它本来就是图片、视频格里的一个模型 —— 你又用得上那个模型，它就不单独列出：放一格图片
(视频、音频)、选那个模型，结果落在原位、能一次几张、能等更久。

**指向某样东西的字段是下拉，不用抄 id**：项目、连接都从这个工作区里挑，项多了下拉顶上能搜。
跟着别的字段走的下拉（比如跟着连接走的模型）换了上级就清掉旧值。

**用谁的连接**：插件工具用的是**点运行的那个人自己接的连接**。共享画板上同事存下的设置，你点运行用的是你自己的
连接 —— 你没有的话，面板会说清楚是哪个插件，并给一个去插件页新建的入口。有好几个连接时，在「参数」里挑一个。

**升级之前**摆在画板上的工具格会搬到它接着的那一格上：设置存进那一格、工具格撤掉，它跑出来的产出留着、改从那一格
连出；按参数出素材的工具格变成那种素材的空格子、选着那个生成器；找不到能接的格子的（或已经不在画板上的工具）变成
一张写明原来设置的便签，线都还在。

## AI 助手

右上角的机器人图标打开助手。它**不是第二套 AI**：会话池、消息、确认卡和全局助手是同一套，
只是每条消息多带一行"你正在看这张画板"。

左上角标题就是当前会话，点击可搜索或切换；空间不足时标题省略，不再塞入另一层带边框的选择器。

它能读画布（`get_board`）也能改（`edit_board`）：加便签、改字、给节点起名、连线、删项、摆位置。你起的名字它也看得见，提到某个节点时可以直接说名字。**改动
一律先出确认卡**，你批准了才落到画布上。它提交的是细粒度算子而不是整份画布 —— 后者在稍微
复杂一点的板上必然出错：漏掉几项，或者把你一手拖好的位置全部推平。

### 让智能体用格子的能力

助手也能替你用一格的能力：先看有哪些（`list_board_producers`，和你在操作条上看到的是同一份：每一项挂在哪几种格子上、
这一格的内容填进哪个字段、还有哪些设置，插件工具只有**你自己接的**），在那一格上写好这一项的设置、别的输入接哪几格
上游，并在同一批改动里连好线（`edit_board` 的 `set_form`）。改动照旧先出确认卡；写错的（这一格没有这项能力、没有这个
字段、绑了没连线的格子、便签接到素材字段上）在开卡时就被拒，不会等你批准了才报错。它不能再放单独的工具格。

**跑**（`run_board_item`，带上是哪一项能力）和你亲手点发送键走的是同一条路，用的是**批准的人自己的连接**：

- **不花钱不出门的工具直接跑**（翻译、转写、视频转 GIF、插件自报只读的工具……），不弹卡；
- **花钱的、对外有后果的等你批准** —— 比如跑 ComfyUI 工作流、声明了对外后果的插件工具。卡上写着
  在哪张画板上跑哪个工具、用你的哪条连接、会不会花钱或伸到应用之外。拒了就什么都不跑。

自动放行照旧生效：auto 档里花钱的有连开上限，对外的仍然回到你；「全部放行」全部放行。只读的那几次
虽然没问你，也记在会话设置里的「这次对话自动放行了」一栏。

## 撤销

<kbd>⌘</kbd><kbd>Z</kbd> 撤销，<kbd>⌘</kbd><kbd>⇧</kbd><kbd>Z</kbd> 重做，工具条上也有按钮。
连续拖动会并成一步 —— 拖一个节点会发几十次位置更新，一次一步的话你得按几十下才回得去。

## 评论与标记

顶部评论与旗帜按钮分别进入评论模式和标记模式；两种模式互斥，Esc 退出。它们旁边的眼睛按钮分别一键显示或隐藏评论、标记，不删除内容。标记不在添加节点菜单里。

标记模式下点击空白处放置位置书签，配置名称和跳转快捷键；同一张画布一次只打开一个标记弹窗。快捷键右侧可清除绑定，底部可删除标记。评论模式下点击空白处写评论，支持 `@` 工作区成员；提交后仍保留可交互的提及标签。自己的评论可点击铅笔编辑。相邻评论点可直接切换，不被当前弹窗的透明区域挡住。

模式切换和撤销不改变数据节点的连线。工具组用分割线区分，评论/标记是独立协作层，不参与生成和工作流运行。

## 文档与 3D 引用

「添加 → 文档」选择固定版本的笔记；拖动正文或内嵌图片都会移动文档节点。更换模式时标题栏高度不变。连接下游后，正文作为创作参考；点击卡片底部可更新版本或打开原文。

「添加 → 3D 场景」可选择工作区场景。**场景格自己会渲白模参考**：选中它，面板底栏挑「镜头」（场景只有一个镜头时
不用挑，显示的就是它；一个镜头都没有时芯片是灰的，打开场景加一个）和「渲染内容」（首尾静帧、运镜视频或都要），
点右下角的圆键 —— 渲的时候格子上是和别的格子一样的扫光、进度和「停止」，渲出来的首帧、尾帧、运镜视频
**新建在场景格右边**并连上线，场景格和它的缩略图不动；再渲一次是新的一列，上一轮的留着。面板上的「编辑场景」
打开场景页改构图、加镜头。渲出来的图和视频再连给图片、视频格当参考就行。

此前这件事要在场景格旁边另放一格「渲染白模参考」工具格，再在工具格上挑一遍场景 —— 同一件事的两半。它已经
撤下画板（工作流里照旧有这个节点）；升级时画板上的这种工具格会把镜头和渲染内容搬到它接着的场景格上、然后
撤掉，跑出来的产出留着、改从场景格连出；找不到场景格的变成一张写明原来设置的便签。详细步骤见
[3D 场景与动画](/docs/guides/scenes)。
