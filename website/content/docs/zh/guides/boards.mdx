创意画板是**想法摊开、边看边做**的地方：把素材、文字和生成结果摊在一张桌上，看、比、改，直到一个想法成形。内容就是界面，摆放和分组就是整理；同一句提示词可以并排试几个模型，挑一个接着做；每一格都记得自己是怎么来的，能重新生成、再跑一次。想把做法固定下来、换个输入让它自己再跑，用[工作流](/docs/guides/workflows)。

画板上的格子有九种：便签、文档、图片、视频、音频、3D 场景、资产、时间线，以及把几格圈起来的分组。**连接两格，会把上游内容作为下游输入**，例如将参考图交给视频格，或将文档交给便签 —— 一根线的意思是「参考它」，不是「然后做它」。拖动连线到格子左右可见的 **＋** 区域即可连接。选中一格，上方是操作条，下方是它的生成或编辑面板。

## 把东西放上画板

工具栏的「添加」(⌘N)是一张可搜索的清单,每行一个名字加一句说明,分三组:

| 分组 | 格子 |
| --- | --- |
| **新建** | 图片、视频、音频、便签、文档、3D 场景(连一段剧本进来搭白模)、时间线 |
| **从库里放** | 素材(素材库里的图片、视频、音频或文档)、资产(资产库里的一个人物、场景或道具)、3D 场景(引用一个现成的场景) |
| **整理** | 分组 |

![工具栏「添加」:可搜索的清单,每行一个名字加一句说明](/media/screens/board-add-menu.png)

- **从访达或资源管理器拖进来**:图片、视频、音频、PDF / Word / PPT 先进素材库,再按种类各放一格,落在松手的位置。
- **⌘V 粘贴**:画布上的格子(见下)、截图或复制的媒体文件各放一格,一段文字落成一张便签,摆在视野中间。光标在便签、提示词框
  或任何输入框里时,粘贴照常贴进那里,不会往画布上放东西。
- **挑素材的弹窗**:能搜名字、按种类筛,也可以只看「这张画板上的」;「上传本地文件」或把文件拖进弹窗(「松手上传」)直接导入,
  只收这一格要的那种素材。

![挑一张图片的弹窗:按名字搜、「上传本地文件」,下面一行一份素材](/media/screens/board-picker.png)

## 连一条线能带来什么

连线不是装饰，下游格子会照着上游的东西改自己的面板：

| 上游 → 下游 | 下游拿到什么 |
| --- | --- |
| 便签 → 图片 / 视频 | 那段文字自动填进提示词 |
| 便签 → 音频 | 那段文字就是要念的内容 |
| 便签 / 文档 → 便签 | 上游的字作为**材料**发给模型（和"要求"分开） |
| 文档 → 图片 / 视频 | 文档正文由后端按连线读给模型;还在解析、解析失败的会直接说明 |
| 图片 → 图片 | 挂成参考图 |
| 图片 → 视频 | 一张挂首帧，多张挂参考；选的模型不收图片时，面板上方写明连过来的图不会用上 |
| 图片 / 视频 → 便签 | 模型**看着写**：图片直接看，视频抽帧看 |
| 音频 → 便签 | 有转写就把转写当材料 |
| 资产 → 图片 / 视频 | 等于在提示词里 `@` 了它:描述拼进提示词,参考图按模型收得下的张数挂上 |
| 3D 场景 → 图片 / 视频 | 面板上多一枚「3D 参考」芯片,见下面「3D 场景格」 |
| 视频 / 图片 / 音频 → 时间线 | 接到这条时间线的末尾 |

上游填进来的东西**不覆盖你自己写的**：只有输入框还空着、或里面正好是上一次自动填进去的那段时才替换。

**一次连几格。** 选中两格以上，选区框右侧有一个带数字的 **＋**：从它拉线，松在一格上就把选中的几格都连过去（每根线连不连得上
先预览给你看），松在空白处弹出「新建一格，连上选中的 N 格」，新的一格把它们都当上游 —— 几张图一起当参考就是这么接的。多选时
每一格自己的 ＋ 只在悬停时露出，只连它自己。撤销都是一步。

![多选三格后的选区框:框上方是统一的操作条,右边是带数字的出口 ＋](/media/screens/board-selection.png)

**复制粘贴格子。** ⌘C 复制选中的格子和它们之间的连线，⌘V 粘贴；连到没被复制的格子的线不带。在跑的状态不复制；时间线格复制出来
是另一条时间线，标明是副本。

## 顶部工具栏

从左到右：添加（⌘N）与撤销 / 重做；评论模式、显示 / 隐藏评论、讨论中心；标记模式、显示 / 隐藏标记、标记清单；查找节点（⌘F）、
连线样式（贝塞尔曲线 / 圆角折线，画板单独记住）、触控板模式 / 鼠标模式、全览、适应画布；最右边是 AI 助手和「更多」（删除画板，需确认）。
窗口较窄时用工具条两端的箭头浏览，AI 助手和「更多」保持可见。

⌘F 按文字、名称或类型查找，起了名的格子在结果里显示名字，命中的在画布上描圈，Enter / ⇧Enter 跳到下一个 / 上一个，Esc 关闭。
画板名字在顶部路径上点一下就能改。

画板列表里，卡片右上角的 ⋯ 和右键菜单有同一组动作：打开画板、重命名、创建副本、删除（需确认）。标题栏的「选择」进入多选，可全选、
批量删除；部分删不掉时会说明几项失败，失败的保持勾选。创建副本不带正在生成的格子，它们在副本里退回空槽、提示词保留。

## 格子上能做什么

选中一格，上方是操作条，下方是它的面板。每一块面板长的都是同一个样子：最上面一排是连进来的上游（芯片、挂上的素材），正文是提示词
或要处理的那段字，底栏是几枚设置芯片（模型、音色、目标语言……）、一个「参数」按钮收着其余的设置，最右边一枚圆形的发送键（⌘↵）。
正文再长，底栏也钉在面板底边。

- **图片 / 视频**：还空着时下面挂生成面板。模型下拉每一行写「模型 · 连接名」，默认选你在设置里设的默认模型，没设时显示「选择模型」；
  换模型时参数回到新模型的默认值。比例、清晰度、时长、生成方式（首尾帧 / 全能参考）、生成声音这些**由模型描述决定**，收在「参数」里；
  模型能一次出几张时底栏多一个「一次落出几格」（N×），点生成之前就按这个数在右边摆好占位。图片格还有「提示词模板」。
  有产出之后操作条上是「预览」「剪一段」「换一份」，接着是这一格的**能力**（见下一节）。
- **参考素材**：面板上的「＋」槽打开「添加参考素材」，按角色写着「还能加 N 份」；也可以把文件拖到槽上，或在面板里 ⌘V 粘贴截图，
  直接上传挂上。
- **便签**：选中一张便签**不会弹出写作面板** —— 选中多半是要挪一挪、换个颜色。要 AI 帮忙时点操作条上的**「让 AI 写」**：空的是
  "从头写"，有字的是"照我说的改"；再点一次收起。双击便签仍然是手动编辑。操作条上还有颜色和「保存到笔记」。
  从笔记的选区工具条「加到画板」放过来的便签，底下一条写着「来自笔记「…」」，点了回到那篇笔记、定位到那段字(见[笔记](/docs/guides/notes))。
- **音频**：选音色 + 要念的文字（配音）。引擎选「阿里云百炼(CosyVoice)」时也能挑「我的克隆音色」，念配音库里那把嗓子在你百炼账号里的副本，第一次用会先问一次要不要把参考音频传上去(见[剪辑 → 不装本机引擎,用百炼念自己的音色](/docs/guides/editing))。空的音频格上方的操作条里可以在几种产出方式之间切换：「配音」、生成模型支持音频之后的
  「生成」（音乐、音效），以及插件提供的生成器（多了收进「⋯」）。
- **分组框**：把一堆东西圈起来命名，「联动拖动」开着时拖框带着里面的格子走。框选几项之后按 <kbd>⌘</kbd><kbd>G</kbd> 直接成组。

![空图片格的生成面板:提示词、模型(演示用的占位连接,不会真的生成)、「参数」,右下「一次落出几格」展开着 1× – 4×](/media/screens/board-generate.png)

**「＋ 生成 ▾」接着做。** 有内容的一格上，操作条的「＋ 生成 ▾」把下一步说全：便签有「用这段文字生成图片 / 视频」「把这段文字念成音频」，
图片有「用这张图当首帧生成视频」，视频有「参考这段视频生成视频」，音频有「配着这段音频生成视频」，3D 场景有「用这个场景的构图生成图片」
「用这个场景的镜头当参考生成视频」，几乎每种都有「让 AI 接着这一项写点文字」。选一项就在右边放好一格连上线的空格子，等你点生成。

提示词、模型、时长、引用素材与任务状态都保存在**格子自己的数据**里。关闭面板、切换格子或重新打开画板不会丢；失败会停在终态并显示
原因，失败与取消不会清空输入，方便直接修改后重试。

每一格都会显示运行状态：等待执行是轻主色描边，生成中整格扫光，失败是红色，取消则用弱化虚线；**完成时闪一下就安静下来**。**每一种在跑
的格子都有「停止」**（生成、配音、写字、剪一段、一项能力），停下的是那一次任务；已经提交给供应商的远端生成，供应商可能照样计费。跑挂了
的格子写「生成失败」或「运行失败」和原因。任务还活着的格子删不掉，要先「停下并删除」。

### 给格子起名

每一格上方那一行显示它的名字，没起名时显示类型（「图片」「视频」「分组」……）。**双击那一行就地改名**，或选中后点操作条上的「重命名」：
<kbd>Enter</kbd> 或点别处确认，<kbd>Esc</kbd> 放弃；用输入法打字时选词的 Enter 不会提前确认。清空名字就退回显示类型。名字最长 120 字，
一次改名在撤销里是一步。画板查找、列表缩略图、复制出来的副本和 AI 助手认的都是这个名字。

### `@` 引用素材和资产

提示词框里按 `@`，菜单跟着光标走，依次列出已连接的格子、资产库、素材库，上面有「全部 / 已连接 / 资产 / 图片 / 视频 / 音频」筛选。
只列所选模型收得下的那种素材；资产（人物、场景、道具）总在。挑中的会变成正文里的一个**行内标签** ——"把 @创作者.png 里的人放到街上"
读起来是一句话。提交时它一分为二：名字留在提示词里，素材本身作为输入发出去；资产的描述和参考图怎么挂见[资产库](/docs/guides/assets)。

![提示词里按 `@`:菜单跟着光标,列出资产库里的人物、场景和道具](/media/screens/board-mention.png)

### 剪一段

视频给**帧条**、音频给**波形**，拖两头定起止，「剪出来」;视频还能「取一帧」、选「保留声音 / 去掉声音」。想精确到某一帧时，右边的数字框
更快。**原素材不动**，剪出来的是一份新素材、落到新的一格。

## 格子自己的能力：把手里的内容变成新内容

画板上**没有单独的工具格**。把手里这一格变成新东西，是**这一格自己会做的事**，操作条上直接摆着前四项，多了收进「⋯ 更多能力」：

| 格子 | 能力 |
| --- | --- |
| 音频、视频 | 素材转写、分离人声与背景音、降噪（强度轻 / 中 / 重） |
| 视频 | 视频转 GIF、对口型（音频取连进来的音频格，或用稿子当场配） |
| 图片 | 宫格切分、让它说话 |
| 便签、文档 | 翻译（英、简中、繁中、日、韩、法、德、西、俄） |
| 资产 | 补全多角度（三种都有）、生成表情（只有人物）、让它说话（只有人物） |

![选中一格图片:操作条上依次是预览、剪一段、换一份、宫格切分、让它说话、「＋ 生成 ▾」、重命名、复制、删除](/media/screens/board-abilities.png)

<Recording src="/media/videos/board-cells.mp4" poster="/media/screens/board-abilities.png" caption="实机操作:添加菜单、格子操作条、多选出口、生成面板的「一次落出几格」、换图弹窗、3D 场景格与时间线格(没有调用生成模型)" />

插件提供的内容工具也一样，按它吃什么内容挂在对应的格子上。对口型、让它说话、补全多角度、生成表情要花钱；数字人的两项还要确认授权，
见[数字人](/docs/guides/digital-humans)。

**宫格切分**把九宫格、四宫格、分镜条这类拼图按行列等分切成单图：四宫格 2×2、九宫格 3×3（默认）、左右两张 1×2、上下两张 2×1、横排三张 1×3、
竖排三张 3×1、六宫格（2 行 3 列 / 3 行 2 列）、十二宫格（3 行 4 列 / 4 行 3 列）；「分隔线」可以保留（严格等分）或去掉（每边最多去 6%）。
本机处理、不花钱，切出来的几张照原来的宫格排在右边。

**点一枚，它的面板挂在格子下面；点另一枚，下面那块换成它的；再点一次收起**（按 <kbd>Esc</kbd> 或选别的格子也收起）。面板最上面写着这一下
对哪一格做什么，**这一格的内容就是输入**，不用再挑、不用再连：

- **底栏是挑一个的设置**（「目标语言 英语」「引擎」），芯片上写的是选中的值，还没选时写字段名；其余在「参数」里，里面有必填还空着时
  按钮上有个小点。**还差什么没填，发送键是灰的**，悬停说差哪几样。
- 工具还要别的输入时，把那一格**连进这一格**，面板上面一排是它的上游芯片：便签给字、文档给钉住的那一版正文、图片 / 视频 / 音频给素材、
  3D 场景给场景。值在**点运行那一刻**从画布上取。
- **每一项的设置存在这一格上**，下次再点开还是上次的样子；这一格自己的东西不动。

**产出落在右边**：每跑一次，结果都**新建成这一格右边的一列格子**并连上线 —— 图片、视频、音频各是那一种格子，文字落成便签，结构化数据
落成按代码排版的便签。只落工具的**成品**，给工作流连线用的输出不落。上一次的产出留着。一次最多新建 12 格，多出来的合进最后一张便签。
在跑时格子底边挂一条运行态、进度和**停止**；跑挂了选中它时底边写着原因。

**不吃画板内容的插件生成器**（按提示词出图的 ComfyUI 工作流、Manim / Remotion 的动画）是**空格子的一种填法**：放一格空的图片（视频、音频），
在操作条里切到那个生成器，面板就是它的表单。

画板上**只有「内容 → 内容」的工具**。调用工作流、HTTP 请求、文本模板这类流程和数据步骤，只列清单、看状态、上传的插件工具，以及**按另一个
系统里的编号去取东西**的工具（按任务号导入 ComfyUI 产出、按 fs_id 从网盘导入），都在[工作流](/docs/guides/workflows)和对话里用。

**同一件事只有一个入口。** 一个插件工具和某个生成模型是同一件事时 —— 比如 ComfyUI 里交得出图、视频或音频的工作流，它本来就是图片、视频
格里的一个模型 —— 画板上只留「生成」这一个入口，「⋯」里不再重复列：放一格图片（视频、音频），选这个模型，结果落在原位。工作流里有好几个
保存节点时，生成前按「跑几遍 × 一遍几张」一次摆好占位（ComfyUI 工作流的张数是跑几遍，每遍按工作流原样出；「一次落出几格」里写着跑几遍），「参数」里还有一项「**结果取自**」：默认全部
（只接了预览节点、其中有中间一步或控制图时默认「最终结果」，只交回最后那一张），选一个就只交回它的、别的保存节点不跑。只交出一段字的 ComfyUI 工作流（打标签、反推提示词）不是模型，照旧是格子的一项能力。
ComfyUI 工作流的「参数」里，尺寸可以直接输入任意宽高(如 `768x1024`)，选大模型、LoRA 的那一格带缩略图、底模和触发词；有没有画布都能
跑几遍(局部重绘这类也行)。详见[用 ComfyUI 生成](/docs/guides/comfyui)。

**用谁的连接**：插件工具用的是**点运行的那个人自己接的连接**。共享画板上同事存下的设置，你点运行用的是你自己的连接 —— 你没有的话，面板会
说清楚是哪个插件，并给一个去插件页新建的入口。

## 时间线格

「添加 → 新建 → 时间线」在画布上放一格小剪辑台。格子背后是一条正常的时间线，放在这张画板自动建的同名项目里，剪辑页里能接着精修。

![时间线格:三格视频连进来按顺序接上,上半是粗剪预览,下半是缩略图条](/media/screens/board-timeline.png)

- **上半是粗剪预览**：主视频轨按顺序连着播，第一条音轨跟着出声；底下是播放 / 暂停、「当前 / 总长」和静音。变换和字幕不在这里预览，在剪辑里。
- **下半是缩略图条**（宽度跟时长走），带播放头：点一段选中，按住横着拖换顺序（后面的跟着挪），Delete 删掉选中的一段。
- **加片段**：把视频 / 图片 / 音频格连进来就接到末尾（音频进音频轨，画幅跟第一段走；断开连线不会把片段拿掉）；或点缩略图条末尾的「＋」，
  先列这张画板上的素材，也能挑整个素材库。别的格子连不进来，会说「时间线格只收视频 / 图片 / 音频」。
- **操作条**：「在播放头处切开」「删掉选中的这一段」「在剪辑里打开」「导出」。剪、删、排、加片段都在画板的撤销里，和画布上的改动按先后一步步退。
- **导出**：面板写着几段、多长、多大，底栏挑分辨率（原样 / 1080p / 720p / 480p）和画质（高画质 / 标准 / 紧凑），「参数」里是「AI 生成」标识
  （默认不标）。成片落成右边一格视频；导出时格子上方一条「导出中」，能停，预览照常能用。

## 文档格、资产格与 3D 场景格

**文档格**有两种：

- **引用笔记的**：「添加 → 新建 → 文档」放一格空文档。选中它，操作条上点「选择笔记」钉住一篇笔记的某一版（之后是「更换笔记」），格子底部写着
  版本号，可以「更新到最新版本」「打开原文」；或者点「让 AI 写」—— 空的写出一篇新笔记并引用它，引用着笔记的写成那篇的新一版（旧版还在）。
  「让 AI 写」看得到连进来的图、资产和便签。
- **文档素材**：PDF / Word / PPT / Excel 拖进来（或从素材库挑），格子里是解析出的全文，底部写「文档原件 · 只读」，能「在素材库里打开」。
  操作条上的「转为笔记」把全文存成一篇笔记，这一格随即改成引用它，之后就能「让 AI 写」。见[文档](/docs/guides/documents)。

**资产格**（「添加 → 从库里放 → 资产」）是封面、名字和种类角标。连进生成格等于 `@` 了它，连进便签或文档格时它的描述当材料。见[资产库](/docs/guides/assets)。

**3D 场景格**上画的是整个场景的全景白模（后端渲，场景改了回到画板就是新的一张），操作条上有「编辑场景」。面板的「怎么产出」在两种之间切：

- **渲白模参考**：底栏挑「镜头」（只有一个镜头时就是它；一个都没有时打开场景加一个）和「渲染内容」（首尾静帧 / 运镜视频 / 静帧和运镜视频），
  点圆键渲；首帧、尾帧、运镜视频**新建在场景格右边**并连上线，再渲一次是新的一列。
- **按文字搭 3D 场景**：把剧本或分镜（文档、便签）连进场景格，挑模型、「最多几镜」（默认 6）和画幅，搭**一个**白模布景 —— 人物按文字动起来，
  几台相机从不同机位拍同一段动作，写好运镜。搭好的场景换进这一格（旧的还在「3D 场景」里）。「添加 → 新建 → 3D 场景」放的就是一格等着搭的空场景。

![选中 3D 场景格:操作条上「渲白模参考 / 按文字搭 3D 场景」两种产出方式,面板底栏挑镜头和渲染内容](/media/screens/board-scene-cell.png)

把 3D 场景格**连进图片或视频格**，生成面板上多一枚「3D 参考」芯片：挑镜头和「怎么用」—— **构图参考**、**首尾帧**（视频）、**运镜参考**（视频），
只列所选模型收得下的。生成时按场景**当时**的样子现渲这个镜头挂上，提示词里自动附上「这是白模、只取构图和机位」；镜头里看得见的人偶要是指定了
「演的是」资产库里的人物，长相和描述一并带上。详细见 [3D 场景与动画](/docs/guides/scenes)。

![3D 场景格连进视频格:生成面板最上面多一枚「3D 参考」芯片,写着场景名和「构图参考」](/media/screens/board-scene-reference.png)

## AI 助手

右上角的机器人图标打开助手。它**不是第二套 AI**：会话池、消息、确认卡和全局助手是同一套，只是每条消息多带一行"你正在看这张画板"。
左上角标题就是当前会话，点击可搜索或切换。

它能读画布（`get_board`）也能改（`edit_board`）：加便签、改字、给格子起名、连线、删项、摆位置、放一格新的时间线并把格子接进去、写导出设置。
**改动一律先出确认卡**，你批准了才落到画布上，开着的画板跟着刷新。它提交的是细粒度算子而不是整份画布 —— 后者在稍微复杂一点的板上必然出错。

### 让智能体用格子的能力

助手也能替你用一格的能力：先看有哪些（`list_board_producers`，和你在操作条上看到的是同一份，插件工具只有**你自己接的**），在那一格上写好
这一项的设置、别的输入接哪几格上游，并在同一批改动里连好线（`edit_board` 的 `set_form`）。写错的在开卡时就被拒。

**跑**（`run_board_item`）和你亲手点发送键走的是同一条路，用的是**批准的人自己的连接**：不花钱不出门的工具直接跑；花钱的、对外有后果的等你批准，
卡上写着在哪张画板上跑哪个工具、用你的哪条连接。自动放行照旧生效。

## 撤销

<kbd>⌘</kbd><kbd>Z</kbd> 撤销，<kbd>⌘</kbd><kbd>⇧</kbd><kbd>Z</kbd>（或 <kbd>⌘</kbd><kbd>Y</kbd>）重做，工具条上也有按钮。连续拖动会并成一步；时间线格里的剪、删、
排也在同一条撤销里。撤销不会把在跑的格子撤没，智能体改过的画板跟上新版之后，撤销也不会把它的改动盖回去。

## 评论与标记

顶部评论与旗帜按钮分别进入评论模式和标记模式；两种模式互斥，Esc 退出。它们旁边的眼睛按钮分别一键显示或隐藏评论、标记，不删除内容。标记不在「添加」菜单里。

标记模式下点击空白处放置位置书签，配置名称和跳转快捷键；同一张画布一次只打开一个标记弹窗。快捷键右侧可清除绑定，底部可删除标记。评论模式下点击空白处写评论，支持 `@` 工作区成员；提交后仍保留可交互的提及标签。自己的评论可点击铅笔编辑。相邻评论点可直接切换，不被当前弹窗的透明区域挡住。

模式切换和撤销不改变格子之间的连线。评论 / 标记是独立协作层，不参与生成和工作流运行。
