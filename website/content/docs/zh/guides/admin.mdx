侧栏的「**管理**」是给**部署管理员**的:整个后端怎么跑、谁能进来、装哪些本机引擎、钱花在哪。只有部署管理员看得到这一项,
后端的每个管理接口也都查这个身份 —— 工作区管理员不算。**单机使用时你就是部署管理员**,什么都不用改;
把后端共享给同事之后(见[远程部署](/docs/guides/remote)),这些设置才需要有人管。

「管理」分五页:**概览、成员、成本规则、引擎、部署设置**。

## 概览

顶上挑统计范围:近 7 / 30 / 90 天。任务活动和花费按这个范围算;账户、工作区、素材(全部工作区)是当前总数。

![管理 → 概览:近 30 天的账户、工作区、素材和花费,任务活动图,「谁在花钱」(还没有花费)](/media/screens/admin.png)

<Recording src="/media/videos/admin.mp4" poster="/media/screens/admin.png" caption="实机操作:概览、成员、引擎(滚动长列表时顶栏不动)、部署设置,再到统计页" />

- **任务活动**:每天跑了多少任务、失败多少,没跑任务的日子也占一格。
- **谁在花钱**:按人列 AI 花费。不同币种分开列、不相加也不换算;用量没有匹配到价格规则时这里是空的,去「成本规则」补上。

## 成员

- **账户**:谁在用这个部署 —— 成员、角色、最近活跃、所在工作区,以及各自的客户端版本(由客户端自报,桌面端或浏览器扩展)。
  每行的 ⋯ 菜单里可以「设为部署管理员」「取消部署管理员」(至少留一位),或「删除账号」:删掉这个人和只属于他的东西 ——
  他的对话、他的密钥、他的默认模型,以及只有他一个人的工作区;还有别人在的工作区不会被删。这一步不可撤销。
- **不带工作区的邀请**:不开放自助注册时,用「生成邀请」放人进这台部署。生成之后给出一条链接(只在这一次看得到,库里只存它的
  哈希),一次性使用,7 天后失效;备注只给你自己看(记一下发给了谁)。对方打开链接注册、自己设密码,然后自己建工作区,或者再被人
  拉进某个工作区。发错了人、消息被转走了,在那一行点「作废」。列表里认一张邀请靠它末尾几位。升级之前发出去的邀请码也在这里,
  照样能用到过期。开着自助注册时这里会说「现在不需要邀请」。
- **等你放行**:工作区管理员发的邀请链接只管进工作区。要让还没账号的人也能凭它注册,他会请你放行 —— 你会收到一条通知,这里
  列着是谁发的、什么角色,点「放行」即可。你自己发的邀请链接不用放行。

拉人进某个工作区,在「设置 → 团队与成员」里做最省事:

- **发邀请链接**:选角色,生成一条链接发给对方。已有账号的人打开就直接加入、切过去(右下角会说是谁的工作区、什么角色,能撤销);
  还没账号的人凭它注册,注册完直接是那个工作区的成员,不用先建一个自己的。链接 7 天有效、用一次就作废,只在生成的那一次看得到,
  发错了在成员列表里撤回。还没账号的人能不能凭它注册,看这台部署:开放注册时都能;否则部署管理员发的能,工作区管理员发的要请
  部署管理员放行(放行之前,链接只对已有账号的人有效)。
- **按用户名邀请**:对方是这台 Mosael 上已有的账号时也可以,他在通知里接受。

发出去还没被接受、还没用掉的邀请(两种都有)列在成员下面,邀错了可以撤回。

### 有人忘了密码

- **成员忘了**:在他那一行的 ⋯ 菜单里点「重置密码」。他现在的密码和所有已登录的会话立刻失效,弹窗里给出一个临时密码 ——
  **只显示这一次**,复制下来交给他;他登录后在「设置 → 账户」里改成自己的。改你自己的密码不走这里,在「设置 → 账户」里改。
- **你就是唯一的部署管理员,自己忘了**:在运行后端的那台电脑上跑一条命令重置(不用先停应用):

  ```bash
  # 开发环境(源码检出)
  cd backend && uv run python -m app.cli reset-password <用户名>

  # 安装好的应用(macOS)
  /Applications/Mosael.app/Contents/Resources/backend/mosael-backend/mosael-backend reset-password <用户名>
  ```

  Windows / Linux 在安装目录的 `resources/backend/mosael-backend/` 下(Windows 是 `mosael-backend.exe`)。命令打印一个临时密码,
  用它登录后再改;想直接设成某个密码就加 `--password <新密码>`。数据目录和后端是同一份(默认 `~/.mosael`,设了 `MOSAEL_DATA_DIR`
  就用它);用户名记不清的话,随便填一个,命令会列出这台部署上有哪些账号。

## 成本规则

给模型配计价规则(按 token、按张、按秒、按条,可带分时段价格),统计和任务中心据此累计 AI 花费。只有部署管理员能改,
其他成员在统计页看到的是按规则算出来的花费。规则怎么写、「预填价格」从哪取价,见[模型连接与配置 → 成本规则](/docs/guides/providers)。

## 引擎

本机跑的那几样 —— 转写、声音克隆、人声分离、降噪 —— 要装运行环境、下模型,动辄几 GB,而且装在后端所在的那台电脑上,
所以只有部署管理员能装。其他成员在用到的地方(逐字稿、降噪对话框、字幕配音)看到的是「由部署管理员安装」。

- **下载源**:装东西从哪个镜像拉。「依赖下载源(pip 镜像)」给本机引擎装 Python 依赖用 —— 每个都要拉 2–3 GB,国内直连官方 PyPI
  常常慢到不可用;「npm 源」给要装 npm 依赖的插件(比如 Remotion)。插件连接上可以各自换,没换就跟随这里。最后一行「模型下载源」
  管模型权重从哪儿下(HF 镜像、HuggingFace、ModelScope):声音克隆、本机识别(NSFW)、Mosael 起的本机 ComfyUI 都读它。
- **转写模型**:FunASR、WhisperX 的运行环境和模型。「安装运行环境」之后,它才会出现在「设置 → 能力提供方 → 转写」里能选。
- **声音克隆**:本地音色克隆(F5-TTS、Fish Speech)的运行环境和权重(权重从上面的「模型下载源」拉)。
- **人声与背景音分离**:Demucs。长素材在 CPU 上要跑十几分钟。
- **降噪**:内置降噪不用装;DeepFilterNet 在这里下载一次(约 30 MB),RNNoise 随应用带着。

![管理 → 引擎:下载源(pip 与 npm),下面是转写模型等本机引擎和各自的安装按钮](/media/screens/admin-engines.png)

这里说的「已安装」是真的试着把引擎加载了一遍,不是看目录在不在;装到一半断掉时会说「运行环境不完整」,再点一次安装补齐。

## 部署设置

- **谁能加入**:「开放自助注册」开着时,任何能连到这台后端的人都能自己建账号;部署到公网之后第一件事就是把它关掉,改发邀请。
  关掉之后,Google / Apple 这类第三方登录也建不了新号。
- **网页地址**:成员用浏览器打开 Mosael 的地址(例如 `https://studio.example.com`)。填了,邀请链接就多一个网页版 —— 对方可能还没装
  客户端;桌面单机用不着,空着,邀请只给桌面端链接。
- **共享文件夹**:其他成员读这台电脑上的本机文件(工作流的「上传文件」节点、按路径导入)时,只能读这里列出的文件夹;
  部署管理员不受限。详见[远程部署](/docs/guides/remote)。
- **出站代理**:代理地址和「绕过代理的主机」(一行一个)。AI 供应商请求、授权登录都走它;本机回连永不走代理。内嵌浏览器不受影响
  (发布账号各自配代理),插件连接可以在自己的「网络」里选跟随、直连或走指定代理。
- **内网访问**:工作流的「HTTP 请求」节点、智能体抓网页 / 发请求、从链接导入，默认**只许去公网** —— 本机回环、局域网和云服务器元数据
  地址在发出之前就被拦下，报错里会说该加哪一项。要放行就在这里「添加地址」：一个主机名、IP 或 CIDR 网段，主机名和 IP 可以带端口(只放行那一个端口)，
  比如 `127.0.0.1:11434`(本机 Ollama)、`nas.local`、`10.0.0.0/8`。判的是名字解析出来的 IP，跟随重定向时每一跳重新判。桌面版也一样，
  包括本机回环 —— 导入别人的模板在桌面版上一样常见。插件自己联网、供应商交回的产物地址不受这一项管。
- **AI 运行时**:「最大重试次数」(0–10,默认 3)。所有 AI 调用遇到 429、5xx、连接失败时按指数退避重试。
- **数据与诊断**:「完整备份」保存数据库、素材(含字体与头像)、插件和本机密钥(日志、导出文件、模型缓存不进备份);
  「从备份恢复」先校验归档格式、文件哈希和数据库完整性,再替换本机数据并重启;「诊断包」导出版本、系统信息和脱敏后的日志尾部,
  不含数据库、素材或密钥,报问题时附上它。

## 统计

侧栏的「**统计**」每个人都能看,看的是自己能看到的数据。分三页,统计范围可选近 7 / 30 / 90 天(默认 30 天),跟着范围走的每一块
都标着「近 N 天」;项目、素材、序列、工作流是当前总数。

![统计 → 概览:项目、素材、序列、工作流,近 30 天的任务活动和素材构成](/media/screens/statistics.png)

- **概览**:项目、素材、序列、工作流、运行中任务,近 N 天的 AI 花费、完成的任务和发布;任务活动和素材构成两张图。
- **发布**:发布活动和发布平台构成。
- **AI 用量**:AI 费用(按天、按供应商分摊;不同币种各画各的,可以切换)、Token 用量和缓存命中率。有「未定价」的用量时,
  部署管理员可以直接点过去补成本规则。
