**技能**是一份「做某一类事的方法」:分几步、每步用哪个工具、要检查什么,可以带几份参考文件。比如:

- 「做带货短视频」:先看商品图,写三段卖点脚本,配音,出 9:16 竖屏,片尾放购买引导;
- 「长视频切竖屏短片」:转写,挑出能独立成段的几分钟,裁成竖屏,加字幕;
- 「我们品牌的视频规范」:片头用哪段、字幕什么字体、哪些颜色不许用。

## 和记忆、工作流有什么不一样

| | 是什么 | 什么时候进对话 |
| --- | --- | --- |
| [记忆](/docs/guides/ai-studio) | 一条短约定:「成片统一 1080p 竖屏」 | **每一轮都在**,所以必须短 |
| 技能 | 一份做法,可以很长,带参考文件 | 平时只有名字和一句说明;要用时智能体才读全文 |
| [工作流](/docs/guides/workflows) | 一张固定的自动化图 | 不进对话;换个输入再跑一遍 |
| [笔记](/docs/guides/notes) | 可以追溯的资料 | 智能体搜到了才读 |

一句话:**规矩写成记忆,做法写成技能,要反复自动跑的做成工作流。**

## 在哪里管

**设置 → 智能体 → 技能**。列表分三组:

- **内置**:Mosael 自带的「创意画板」「搭工作流」「3D 场景与建模」。它们原来是每一轮都塞在智能体说明里的长段落,现在用到才读,
  每轮的说明短了约五分之一。不能改,可以「复制成我的」再改。
- **这个工作区的**:你和同事新建、导入、从对话存成的。工作区的成员共用。
- **来自插件**:插件包里带的技能,跟着插件装、跟着插件卸。

每一行有一个开关。**开着的技能才会出现在智能体那里**(和输入框的「/」菜单里)。

### 新建和编辑

点「新建技能」,填:

- **显示名**:给人看的,中文也行;
- **名字**:小写英文字母、数字和连字符(`short-video-ads`),智能体用它点名。显示名是英文时会自动填一个;
- **说明**:做什么、什么时候用。**智能体靠这一句决定要不要用它**,写清楚触发的说法(「用户说『带货』『种草视频』时用」);
- **做法**:Markdown 正文,写给智能体看。长的参考资料、模板、示例保存后作为**文件**加进去,正文里写「去读哪个文件」。

### 从对话存成技能

一段对话里把某件事做顺了,点输入框旁的「会话设置」→「存成技能」。Mosael 用这次对话正在用的模型起草一份,填进同一个编辑表单,
**你改完才保存** —— 草稿里不该有这一次具体的素材和文件名。这一步会调用一次模型,算在用量里。

### 导入与导出

技能用的是开放的 **Agent Skills(SKILL.md)** 格式,和 Claude Code、Claude 认的是同一种:一个文件夹,里面一份 `SKILL.md`(开头的
`name`、`description`,下面是正文),再加随意的文件。

- **导出**:每一行的「导出 .zip」,得到的就是那个文件夹,别处能直接导入。
- **导入**:「导入 .zip」或「导入文件夹」。导入**先不装**:每个技能的每个文件都摊开给你看,你决定装哪几个、换不换名字、
  装好开不开(默认不开)。和内置技能同名的必须换名字;和已有的同名可以替换。
- Mosael 自己的扩展只放在规范留的位置:显示名写在 `metadata` 的 `mosael-title` 里。别家的扩展字段(比如 Claude Code 的
  `disable-model-invocation`)原样保留在文件里,Mosael 不用它们。

技能文件夹放在数据目录的 `skills/<工作区 id>/<名字>/` 下,能用编辑器直接打开改。有人直接往那里扔一个文件夹,它会出现在列表里,
但**默认关着** —— 打开前同样先看全文。

## 在对话里用

- **智能体自己判断**:要做的事对得上某个技能的说明时,它先读那份技能(`use_skill`),需要时再读它带的文件(`read_skill_file`),
  然后照着做。对话里那一步显示成「用了技能:做带货短视频」,点开就是它读到的做法。子智能体也能读技能。
- **你点名**:在输入框里打 `/`,选一个技能,它变成一颗胶囊。发出去之后,这一轮直接照它做,不用等智能体想起来。一条消息最多点 3 个。
  `/` 只在行首或空格后面弹出,打网址不会弹。

## 安全

导入的技能是**别人写的话**,和网页上的字一样对待:

- **它不是授权**:会改东西的操作照旧弹确认卡,[权限档](/docs/guides/ai-studio)和放行准则一概不变。技能里写的 `allowed-tools` 不会预先批准任何工具。
- **启用之前看全文**:导入、打开插件带的、打开扔进文件夹的技能,都要先把全文摊开。
- **处处标来源**:列表、「/」菜单、智能体读到的那一份里都写着它从哪来。
- **脚本不执行**:技能里的脚本照样存着、能当参考读,Mosael 不会运行它们。
- **有大小上限**:`SKILL.md` 不超过 64 KB,单个文件 2 MB,一个技能 200 个文件、合计 10 MB;压缩包里的路径越界、符号链接一律拒收。
