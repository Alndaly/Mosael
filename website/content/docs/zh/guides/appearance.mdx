在侧栏打开「设置 → 外观」。这里的选择立即应用到整个界面，并保存在当前设备；不用重启。

![外观设置：主题、背景与字体](/media/screens/settings-appearance.png)

## 主题与自定义背景

可选择浅色、深色或跟随系统。

「背景与磨玻璃」给整个应用换一张背景：背景来源可选「无」「渐变预设」或「自定义图片」（上传、更换、移除）。设了背景之后，面板自动变成半透明磨玻璃，可以调「表面透明度」「磨玻璃模糊」和「背景压暗」，让文字始终读得清；悬浮表单、菜单和助手同样是半透明模糊表面。改动即时预览、逐设备保存，「恢复默认」一键回到原始外观。

![「背景与磨玻璃」:背景来源、五种渐变预设、表面透明度与磨玻璃模糊](/media/screens/settings-background.png)

![设了渐变背景之后的工作台:面板变成半透明磨玻璃](/media/screens/appearance-glass.png)

## 界面语言

同一页的「语言」可选简体中文或 English。它管的不只是页面上的文字：后端返回的报错、桌面端的菜单栏与托盘菜单、系统对话框和通知、发布时回报的失败原因、3D 场景页，以及从 Blender 取回、接回时的提示，都跟着这里的语言。浏览器扩展有自己的语言设置，见[Chrome 视频助手](/docs/guides/browser-extension)。

## 选择字体

字体卡片同时预览中文、英文和数字。可选默认 Inter、系统字体、思源黑体、思源宋体、霞鹜文楷，以及四种强调英文风格的组合：

| 英文字体 | 中文搭配 | 风格 |
| --- | --- | --- |
| Space Grotesk | 思源黑体 | 几何、简洁 |
| Newsreader | 思源宋体 | 衬线、阅读感 |
| Caveat | 霞鹜文楷 | 自然连笔手写 |
| Kalam | 霞鹜文楷 | 手写笔记 |

选择卡片即可预览整套界面。内置字体随应用提供，不需要访问在线字体服务；系统字体依设备而异。界面字体不会修改素材、字幕样式或导出视频的字体。

## 自定义 CSS

桌面端还可以写一个 CSS 文件覆盖应用自带的样式：「打开」会按模板建好文件并交给你的默认编辑器，存盘即生效、不用重启；「在文件夹中显示」找到它在哪。这个文件里的规则压过应用自带的所有样式，多数时候不需要 `!important`。界面看起来不对劲时先把「启用」关掉 —— 文件还在，只是不加载，就能分清是不是自己写的 CSS 造成的。网页版读不到你机器上的文件，没有这一项。
