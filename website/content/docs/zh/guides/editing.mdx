「剪辑」页以中央监看器和底部时间线为核心。左栏在 **素材 / 逐字稿 / 字幕 / 配音** 间切换;选中片段后右侧出现检查器。
顶部命令栏右侧依次是 AI 助手、撤销 / 重做、「在播放头加字幕」「在播放头加花字」和「导出」。

从素材栏导入文件(或右键素材「加入时间线」),再拖入轨道。演示使用已经准备好的视频、旁白和字幕,展示选中片段、打开检查器和播放预览。

标题栏的下拉用来切换项目;一个项目里有几条时间线时,从画板时间线格「在剪辑里打开」会直接打开那一条。面板宽度可拖动边缘改变。

## 时间线

时间线工具栏从左到右:**选择**(A)/ **刀片**(B)工具,**放置模式**(覆盖 / 插入),「序列设置」,在播放头分割、存下这一帧、
创建副本、涟漪删除、删除片段,「添加轨道」(视轨 / 音轨 / 字幕轨),吸附(N),缩小 / 放大 / 适配窗口,以及「快捷键」速查。

- **序列设置**:改画幅(16:9、9:16、1:1、4:5)和填充方式(裁剪、留黑边、模糊背景)。
- **轨道**:视频、音频、字幕轨并存。新视频轨建在最上面(盖在下面的画面之上),音轨和字幕轨加在底部;把片段拖到最上方松开
  会新建一条视频图层。轨道头上有:上移 / 下移(改图层顺序)、静音、**S 独奏**(只听这一条)、**D 闪避**(别的轨出声时这条自动压低约
  10 dB,常用在给人声让路的背景音乐上)、锁定、删除。字幕轨只有一只眼睛:隐藏后预览和导出都不显示这条字幕。**锁定的轨真的改不动**;
  **最后一条视频轨删不掉** —— 先加一条新的再删它。删除带片段的轨会先问。
- **播放**:空格播放 / 暂停,监看器上可循环、调倍速(0.5 / 1 / 1.5 / 2 倍)、调音量、全屏。变速播放保持音高,和导出时的
  变速一致。点画面也能播放 / 暂停。
- **存下这一帧**:把播放头这一帧存成一张图片素材 —— 含字幕和花字,和成片一致。
- **长时间线**:时间线只画看得见的片段,播放头平滑走,预览的声音用轻量代理文件,几百段的时间线也拖得动。

### 放下即覆盖,或插入

放置模式默认是**覆盖**:拖动、修剪、复制、从素材栏拖入的片段落到别的片段上时,被盖住的那部分直接挖掉,拖动时预览里就能看到
下面那段会被挖成什么样 —— 同一条轨上不会叠着两段。修剪停在邻居的边上,不会越过去。切到**插入**时,放下的位置之后的片段整体往后让。

![覆盖模式下把「松鼠与蝴蝶」往左拖:落点上被盖住的那部分在拖动中就挖空了(按 Esc 取消,没有真的移动)](/media/screens/editor-overwrite.png)

- **波纹删除**(⇧Delete,或右键「涟漪删除」)删掉片段并让后面的左移补缝;**Q / W** 把上一个编辑点到播放头、播放头到下一个编辑点
  这段剪掉并补缝;逐字稿里删词删句、清口癖也是同一套「按区间剪掉」。
- **变速会推着后面的走**:片段变快变慢时,后面的片段跟着挪,不会叠到一起。
- 时间点都吸到帧上,长时间线不会越往后越错位。

### 链接的画和声音

右键视频片段「分离音频」,声音放到一条空着的音轨上、原片段静音,两段**链接在一起**:片段上有链环标记,一起挪、一起修剪、
一起切、一起删,变速也一起变。分离出来的声音带着原来的淡入淡出和音量曲线。

- **⌥ 单击**只选链接组里的这一段(临时解链):接下来的拖动、修剪、删除、切分只动它。
- **按住 ⌥ 拖边缘**只修这一段的边。

![分离过音频的片段:画面在 V1、配乐在 A1,两段带着链环标记,选中一段时它的链接组一起选中](/media/screens/editor-linked.png)

### 几个人(和智能体)一起改

同一条时间线可以有几个人、几个智能体同时改。每一步编辑都带着「我看到的是哪一版」:别人改的是不相干的地方,你这一步照常落下;
碰到同一处时,你会看到「某某刚改过这条时间线……已换成最新的一版」,在新版上再做一次即可,不会互相覆盖。

**⌘Z 只撤你自己的那一步**,不会把同事或智能体刚做的改动撤掉;撤销 / 重做会打乱别人后来改过的地方时,它不执行并说明原因。
一串操作算一步:整次配音、重新生成字幕撤销一次就回去。素材删掉之后撤销 / 重做照常进行,片段重建成「素材已删除」占位。

## 片段属性、外观与花字

选中片段,右侧检查器的「属性」里依次是:素材与时间信息、字幕或花字的文字、**速度**(0.5–2 倍预设)、**音频**(静音、增益 0–200%,
可打关键帧)、**画面淡变**和**音频淡变**(淡入 / 淡出秒数)、**外观**、**变换**(缩放、旋转、不透明度、水平 / 垂直位置,
都能打关键帧,「清除动画」「重置」)。也可以直接在监看器上拖画面框缩放、旋转。

![选中片段时右侧的检查器:素材与时间信息、速度、音频、画面淡变](/media/screens/editor-inspector.png)

- **外观**(视频和图片片段):**形状蒙版**(无 / 圆角 / 圆形,圆角可调半径),**阴影**(默认关;颜色、不透明度、模糊、水平 / 垂直偏移)。
  投影按画面像素算,片段缩放、旋转时,预览和导出的投影一样大、一样方向。降分辨率导出时按比例缩小。
- **画中画**:加一条视频轨把画面叠在上面,用「变换」或在监看器上拖小、挪到角落,再配上圆形蒙版和阴影即可。导出按素材自己的宽高比。
- **花字**:命令栏「在播放头加花字」放一段文字片段。「文字样式」有五种预设(简白、描边、综艺、投影、糖果),可调字体、字号、
  文字颜色、描边色、**描边**(上限是字号的 15%)、阴影、加粗、斜体和对齐。描边画在字的外面,白字的字芯不会被吃掉;
  预览和导出是同一个外圈。

## 逐字稿驱动剪辑

对音视频素材点「AI 转写」,得到带时间码的**逐字**稿:

- 单击定位,按住拖选标记删除,双击标记单个词;选好之后「删除所选词」,对应的片段从时间线上剪掉并补缝。
- 「静音」找出逐字稿里 0.6 秒以上的停顿,打开后可以「全选静音」一起删。
- 「口癖」先预览再选中:按类别列出每一处和它的上下文(拖音「呃 / 嗯 / um / uh」、套话「就是说 / 然后就是」、「那个」、英文 like),
  看过再「选中这 N 处」。「那个」和 like 常是正经词(那个人 / I like it),默认不选。
- 「按句切分」把整段按句切开;在一句中间「在此切一刀」后,两半仍挨在原位,不会被同一时刻的另一种语言或另一轨的行插开。
- 「生成字幕」从逐字稿铺一条字幕轨。
- 说话人以人形图标加从 1 数的序号标出(「说话人 1」),只在识别出两位以上说话人时显示。
- 已有逐字稿、时间线上还有素材没转写时,按钮写作「转写其余 N 段」。
- 断句只在以标点结尾的地方断:讲话人换气不会劈出半句,拉丁词(controlnet 这种)不会被劈开。重新断句会重新测量每一行,
  不留下大块空白。
- 转写用「设置 → 能力提供方 → 转写」里定的那一家;本机引擎由部署管理员在[管理 → 引擎](/docs/guides/admin)里装好,模型首次使用时下载。

## AI 助手

机器人入口打开的是 AI Studio、工作流与画板共用的会话池。剪辑页默认把助手停靠成真正的右栏,时间线与监看器随之缩放而不是被覆盖;
需要盖在上面时再切换为悬浮。左上角标题就是当前会话名称,点击可搜索或切换会话。

智能体能用的剪辑操作和你手上的是同一套:新建时间线、加片段、复制片段、替换媒体、加轨道时指定放在第几行、配字幕、配音……
改动先出确认卡;它的改动和你的改动一样按「只撤自己的」来。

## 调色

选中视频或图片片段,在检查器切到「调色」。调色只作用于当前选中的片段,右上角「重置」:

- **风格预设**:无、鲜艳、黑白、暖色、冷色、电影、褪色。
- **光线**:曝光、亮度、对比度、伽马、高光、阴影、白色阶、黑色阶;**色彩**:色温、色调、饱和度、自然饱和度、色相;
  **效果**:褪色、锐化、暗角。
- **曲线**:Luma / R / G / B 通道,点曲线加点、拖动调整,双击或右键删除;独立撤销栈(每次拖动记一步)。
- **3D LUT**:上传 `.cube`,导出时烧录、叠在调色之上。

色阶(高光 / 阴影 / 白 / 黑)、锐化和 LUT 只在导出时完整生效,预览里是近似效果(LUT 预览暂不显示)。

## 字幕

- **加字幕**:命令栏或字幕页的「在播放头加字幕」,或「从逐字稿生成」整条。字幕页每条可以直接改字;点时钟图标「改起止时间」,
  开始、结束填秒数或 `分:秒`,Enter 确认、Esc 取消;把一条的文字清空就是删掉它。播放时列表跟着当前那一条滚动。
- **重新生成字幕是替换,不是叠加**:目标字幕轨上已经有字幕时会先问「重新生成字幕?」,确认「替换并重新生成」。工作流「生成字幕」
  节点和这里断句一致。
- **字幕样式**(整条时间线共用):文字(字体、可上传字体、字号、颜色、加粗)、衬底(底色、不透明度,0 为无衬底)、布局
  (底部 / 居中 / 顶部、边距)。字幕和花字都会烧录进导出的成片。

![字幕页:每条字幕可以直接改字,点时钟图标改起止时间(这里正在改第一条)](/media/screens/subtitle-timing.png)

### 导入与导出 .srt / .vtt

- **导入字幕文件**:选落到哪条字幕轨(默认新建一条),选已有的轨时可以「替换这条轨上原有的字幕」;选 `.srt` / `.vtt` 文件,
  也可以把文件拖进素材池。
- **导出字幕文件**:选哪条字幕轨(不止一条有字幕时)、格式(SRT 或 WebVTT);有两行的双语字幕时选「两行都写 / 只写第一行(原文)/
  只写第二行(译文)」。

### 翻译与双语字幕

字幕页的「翻译」:选目标语言(英、简中、繁中、日、韩、法、德、西、俄),可以「仅选中的 N 条」,打开「保留原文(双语)」
得到「原文 / 译文」两行。翻译引擎照「设置 → 能力提供方 → 翻译」列:**Google 翻译(免费)** 不用配置、逐句直译;
**对话模型** 用你自己的对话连接,能顺着上下文润色(会花钱);装了翻译插件的也在里面。默认是 Google。

**双语也可以分两条轨放**:原文一条字幕轨、译文一条(比如另导入一份 .srt)。同一时刻几条字幕轨上都有字时,合成一个框放在底部,
上面那条轨的字在上 —— 预览和导出逐像素一致。

## 配音

![字幕配音:每条字幕自带入口,产物落到一条专门的配音轨](/media/screens/subtitle-dub.png)

<Loop src="/media/videos/subtitle-dub.mp4" poster="/media/screens/subtitles.png" alt="操作演示:查看字幕配音设置与逐字稿入口" />

左栏的「配音」页给字幕配音:上面选**语音引擎、音色、语速**,下面是这批字幕怎么配。范围跟着时间线上的选中走 —— 选了几条就只配
那几条(「仅选中的 N 条」),没选就整条轨;字幕页每条字幕旁的配音按钮就是「选中这一条、切到配音页」,这时会写「只配 0:12 这一条」,
可以「改成整条轨」。有几条字幕轨时选「配哪条字幕轨」(默认是选中那条所在的轨,否则最上面那条)。

产物落到一条专门的**配音轨**:原声一个字不动,不满意整条删掉就回到原样;再配一次回到同一条轨。**重配一句是替换,不是叠加**;
同一句、同一把嗓子已经配过的直接跳过,完成时会说跳过了几条。整次配音撤销一次就回去。

**原声**怎么办,四档:

- **配音说话时压低**(默认):原声降到约 −10 dB,适合原声是环境音或音乐。
- **静音(译配用这个)**:两边都是人声时压低只会变成两个人同时说话。
- **保持原样**:你自己在轨道上处理。
- **只去掉人声,留背景音**:先把原声拆成人声和背景音,丢掉人声、留住背景音乐(要装人声分离引擎)。

四档都**不删任何东西**:动的是轨道上的静音 / 闪避开关,或者把背景音那份放到一条音频轨上,随时撤得回来。生效的范围是真正装着声音
的那条轨,视频片段自带的声音也算。

- **缩放到段落长度**(默认开):念不完时在 0.9–1.5 倍之间变速压回这条字幕的时长;1.5 倍还放不下就占用到下一句开始之前的空当。
  用的是片段自己的倍速,无损、可撤销,事后还能在检查器里微调。
- **配音文本**:双语字幕会多问一句念「完整字幕(含两行)/ 第一行 / 第二行」。整段丢给合成会先念原文再念译文。
- **引擎**:本地音色克隆、Edge 免费语音、OpenAI、火山、阿里云百炼,以及装了配音插件的;远端引擎的音色按引擎现拉(火山的目录
  跟着你的账号走)。本地克隆还能选克隆引擎(F5-TTS / Fish Speech),音色库在「设置 → 配音与音色」。

念一段任意文字、做播客产出的是独立的音频素材,和时间线无关,在 [AI Studio → 音频](/docs/guides/ai-studio)。

> **语言对不上时,引擎不会报错** —— 它按自己认识的发音规则硬念一遍,交出一段听不懂的声音然后报成功。
> 所以选引擎的那一刻就会拦下来并说清出路,而不是等你听完才发现。

### 用自己的音色念外语

本地音色克隆的语言能力**取决于装了哪份权重**,不是引擎的固有限制。基础权重是中英双语;日文、法语、德语、西班牙语、意大利语、
俄语、印地语、阿拉伯语、芬兰语各有一份社区微调权重,缺哪份就在配音页当场下载(各约 1.4 GB)。

日文、韩文、俄文、阿拉伯文、印地文能按文字自动认出来,装好就直接用。而法语、德语、西班牙语、意大利语、芬兰语和英语共用拉丁字母
—— **没有任何字符能证明「这是法语而不是英语」**,所以它们要在「权重」下拉里明说用哪一份。

### 不装本机引擎,用百炼念自己的音色

配音库里的嗓子也能交给**阿里云百炼的 CosyVoice** 念:引擎选「阿里云百炼(CosyVoice)」,音色下拉在系统音色下面多一组
「我的克隆音色」。念的是这把嗓子在**你自己的百炼账号**里复刻出来的一份副本 —— 不用装本机引擎、不用下几 GB 权重,代价是
按 CosyVoice 的字符价计费(复刻这一步免费)。本机克隆照旧能用:同一把嗓子,本机直接用参考音频,CosyVoice 用副本。

- **第一次用要你点一次头。** 参考音频(就是建音色时那 5–15 秒)会上传到你的百炼账号,确认框里写明传到哪条连接、复刻到哪个
  模型上;同意了才传,复刻在后台做,十秒左右,配音会等它好了再念。之后换了模型、副本被百炼删了(一年没被合成用过会被自动删除),
  都在用到时自动重建,不再问。也可以先在「设置 → 配音与音色」里点那把嗓子的「复刻到百炼」(排成一个任务,好了任务中心会说)。
- **没声明是谁的嗓子不能复刻**(和[数字人](/docs/guides/digital-humans)同一条线),下拉里也不列:先在音色库里补上授权声明。
- 音色库里每把复刻过的嗓子写着它在哪儿能念:「本机」「百炼 · cosyvoice-v3-flash」;复刻中、复刻失败(悬停看原因)、被百炼删了
  也写在那儿。
- **在 Mosael 里删掉这把嗓子,百炼上的副本一起删。** 删不掉的(钥匙失效、网络不通)会列出来,去百炼控制台的声音复刻里看一眼。
- 副本跟着钥匙走:同一条连接下每个人用自己的 Key,复刻出来的音色只在那个人的账号里。复刻在用量里记一笔(免费),
  看得到哪天、哪把嗓子、传到了哪条连接。
- 音色绑在建它的那个模型上:连接上配的 CosyVoice 模型换了,用到时在新模型上再复刻一份,旧的那份不动。

AI Studio 的「音频」、画板上的念字、工作流的配音节点、「语音对话」的音色,选 CosyVoice 时都能挑配音库里的嗓子。
工作流和人物资产的「让它说话」在后台跑、当场问不了你,第一次用之前先点「复刻到百炼」;没同意过的会停在配音那一步并说明。
智能体也能点名用 CosyVoice 念配音库里的嗓子,没同意过时它在开确认卡的那一刻就会说,请你先去点「复刻到百炼」。

要在账上看到 CosyVoice 花了多少,先在「管理 → 成本规则」里对百炼那条连接点一次「预填价格」(见[模型连接与配置 → 成本规则](/docs/guides/providers))。
合成失败时,报错带着百炼回包里的原话(比如音色不存在、模型不对)。

## 导出

命令栏的「导出」打开「导出设置」,渲染当前时间线,产出一条新素材:

| 选项 | 可选 | 默认 |
| --- | --- | --- |
| 分辨率 | 原始、1080p、720p、480p(只降不升,花字和投影按比例缩) | 原始 |
| 帧率 | 跟随序列,或 24 / 25 / 30 / 50 / 60 | 跟随序列 |
| 画质 | 高(文件较大)、标准、压缩(文件较小) | 标准 |
| 响度标准化(−14 LUFS) | 把整条声音拉到 −14 LUFS、峰值不超过 −1 dB,适合发到不做音量归一的地方;预览里听不到 | 关 |
| 给 AI 生成的内容加「AI 生成」标识 | 时间线上有 AI 生成的片段时才出现(片段上带「AI」角标) | 开,每次导出都是开着的 |

![导出设置:分辨率、帧率、画质与响度标准化。这条时间线上没有 AI 生成的片段,所以没有「AI 生成」标识那一项](/media/screens/export-dialog.png)

前四项会记住上次的选择。**不开响度标准化也不会爆音**:混音后总是限幅。

- **AI 标识**:成片里用到 AI 生成或合成的素材(包括由它们截取、降噪、分离出来的),片头正中写 3 秒「AI 生成」,整片右上角一行小字;
  文件里总会写入标准的隐式标识字段。关掉画面上的标识时会提示由发布的人负责,详见[数字人](/docs/guides/digital-humans)里的「AI 生成标识」。
- **更快**:字幕和静止的花字合成一路透明轨叠一次、同一句只渲一次;同一素材接着用的几段共用一路输入;层多的时间线分块渲再无损接起来。
  一条 270 秒、150 段跳剪加 200 条字幕的时间线,导出从 106 秒降到约 17 秒,内存占用减半多;素材很多的时间线不再报「打开的文件太多」。
- **更准**:每次导出用自己的中转目录,同一条时间线同时导出两份互不干扰;段边界按整帧对齐;声音晚开始的素材不会声画错位;
  入点正好落在关键帧上时声音不缺头;硬件编码起不来时开跑前就换成软件编码。
- 时间线上有「素材已删除」的占位片段时,导出会拒绝并点名是哪一份素材,而不是静默地少一段。

导出完成即可进入[发布](/docs/guides/publishing)。
