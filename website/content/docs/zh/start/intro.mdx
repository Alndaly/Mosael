Mosael 是一个**本地优先的桌面创作工作台**。素材、笔记、画板、3D 场景和剪辑工程位于同一工作区，智能体和工作流可以在这些内容之间协助完成任务。

## 从资料到作品

- **整理资料**：[素材库](/docs/guides/media)收集视频、图片与声音；[文档](/docs/guides/documents)导入 PDF、Word、PPT、表格并在本机解析成可读全文；[笔记](/docs/guides/notes)保存脚本、逐字稿和研究资料；[资产库](/docs/guides/assets)把反复出现的人物、场景、道具存成有名字的资产。
- **展开构思**：[创意画板](/docs/guides/boards)把文档、参考图、资产、3D 场景与生成格子连起来，格子自己会转写、翻译、降噪、宫格切分；画板上还能放一格时间线做粗剪。评论和标记帮助讨论与定位。
- **预演镜头**：[3D 场景](/docs/guides/scenes)用于布景、灯光和关键帧动画，镜头画面可以作为图片或视频生成参考。
- **制作成片**：[AI Studio](/docs/guides/ai-studio)与智能体对话、生成图片 / 视频 / 音乐；[数字人](/docs/guides/digital-humans)让一张脸说话或给片子改口型；[剪辑](/docs/guides/editing)处理时间线、逐字稿、字幕、配音、调色和导出。
- **重复与发布**：[工作流](/docs/guides/workflows)复用创作步骤（官方模板覆盖成片、译配、带货、数据分析），[定时任务](/docs/guides/scheduler)安排执行，[发布](/docs/guides/publishing)管理目标账号与上传结果。
- **扩展与管理**：[插件](/docs/guides/plugins)接入 ComfyUI、对象存储、文档解析等外部能力；团队使用时由部署管理员在[管理控制台](/docs/guides/admin)装引擎、管成员和成本。

![工作台：最近编辑、全部项目与项目搜索](/media/screens/home.png)

在工作台新建项目（先起名，建好留在工作台），点项目卡片或行的任意位置打开它进入剪辑；「选择」可以批量删除项目。素材、资产、笔记、3D 场景、画板等页面都在左侧导航；任务、发布与 AI 费用汇总在「统计」。

## 数据与联网

默认情况下，工程和素材保存在当前电脑。本地素材整理、剪辑与导出可离线进行；云模型、链接下载、联网工具和平台发布需要网络。使用本地转写或声音克隆前，需要先下载相应模型。

连接团队后端后，共享数据保存在该服务器；浏览器登录档案仍属于执行上传和自动化的桌面设备。详见[远程部署](/docs/guides/remote)与[浏览器池](/docs/guides/browser-pool)。

## 从哪里开始

先[下载安装](/docs/start/download)，再按[快速上手](/docs/start/quickstart)完成一次导出。需要 AI 时，再[配置模型连接](/docs/guides/providers)。文档按「开始使用 → 整理与构思 → 制作与剪辑 → 自动化与发布 → 扩展与部署」组织；手机顶部可分别打开文档目录与本页目录。

源码可在 [GitHub](https://github.com/Alndaly/Mosael) 查看，使用与再分发须遵守[专有许可](/docs/about/project)。
