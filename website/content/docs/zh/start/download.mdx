Mosael 是本地优先的桌面应用：本地素材剪辑与导出可离线。工作流是否需要联网取决于节点；远端 AI 需配置服务商或授权登录，本地转写和声音克隆需先下载模型。

## 下载

当前正式版本：**[GitHub Releases](https://github.com/Alndaly/Mosael/releases/latest)**。

安装包统一发布在 **[GitHub Releases](https://github.com/Alndaly/Mosael/releases)**:

| 平台 | 产物 | 说明 |
| --- | --- | --- |
| macOS | `Mosael-<版本>-arm64.dmg` | Apple Silicon(M 系列) |
| Windows | `Mosael.Setup.<版本>.exe` | Windows 10 / 11(x64),NSIS 安装器 |

应用启动后会静默比对 Releases 的最新稳定版，发现新版会提示前往下载；设置 → 本地后端 → 版本 里也有
「检查更新」按钮。GitHub 预发布版不会主动推送，需要从 Releases 页面明确选择下载。

<Aside type="note" title="安装包签名">

1.2.0 已正式发布。macOS 应用与 DMG 均已完成 Developer ID 签名、安全时间戳和 Apple 公证，并附加公证票据。兼容且已录入指纹的 Mac 可在浏览器池使用设备绑定的 Touch ID passkey。

Windows 安装包暂未签名，SmartScreen 可能提示未知发布者；继续安装前请确认下载来源。

</Aside>

- 内置后端引擎与 ffmpeg，开箱即用。
- 本地转写 / 声音克隆模型首次使用时按需下载(数百 MB 至数 GB)，建议预留 **10GB+** 磁盘。

## 从源码运行(开发)

仓库根目录：

```bash
pnpm install
pnpm dev          # 起后端 + 前端 + Electron
```

打包桌面版：

```bash
pnpm build:mac    # 前端 + 边车 + 发布器 + 后端(PyInstaller)+ .app
pnpm dist:mac     # 同流程,产出 .dmg(分发时用)
```

macOS 本地打包需要签名证书、描述文件与公证凭据，配置步骤见仓库的 [macOS 签名说明](https://github.com/Alndaly/Mosael/blob/main/docs/MACOS_SIGNING.md)。

正式发版由 CI 完成：维护者推送 `v*` tag，GitHub Actions 自动打包 macOS / Windows 双平台并挂到
Releases。带 `-beta1` 等后缀的 tag 保持为预发布，不会覆盖当前稳定版（详见仓库 README）。

## 数据在哪

默认本地模式下，账号、项目、素材与后端配置保存在 `~/.mosael`(Windows:`C:\Users\<你>\.mosael`),app 本体之外——升级 / 重装不丢数据。

界面主题、背景与字体在「设置 → 外观」中调整，详见[外观与字体](/docs/guides/appearance)。连接远程后端时，工程数据保存在远端；升级前建议备份所用后端的数据目录。
