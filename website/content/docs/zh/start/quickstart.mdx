<Steps>

1. **登录 / 创建本地账号**

   首次打开 Mosael 会让你登录或注册一个本地账号(数据都在本机)。也可以切到团队服务器。

   <Shot src="/media/screens/login.png" alt="Mosael 登录页" />

2. **配置模型服务商(用到 AI 时)**

   进「设置」，在 **AI 对话 / AI 绘图 / AI 视频 / AI 音频** 各分区里「添加供应商」，选服务商、贴 API Key。
   详见[配置模型服务商](/docs/guides/providers)。

3. **新建项目、导入或生成素材**

   首页新建项目。把本地视频拖进「素材」库；或到「AI 工作台」让智能体按描述生成素材。

4. **在时间线上剪辑**

   「剪辑」页把素材拖到轨道上；用逐字稿删句删词、涟漪删除、变速、调色、字幕滤镜把成片打磨好，一键导出。

   <Shot src="/media/screens/editor.png" alt="Mosael 剪辑页:多轨时间线" />

5. **一键分发(可选)**

   到「发布」页，选好已登录的社媒账号，配标题/简介/标签，检查目标与文案后提交发布。
   详见[发布与浏览器账号](/docs/guides/publishing)。

</Steps>

<Aside type="tip" title="先配置，再运行">

模型服务商、素材输入与发布账号需要按自己的环境配置。智能体对需要批准的工具操作显示确认卡；你主动启动的工作流按已配置步骤执行。

</Aside>

登录后可先到[外观与字体](/docs/guides/appearance)选择浅色、深色或自定义背景，并预览中英文字体。平台账号先在[浏览器池](/docs/guides/browser-pool)登录，再回发布页选择。
