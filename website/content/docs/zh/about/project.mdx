## 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面壳 | Electron(内置发布执行器，驱动内嵌浏览器登录 / 上传) |
| 前端 | Vite + React + TypeScript + Tailwind |
| 后端 | FastAPI(Python)+ SQLite，单一事实源；PyInstaller 打包进应用 |
| AI 智能体 | 内置 Node.js 边车，基于 pi-agent-core / pi-ai，调用 Mosael 工具 |
| 文档站 | Next.js（本站） |

默认工程数据保存在本机 `~/.mosael`；连接远程后端后则保存在该服务器，浏览器登录分区仍属于桌面执行器。
